==================================================
  AIQUIZ 3D - AIクイズランナーゲーム
==================================================

■ 遊び方
  1. AIQUIZ.exe をダブルクリックして起動
  2. メインメニューで学年・教科・難易度を選択
  3. ゲーム開始！正しい答えのドアを選んで走り抜けよう

■ オフラインモード
  設定不要ですぐ遊べます。内蔵の問題バンクから出題されます。

■ オンラインモード（AI問題生成）
  AIがリアルタイムで問題を生成します。
  利用するには、以下の手順でAPIキーを設定してください：

  1. 同フォルダの「.env.example」を「.env」にリネーム
  2. テキストエディタで .env を開く
  3. 使いたいAIサービスのAPIキーを入力して保存
     - OpenAI: OPENAI_API_KEY=sk-xxxx...
     - Google Gemini: GOOGLE_API_KEY=AIza...

■ 操作方法
  - A / ← キー : 左に移動
  - D / → キー : 右に移動

■ グラフィックス設定
  .env ファイルで以下を調整できます：
  - TARGET_FPS=120  （フレームレート上限）
  - VSYNC=1         （垂直同期: 1=ON, 0=OFF）
  - MSAA_SAMPLES=4  （アンチエイリアス: 0, 2, 4, 8）
