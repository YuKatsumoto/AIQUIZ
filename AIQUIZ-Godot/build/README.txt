AIQUIZ 3D
=========
AI搭載クイズランナーゲーム

【遊び方】
1. このフォルダ内の「.env.example」を「.env」にリネーム（コピー）してください。
2. AIQUIZ.exe を起動してください。
3. メインメニューから学年・教科・難易度を選んでスタート！

【オンラインモード】
プロキシサーバー経由でAIが問題をリアルタイム生成します。
.envファイルの PROXY_URL が設定されていれば自動的にオンラインモードが有効になります。

【オフラインモード】
インターネット接続なしでも2400問以上のクイズで遊べます。

【動作環境】
- Windows 10/11 (64bit)
- 画面解像度: 1280x720 以上推奨
