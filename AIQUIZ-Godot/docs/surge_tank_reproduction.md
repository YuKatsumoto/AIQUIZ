# 地下ステージ：首都圏外郭放水路 調圧水槽の再現

2026-10-04作成。2Pサドンデスの地下ステージ（これまでの架空の「地下神殿」）を、首都圏外郭放水路の調圧水槽（通称「地下神殿」）の図面どおりの配置・寸法・照明で作り直した記録。サドンデスのゲーム内容はこのあと作り直す予定なので、いまのサドンデスに合わせた架空の要素（天井開口・流入トンネル・操作室のバルコニー）は作っていない。

最初は写真とストリートビューだけから柱の格子を推定した（7.8m×13.5m、13線、平らな床）。その後、国土交通省の平面図・断面図が見つかり、配置そのものが違っていたので、図面に合わせて全部作り直した（旧版のスクリプトは `assets/environment/surge_tank/source/build_tank_v1_grid_guess.py.bak`）。

## 2. 再現の寸法（図面の座標、m）

### 2.1 キャラクターに合わせた拡大（1.5倍）

ゲームのキャラクターは身長約2.1m・頭0.44m（立方体）・肩幅0.76m で、実際の人（約1.7m・頭約0.23m・肩幅約0.45m）より大きい。実寸の舞台ではキャラクターに対して柱が細く低く見え、写真の見学者と柱の対比（人が柱に比べて小さい）にならなかった。そこで舞台全体（形・光の焼き込み・実ライトの位置と届く距離と強さ・当たり判定・反射プローブ・霧・番号札・塵）を一つの倍率で拡大できるようにした。

- 身長の比は1.25倍、頭・肩幅の比は1.7〜1.9倍。実際のゲーム画面（着地・洪水・本戦）を1.0・1.25・1.5倍で見比べ、1.5倍にした（柱は高さ約26.5m・幅3m相当、ホールは幅約107m・長さ約257m）。
- 焼いた光は図面の照明の明るさのまま使う（形と照明を同じ倍率で拡大すると、見え方は実寸と同じ）。Godot の実ライトは位置と届く距離を1.5倍、強さを1.5²倍にした。
- シェーダーの図面の計算（柱のまわりの泥、掘り下げの縁、側壁、照明の位置）とテクスチャの投影は、ワールド座標を拡大率で割った図面の座標で行う。
- ゲームの位置（着地点・リフトのタワー・審判の立ち位置・水のシミュレーションの範囲）は変えていない。降下の演出が通り抜ける天井の高さは拡大後のスラブ下面（26.55m）にした。
- 2026-10-04 に 2.0 倍へ上げた（柱は高さ約35m・幅4m相当、線の間隔28m、ホールは幅約142m・長さ約343m）。設定画面の講義室（ゴドーくん 1.62m）では 1.5 倍でも柱の間が狭く、教室と実習場（`docs/settings_hall.md`）が窮屈だったため。`SuddenDeathLayout.TANK_SCALE` を変えて `tools/sudden_death/build_tank_scenes.gd` で組み立て直しただけで、Blender の部品とライトマップは作り直していない。見た目のテスト（`tank_look`、high、GPU p95 1.1〜1.4ms）と読み込みのテスト（27/27）は合格。サドンデスは廃止したので、そのルールのテストで出る不合格（天井が高くなった降下の加速、柱に重なった流入口の決め打ち座標）は直していない。

### 3.1 光

- 静的な光はBlender（Cycles、GPU）で焼く。ベイクのたびに水槽全体（全区画・両端・第1立坑・階段と全照明）がシーンにあり、焼く部品だけを選ぶので、隣の区画の照明や第1立坑からの光も入る。
- 符号化は RGB = (E × 汚れ / light_max)^(1/2.2)、A = AO。E は白いランバート面の放射輝度（露出0）。
- Godotでは焼いた光を IRRADIANCE として渡し（デカール・SSAO・SSILが効く）、同じ位置に置いた実ライト（影なし）は人物を照らし、舞台には `light()` で鏡面のハイライトだけを足す（濡れた床に照明が映る）。反射は箱投影の反射プローブ6個と画面空間反射（高画質以上）。

### 3.2 汚れと床

- 柱・壁の汚れ（下の茶色い変色、足元の濡れ、水位の筋、縦の流れ跡、柱ごとの色の違い）と天井のしみはBlenderの汚れの場（`materials_tank.py`）でライトマップに掛けてある。足元の濡れは、その場所の床（掘り下げ0、棚5m）からの高さで付ける。
- 床はシェーダーで描く：柱の根元の輪、掘り下げの斜面の足元と棚の壁際の泥、濡れ、鏡のような水たまり、立坑側の乾いてひび割れた泥。

### 3.3 照明の位置の確かめ方

公式写真（中央の柱を正面に見る構図）で、中央の柱の幅（2m）は52画素、奥の列の柱（x = ±7m）は中心から±95画素。柱の線の間隔14m を使うと、焦点距離は約400画素、中央の柱の手前の端までは約15.4m。この条件で照明の候補を投影すると：

| 照明の規則 | 大きな2灯の位置（予測） | 写真 |
| --- | --- | --- |
| 柱の線の中間の横断梁、その線の柱と同じ列（旧版の推定） | 中心から ±108画素 | ±146画素 |
| 格天井の中央（柱のない列、線と同じ位置） | 中心から ±148画素、高さ 182画素 | ±146画素、187画素 |

後者は次の列（±14m、予測 ±170画素・302画素／写真 ±185・292）とその次の列（±7m、予測 ±60・350／写真 ±68・341）も合う。床の消失点（写真で約 470画素）から求めたレンズの高さは床から約14.9m。

## 4. いまのサドンデスとの関係

- 舞台の差し替えだけを行い、サドンデスの流れ（降下・着地・導入・本戦・帰還）は動くままにした。降下の計算が使う天井の高さ（`SuddenDeathLayout.HALL_HEIGHT`、`SuddenDeathDescent.HALL_HEIGHT` も同じ値を使う）は拡大後のスラブ下面（17.7m × 1.5）。着地点（0, 0）・リフトのタワーの位置（±4, 9）は掘り下げの床の上で、柱と重ならない。
- 実物に天井開口はないので、降下の演出は天井を通り抜けて着地する。水のシミュレーションの障害物は新しい柱・掘り下げの斜面と棚・側壁（`SuddenDeathLayout.pillars()`・`floor_height()`・`wall_half_width()`）に変えたが、流入は以前の「上流端のトンネル」の想定のまま（`HALL_START_Z` は立坑側の端の壁 −38.6 になったので、演出が見る方向は第1立坑の開口になる）。審判はバルコニーがないので見学エリアの床に立つ。これらはサドンデスを作り直すときに決め直す。

## 5. 推定を含むところ

- 掘り下げの縁が60°の斜面か垂直の段差か（図面は1本の線、写真は斜面に見える）。斜面にした。
- 横断梁が線の中間か線の上か（ストリートビューは中間、見学記の写真の読みは線ごと）。中間にした。
- 吸込水路の奥（ゲート室）の形、柱頭・梁の断面寸法、第1立坑の上部の形、ポンプ側の水路の中央にある破線の要素（図面では隠れ線。作っていない）。
- 天井の重機の搬入口（図面の u ≈ 151〜156、v ≈ −12〜−1 の矩形）は作っていない。
- 照明の台数（格天井の中央に1灯ずつで38灯）と明るさ・配光。
- 柱頭の広がり。奥の列の柱は頂部で逆台形に広がって見える（写真では高さ約14〜17m）ので、13.5〜15.5m で幅4m・長さ12m まで広げたが、公式写真の中央の柱は梁の近くまで真っ直ぐ伸びて見え、広がりの高さと形は確かめきれていない。

### 6.3 公式写真との見比べ

`tests/tank_look_runtime.gd` の `00_official_match`（水平のカメラ、縦の画角68°、レンズシフト0.357、写真と同じ縦横比で中央を切り出す）を公式写真に重ねて調整した：

- 照明を150°のスポットからランバート配光の円板にした（柱の上半分が写真のように明るくなる）。
- 床は全面が濡れた茶色の膜（水たまりと鏡のような反射）にした（白い乾いた床と泥の斑点に見えていた）。
- ベイクの露出を2.7倍に、ホワイトバランスは4800K の補正を55% にして、汚れた下部の黄土色を残した。

残る差：写真のほうが露出が高くコントラストが強い（長時間露光と画像処理）、柱の下部の黄土色が写真ほど鮮やかでない、灯具の光芒（写真はカメラの絞りの光条）。
