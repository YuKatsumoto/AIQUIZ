# サドンデスへ行くときの幽霊の復活

2026-10-21作成（ユーザーの指示：「サドンデスに行くとき幽霊状態のときは画面外から体が集まって復活するように。アニメーションは超ハイクオリティで」）。

2人用「10問」の引き分けで、脱落して幽霊のまま表彰台にいる人は、サドンデスへ行く前に体を取り戻す。宙へ浮いた幽霊が体を呼ぶと、
体の部位が画面の外から 1 つずつ飛んできてはまり、はまった所から体に戻る。全部そろうと身を丸めてため、光を放って弾け、
台に降りて立ったまま着地する（膝はつかない）。大型ビジョンの種目発表のあとに流れ、そのまま乗り込みへ続く。

それまでは、発表のあと乗り込みが始まる瞬間（`_begin_pickup`）に、幽霊がいきなり普通の体へ切り替わっていた。

## 2. 時刻表（1 人ぶん。秒は復活の始まりから）

2026-10-21、ユーザーの指示「もっとアニメーションを早く」で、約 5.2 秒から約 3.2 秒に詰めた（発表まで、1 人で 3.3 秒・2 人で 3.4 秒）。

| --- | --- | --- | --- |

| 0.02–1.44 | 部位が脚から順に画面の外から飛んでくる（1 つ 0.5〜0.56 秒）。速く飛んできて、はまる手前でほとんど止まり、最後に吸い込まれるようにはまる（飛ぶ間は回りながら向きがそろう。縁が光り、光の尾を引く）。はまるたびに体が少し揺れる | はまった部位：同じ形の光がふくらんで消える・小さな輪・火花。体の灯りが脈打つ | `ghost_revive_gather`（0.25 秒から）、はまるたびに `ghost_revive_snap`（長音階で上がる） |

そのあと 0.12 秒待って乗り込みへ（カメラは決着演出の画から次の画へなめらかに移る）。2 人とも幽霊のときは 2 人目が 0.12 秒遅れる。
場面の順は `BRANCH → REVEAL → REVIVE → BOARD`（幽霊がいないときは `REVIVE` なし）。種目発表のカメラは、ビジョンから引くときに乗り込みの最初の画ではなく決着演出の画へ戻る。

## 3. 作り

| ファイル | 中身 |
| --- | --- |
| `scripts/world/sudden_death/ghost_revival.gd`（新規） | `GhostRevival`：1 人ぶんの復活の見た目（アバターの姿・部位の飛行・光・音）。拍（`call`・`snap`・`burst`・`land`・`stand`）を `take_beats()` で監督へ渡す |
| `scripts/world/sudden_death/heli_sudden_death_director.gd` | 場面 `REVIVE`（種目発表 `REVEAL` のあとに幽霊がいれば入る）。決着演出の人形から本物のアバターへの入れ替え（`_take_over_cast`）を、復活があるときは復活の頭に 1 回だけ行う（乗り込みでは入れ替えない）。生きている側の見守り（`_pose_watcher`）。試合の頭の予熱に復活の光を足した |
| `scripts/world/player_controller.gd` | `remove_ghost_soul_look`・`restore_ghost_soul_mesh`（幽霊の姿を元へ戻す。部品 1 つずつも）。`apply_ghost_soul_look` が元の見た目（`material_override` と影）を覚えるようにした |
| `scripts/core/game_state.gd` | `sudden_death_revived_mask`・`is_sudden_death_revived`・`mark_sudden_death_revived`。デバッグの引き分けに幽霊を指定する `debug_force_draw_finish(ghost_mask)` |
| `scripts/world/result_finale/result_finale_stage.gd` | 人形を幽霊にするかを `wants_ghost_look` で決め、状態が変わったら付け外しする（復活のあと打ち切りで引き分けに戻ったとき） |
| `scripts/world/game_world.gd` | デバッグ版の F9：Shift で P1、Ctrl で P2、両方で 2 人とも幽霊のまま引き分け |
| `scripts/autoload/audio_manager.gd`・`tools/audio/make_ghost_shark_sfx.py`・`assets/audio/sfx/ghost_shark/ghost_revive_*.ogg` | 新しい 3 音（合成。`docs/sound_effects.md`） |

- 部位は、本物のアバターの部品と同じ形の「飛んでくる部品」を作って飛ばす。はまった瞬間に飛んでくる部品を消し、本物の部品を魂の見た目から元の見た目に戻す。
  飛んでくる部品の縁光りは GOSTRIDER の乗り手と同じシェーダー（`ghost_rider_solid`）、光は `ghost_fx_additive`。
- 飛び立つ所は、カメラから見て、その部位がやって来る向き（体から見た向き）の画面の外。決着演出の画と今のカメラの両方に映らないことを確かめ、床より上に置く。
- 火花・粒・渦の粒は MultiMesh 3 つ（CPU で動かす）。品質「低」では `GraphicsQuality.particle_amount` で減る。

## 4. 確かめ方

```powershell
./Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1280x720 --fixed-fps 60 --script res://tests/sudden_death_v2/ghost_revive_runtime_bootstrap.gd -- case=p1
#   case=p1（P1 が幽霊）/ p2 / both（2 人とも）/ none（幽霊なし：復活の場面が無いこと）。every=N で N フレームごとに画（既定 6）
./Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/sudden_death_v2/parse_check.gd
```

確かめること：場面が `BRANCH → REVEAL → REVIVE → BOARD` の順（none は REVIVE なし）・乗り込みの頭で 2 人とも見えていて魂の見た目の部品が 0・
復活の間カメラが動かない（揺れの数 cm だけ。向きと画角は変わらない）・テロップが出ない・飛び立つ所が画面に映っていない・復活した人に印が付く。
画と `report.json` は `artifacts/sudden_death_v2/ghost_revive/<case>/`。

実際に遊んで見るときは、デバッグ版で 2 人用「10問」を始め、プレイ中に Shift+F9（P1 が幽霊）・Ctrl+F9（P2）・Ctrl+Shift+F9（2 人とも）。

サドンデスの通し（`skygate_runtime.gd`）にも `ghosts=1|2|3` を足した：復活から始まり、帰還のあと決着演出の人形が「勝った元幽霊は体のまま・負けた人は幽霊」になっていることを確かめる。
