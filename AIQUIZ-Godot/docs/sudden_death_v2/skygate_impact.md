## 2. ルールの流れ（`SkyGateGame`）

```
gate（動いて選ぶ、8 / 6.5 / 5 秒）
 → 時間切れ：位置を止め、真下のパネルで正解かどうかを決めて gate_impact（判定はまだ出さない）
 → impact（IMPACT_TIME 1.3 秒：見せ方が「つき破る」動きを見せる。入力は効かない）
 → 判定：gate_pass（＋ out・decided / both_out）
 → pass（PASS_TIME 0.5 秒）→ 次のゲート（または round_clear・延長）
```

- `gate_impact` と `gate_pass` の中身は同じ（`panels`・`results`・`local`・`since`…）。正解かどうかの決め方（時間切れの位置・早い者勝ち）は変えていない。
- ゲート 1 枚の時間切れから次のゲートまでは 0.8 秒 → 1.8 秒になった。

## 3. つき破る動き（`SkyGateImpact`、時間切れからの秒）

高さは「紙の面から体の中心まで」。体は腹ばいで、お腹は中心の 0.24 m 下。

| | 正解（burst） | まちがい（boom） |
| --- | --- | --- |
| 0〜 | お腹が紙に当たって押し込む（へこみ最大 0.5 m） | 紙が大きくたわむが破れない（0.8 m）。紙が暗い赤に張りつめる |
| 0.30 | **紙が破れる**（穴・紙吹雪・フラップ、`door_correct`） | |
| 0.36 | | **はね返される**（白い輪・星・`wall_crash`）。体が回りながら上へ（お腹が紙を離れたら紙とは別に飛ぶ） |
| 0.30〜0.95 | 体が抜け、ボードは上へ 3.2 m 離れる | |
| 0.84 | | 一番高い所（約 4 m 上）で**爆散**（体がブロックにばらける・火の玉・星、`barrier_explosion`） |
| 0.92〜 | ドローンがボードを横へ運び去る（画の外へ出てから消す） | 同じ |
| 1.30 | **判定**：札「セーフ！」 | **判定**：札「ドカン！」・`door_wrong`・アウト／決着（2人ともなら復活へ） |

- だれかが正解なら、正解の人は落ちる点のまま（ボードが上へ抜ける）。2人ともまちがいなら、ボードはたわむまで押し上がって止まる。
- 時間切れの少し前（0.12 秒）からスロー（0.32 倍）、0.62〜1.15 秒で戻す。スローは雲・効果・マフラーの時計にかかる（ルールの時計は実時間）。
- **全員が正解でくぐるときは減速しない**（2026-10-23、ユーザーの指示「カメラの拡大をむやみに変えず、そのまま自然に減速せずに突破」）：`SkyGateImpact.time_scale(t, mode)` は ALL_BURST なら常に 1.0。ゲートの終わりは `_all_safe`（2 人とも正解のパネルの上）で見分け、スローも2人への寄り（`_push_weight`）も入れない。つき破る間（impact・pass）は画の距離を止めたまま（`_fit_topdown` を飛ばす）。誰かがまちがえるときだけ、これまでどおりスローと寄りで見せる。
- 近づき方（`_approach`）は最後の 0.9 秒をエルミートにして、届くときの速さを 4 m/秒に落とした（押し込みの初めの速さとつながる）。
- 爆散したブロックの中心は 1 秒かけて落ちる点の高さへ戻る（2人ともアウトの復活はそこで体が戻る）。
- 2人が同じパネルに当たったときのへこみは深い方（足すと深くなりすぎる）。選択肢の文字は枠の厚み（0.3 m）までしか沈めない。

## 4. 瞬間移動をなくした所（本戦の中）

| 前 | 今 |
| --- | --- |
| 判定の瞬間に G3（ボードの真下／斜め上）へカット | G2（見下ろし）から**クレーン**で G3_Impact へ（時間切れの 0.45 秒前〜0.35 秒後）。押し込むまでは少し上から（16°）、全員が抜けたらボードの下へ回って見上げ（−18°）、はね返る人がいれば少し上から追う（10°）。体（はね上がった人も）が画に入る距離を投影で求める。判定のあと 1 秒で見下ろしへ戻る |
| 2 枚目以降の頭に G4_Chain（真上から引く）へ切る | やめた（見下ろしのまま次のボードが下から来る） |
| 通りすぎたボードは次のゲートの頭で消える | ドローンが横へ運び去り、画の外（70 m）か 3.2 秒で消す。次のゲートが無いときの「次のボード」は下へ離れて海の下で消える |
| ROUND の着地：パラシュートを開いたら海の高さのセットへ**カット**（海が 20 m 下へ飛び、2人は着地台の 14 m 上から） | **切らずに降りる**：今の高さから、高ければ頭を下にして急降下（エルミート。2.4 秒まで）→ 60 m でパラシュート → 0.35 秒は落ちる速さのまま → 12 m/秒 → 2.2 m で引いて着地。海と着地台が下から上がってきて、体は最後の 20 m を実際に下りる（着地台の位置は今までと同じ：海＝落ちる点の 20 m 下）。カメラは空中の画から 1.2 秒で「追いかけ」（g5_follow）へ寄り、着地台が近づくと着地台のまわりを回る画（g5_landing）へ移る |
| 勝者の着地も同じカット | 同じ（勝者だけ）。幽霊は勝者の横から着地台の横の宙へなめらかに移る |
| 踊りの画（`extract_camera`）が着地の画と半径・高さ・回る向きがちがう | 着地の画から同じ向きに回り続け、1.5 秒で踊りの画の半径・高さへ寄せる |
| ラウンドの頭に海が 1150 m 下へ飛ぶ | 今の高さから 420 m/秒で寄せる（降下で水上機の場面が置いた高さから続く） |

- 見せ方のカメラは毎フレーム `cut=true` の連続した画を出す（寄せ方は見せ方が持つ）。降下から渡された直後は監督が 1.6 秒かけて寄せる（今までどおり）。
- 時間切れの知らせはルールのフレームの途中の刻みで出るので、時間切れの時刻をルールの `phase_clock()` に合わせ直す（`_sync_impact_clock`。直さないと最初のフレームで最大 1 フレームぶん先へ飛んだ）。
- Space で降下を飛ばしたときの白い閃光とカット（`_handover(true)`）は、ユーザーが飛ばしたときだけなので残した。

## 9. 時間制限をなくした・脱落を GTA 風のスローに（2026-10-25、ユーザーの指示）

指示（要旨）：「サドンデスの時間制限制をなくし、最初から問題 4 枚が用意されていて連続で答える形に」「無駄な UI を削ぎ落とす。
端の選んでる選択肢やセーフは要らない」「脱落演出は今のカメラの切り替えから、そのままの降りるカメラでぶつかったら GTA のように
画面がスローモーションになって爆散」。質問への答え：一定の速さで落ち続ける／4 枚は真下に一列＋ラウンドの頭に全体の引き／
