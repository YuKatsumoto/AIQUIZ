# GOSTRIDER の被弾：吹っ飛びのリアル化（計画）

ゴーストシャークの突進に当たった生き残り側が、今は「サメが体の中を通り抜け、体は固い板のまま滑って飛ぶ」。
これを、当たった部位が先に持っていかれて関節が曲がり、体が回り、地面で転がるような吹っ飛びにする。

> 状態：段階 0〜6 は実装済み（2026-11-06。6〜9 章）。そのあと操作ロックと横の上限を元の数値へ戻し、どの命中も床に落ちてから起き上がる見せ方にした（10 章）。段階 7（オンライン）以降はこれから。
> 見直し（2026-11-06）：サメの急ブレーキ・跳ね返り・曲がって去る動きはやめた。命中後、サメはヒットストップのあと同じ速さでまっすぐ進み、体を突き抜けてよい（4 章の 2）。

### めり込みの原因（段階 0 で確かめた）

1. **判定が遅い**：判定は「サメの中心が体から横 1.45 m 以内」。鼻先は中心の 3.3 m 前なので、判定が出た時には鼻先が体を 2.5〜3.3 m 突き抜けている。
   処理の順で 1 フレーム遅れるのも重なり、真ん中の命中では**命中の 4〜5 フレーム前から**サメの頭が体に入っている。
2. **当たったあとも直進する**：サメ（31〜52 m/s）が飛ばされた体（最大 18 m/s）より 2〜3 倍速く、そのまま体を追い抜く。
3. 体が物理で動かないので、当たっても形が変わらず、回りもしない（走りのアニメの姿勢のまま浮いて滑る）。

## 2. 方針

**「見た目は物理ラグドール、ゲームの判定は `game_state` の点」**にする。

- 海に落ちる・さくで止まる・操作ロック・オンラインの同期は、今どおり `game_state` の点が持つ。ラグドールは見た目だけ。
  ただし飛ぶ向き・高さ・PERFECT の速さは、決めたこと（4 章）に合わせてゲームの式も変える。
- 命中の瞬間、そのときのアニメの姿勢からラグドールを作り、**当たった点に衝撃を入れる**。当たった部位が先に飛ぶので関節が曲がり、全身が回る。
- ラグドールの胴は、ゲームの点へ**位置だけのゆるいばね**でつなぐ。回転は自由、位置は大きくずれない（オンラインでも同じ場所に見える）。
- 強さで 2 通りに分ける：ふつうは**空中で立て直して足から着地**、強い / PERFECT は**倒れて転がり、起き上がる**。

ほかの案（比べて外したもの）：Verlet（投げ縄の方式）は魂用でゲームの体へ移す作業がいる。手付けアニメは当たり方の変化が乏しい。

### 段階 3：吹っ飛びのラグドール
- ヒットストップの終わりに `_setup_ragdoll` で作る（予熱は試合の始めに済ませる）。帽子は頭へ付け替える（`_attach_ragdoll_hat`）。速い間は `continuous_cd` を入れる。
- 全身にゲームの初速を入れ、当たった部位へ追加の衝撃（当たった点で `apply_impulse`、上限つき）を入れる。
  - 胸・顔（今の狙う高さではこれがいちばん多い。鼻先は骨盤の約 0.85 m 上に来る）：上体が後ろへ反って首がしなり、
    脚が前へ振り出されて、後ろ回りに回りながら飛ぶ。
  - 脚に当たる：脚がすくわれ、上体がサメ側へ倒れて前へ回る（車にはねられた形）。
  - 腰・胸：くの字に折れて、後ろへ飛ぶ。
  - 肩・頭・横ずれ：ねじれて横に回る。
- 関節の追従（`omega_n`）は当たった瞬間ほぼ 0（脱力）。
- 胴のばね（位置だけ）：飛んでいる間は弱く、着地が近づくほど強く（ゲームの点とのずれを吸収）。
- 床で跳ねて転がる（反発・摩擦を調整）。海へ落ちたら、今の海の落下演出へ渡す。さく（チュートリアル・練習）にも当たる。

### 段階 4：強さで分けた戻り方（済み・2026-11-06。作りと結果は 7 章）
> 10 章で見直し：操作ロックは元の 0.25〜0.48 秒へ戻し、空中での立て直しはやめた（どの命中も床に落ちて起き上がる）。
- 分け方：**PERFECT または強さ 0.8 以上なら「転倒」、それ以外は「立て直し」**（0.8 は仮）。
- **立て直し**（操作できない時間は今より +0.2〜0.3 秒）
  1. 当たってから 0.25 秒は脱力して回る（関節が曲がる・体が回る）。
  2. そのあと 0.3 秒で胴の向きを立てる力と関節の追従を戻し、空中の姿勢（`Jump_Loop`）へ。回っている向きのまま回り切って起きる（逆回転で戻さない）。
  3. 着地の 0.15 秒前には足が下。着地は横の速さが 7 m/s 未満なら `Jump_Land`、それ以上なら `Roll`（仮）。
  4. 着地 + 0.15 秒で操作が戻る。ラグドールの姿勢からアニメへ 0.2〜0.35 秒で混ぜてラグドールを消す。
- **転倒**（操作が戻るまで、命中から合計 2.2 秒以内）
  1. 着地まで脱力のまま。着地で跳ねて、滑る間は転がる。
  2. 着地後の床の減速を強める（10 → 18 m/s²、仮）。PERFECT の速さを上げても、転がりが長くなりすぎないようにする。
  3. 横の速さが 2.5 m/s を切るか、命中から 1.5 秒たったら起き上がる。あお向けは `LayToIdle`（速め）。
     うつ伏せは寝返りしてから `LayToIdle`、または投げ縄の手続きの起き上がり（腕で押し上げる）を借りる（どちらが自然か段階 0 の絵で選ぶ）。
  4. 起き上がりが 8 割終わったら操作が戻る。
  - 合計 2.2 秒以内にするのは、次の命中が早くても約 2.5 秒後だから（起き上がり中に当たり続けるのを防ぐ）。
    それでも当たったら、その姿勢からもう一度ラグドールにする。
- 操作ロック（`external_control_lock`）は、どちらの戻り方でも「操作が戻る」時刻までにする。

## 4. 決めたこと（2026-11-05）

1. 被弾のあとの流れ：**強さで切り替え**。ふつうは空中で立て直して足から着地、強い / PERFECT は倒れて転がり起き上がる。
   → **見直し（2026-11-06）**：操作できない時間が長くサメが強すぎたので、操作ロックは元の数値へ戻す。空中で姿勢が戻るのは不自然なので、
   どの命中も床に落ちて転がり、自然に起き上がる（体の演出は操作ロックとは別に進め、動いたら切り上げる）。
2. めり込みの避け方：**当たり方で上 / 横を自動**。ヒットストップとサメの減速に加え、真ん中ははね上げ、横ずれはその側へはじく（ゲームの飛ぶ向き・高さも変える）。
   → **見直し（2026-11-05）**：段階 0 で、真ん中のはね上げはサメが大きすぎて成り立たないとわかった（1.5 章）。
   真ん中・斜めの命中は**サメが衝突で急ブレーキ**して、押し出された体だけが先へ飛ぶ形にする。体の飛ぶ向きは今のまま、横ずれの命中だけ当たった側へふる。
   → **再見直し（2026-11-06）**：**貫通してよいので、急ブレーキはやめる**。サメはヒットストップのあと同じ速さ・同じ向きで進み、体を突き抜ける。
   鼻先で当てる（段階 1）・ヒットストップ・横ずれのふり・ラグドールはそのまま。
3. 当たった瞬間の止め：**短いヒットストップ**（0.05〜0.08 秒。ゲームの時計は止めない）。
4. 横の上限 18 m/s：**上げて直す**（PERFECT で今より遠くへ飛ぶ）。
   → **取り消し（2026-11-06）**：サメが強すぎたので 18 m/s のまま。

## 5. 気をつけること

- 物理の暴れ：サメの速さ（〜50 m/s）を体にそのまま入れると飛び散る。衝撃は上限つきで、部位ごとの速さで入れる（死亡演出と同じ考え方）。
- 床の抜け：速い体が床を抜けないよう、吹っ飛びの間は `continuous_cd` を使う（イントロの降下と同じ）。
- 見た目とゲームのずれ：胴のばねが弱すぎると、海に落ちていないのに落ちたように見える。着地前にばねを強めて、点へ寄せる。
- ヒットストップと突進の終わり：サメが止まっていた分だけ進む距離は短くなるが、`ghost_charge_finished`・クールタイム・戻りのポータルの時刻は当たらなかったときと同じにする。
- 起き上がり中の再命中：合計 2.2 秒以内で防ぐ。起きたら、その姿勢からもう一度ラグドールにする。
- 予熱：命中の瞬間にラグドールを作ると初回に引っかかる可能性がある。段階 3 で測ると、作るフレームの重さは約 3 ms 増えるだけだったので、予熱はまだ入れていない。

## 7. 実装（段階 4、2026-11-06）

### 分け方と操作ロック（ゲーム側）
- `GhostHitContact.recovery_plan(power, perfect, 横の速さ, 縦の速さ)`：PERFECT か強さ 0.8 以上は**転倒**、ほかは**立て直し**。
  オフライン・ホスト（操作ロックを決める）と両方の画面の見た目が同じ式を使う。
- 操作ロック（`external_control_lock`）は戻り方で決める。前は強さだけで 0.25〜0.48 秒（空中で操作が戻っていた）。

  | 戻り方 | 操作ロック | 例 |
  |---|---|---|
  | 立て直し・着地は Jump_Land（着地の横の速さ < 7 m/s） | 滞空 + 0.15 秒 | 真ん中・強さ 0 → 0.78 秒、0.24 → 0.86 秒 |
  | 立て直し・着地は受け身の転がり（≥ 7 m/s） | 滞空 + 0.45 秒 | 真ん中・強さ 0.6 → 1.26 秒（真ん中は強さ 0.57 から、横ずれは 0.3 から転がる） |
  | 転倒 | 2.1 秒（ヒットストップと合わせて命中から 2.17 秒） | |

  滞空と着地の速さは「床から飛んだ」として計算する（重力 18、横の減速 10）。プロペラ帽子でゆっくり落ちるときは、着地より先にロックが切れることがある。
- 転倒した人は、操作ロックの間、床では横の勢いを 18 m/s²（ふつうは 10）で減らす（`QuizGameState.TUMBLE_GROUND_DECELERATION`）。
  `apply_external_impulse(..., tumble)` で立つフラグ `p1/p2_external_tumble` を見る（`is_external_tumbling_on_ground`。ロックが切れたら効かないので、
  リセットの場所ごとに消さなくてよい）。オンラインはスナップショット（`p1tb`/`p2tb`、スロットの動き `tb`）で届き、ゲストの予測（`NetPredictor`）も同じ条件で減らす。
- メニューの背景の実演（`menu_ghost_ride_director.gd`）は、ロックを前と同じ最大 0.48 秒に抑える（メニューにはラグドールも起き上がりもない）。

### 見た目（`PlayerController`）
被弾の段：**止め**（ヒットストップ）→ **脱力**（物理）→ **混ぜ**（物理の姿勢からアニメの姿勢へ）→ **アニメ**（ふだんの体に重ねる）→ ふだん。
- **混ぜ**：体を止めて（キネマ）今の姿勢を覚え、毎フレーム「アニメの姿勢」へ寄せて置く（`_begin_ghost_hit_blend`・`_pose_ghost_hit_blend`）。
  手足は親の体からの回転と関節の位置を混ぜて、関節でつながったまま動かす。胴は回っている向きのまま回り切る道を選ぶ（逆へ戻すのは 4.4 rad より多く要るときだけ）。
  始めの回る速さは物理で回っていた速さにそろえる（エルミート曲線）。混ぜ終わると物理の体とアニメの部品がぴったり重なるので、そこで入れ替える（見た目は変わらない）。
- アニメの姿勢は、隠れている部品に UAL のクリップを当てて作る（`_apply_ghost_hit_pose`）。操作が戻ったら 0.25 秒でふだんの動きへ戻す（向きも一緒に戻る）。
- **立て直し**：当たって 0.25 秒は脱力して回る → 着地の 0.15 秒前までに空中の姿勢（`Jump_Loop`）へ混ぜる（0.15〜0.35 秒）→ 着地で
  `Jump_Land`（1.4 倍速。飛ばされてきた側＝サメを向いて後ろへ滑る）か `Roll`（0.75 秒で前転。滑る向きへ）。
- **転倒**：着地まで脱力。体もゲームと同じ重力で落ち（縦はゲームの点へ寄せない）、床で転がる。床に着いたら胴を横だけゲームの点へ強めに寄せる（0.35 → 0.8）。
  操作が戻る時刻に起き上がりが 8 割済むよう、`LayToIdle`（UAL2、1.5 倍速）を始める（着地から 0.3 秒は必ず転がる）。
  寝た姿勢へは 0.3 秒で混ぜ、寝ている向き（骨盤から頭）に起き上がりの姿勢を合わせ、起き上がりながら前（ゲームの向き）へ向き直る。
- 起き上がりの途中で床の端から落ちたら、物理の脱力に戻して落とす。海へ落ちる体は脱力のまま（今までどおり落水・脱落の演出へ）。
- 吹っ飛びの途中でまた当たったら、今の姿勢から飛ばし直す（アニメの段なら、その姿勢でラグドールを作り直す）。

## 10. 数値を元に戻し、床に落ちてから起き上がる見せ方へ（2026-11-06）

実機で遊ぶと、操作できない時間が長く（立て直し 0.78〜1.32 秒・転倒 2.1 秒）、PERFECT がさらに遠くへ飛ぶので、サメが強すぎた。
また、操作ロックを短くすると空中で操作が戻るので、空中で姿勢が戻る見せ方になり、それも不自然だった。

### ゲームの数値（元に戻した）
| 項目 | 段階 4〜6 | 今 |

| 横の上限 | 21 m/s | **18 m/s**（`QuizGameState.EXTERNAL_IMPULSE_MAX_SPEED`） |

### 体の見せ方（`PlayerController`、`GHOST_HIT_ALWAYS_FALL`）
- どの命中も空中では立て直さず、脱力したまま落ちて床で転がり、滑りが落ち着いたら起き上がる（`LayToIdle` 1.5 倍速）。
  着地から 0.3 秒は必ず転がり、横の速さが 2.5 m/s を切ったら（遅くとも着地から 0.9 秒で）起き上がる。起き上がりが 8 割済んだら 0.25 秒でふだんの動きへ。
- 体の演出は操作ロックとは別の時計で進める。操作が戻ったあと、着地してから**自分で動いた・跳んだら切り上げる**：
  寝ていれば 0.15 秒で起き上がりの途中（45 %）の姿勢へ移り、0.18 秒でふだんの動きへ（起き上がりの途中なら、すぐ 0.18 秒で）。
  「自分で動いた」は、ゲームの点の動き（横と、床に対する前後）から吹き飛ばしの速さを除いた分が 1.5 m/s を超えたとき。
- 着地の音と砂ぼこりは、体の演出とは別に「吹き飛んだあとの最初の着地」で出す（`_ghost_hit_landing`）。どの命中も「ドサッ」と転がりの音。
- `GHOST_HIT_ALWAYS_FALL = false` にすると、段階 4 の「空中で立て直して足から着地」に戻る（操作ロックが着地より長いときに向いた見せ方）。
