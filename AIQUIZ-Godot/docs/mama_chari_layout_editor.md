# ママチャリ・ギミック配置ツール

Godotのファイルシステムから `res://tools/bike_course_layout_editor.tscn` を選び、
「現在のシーンを実行（F6）」で起動します。

## 操作

- 左の一覧から「コーン／水たまり／段差／バリケード」を選択します。
- 道路を左クリックすると、0.5m × 1mグリッドへ配置されます。
- 配置済みギミックは左ドラッグで移動できます。
- 右クリックで選択し、Deleteキーまたは「削除」で消せます。
- X/Z欄から正確な座標も入力できます。
- 「複製」「全ギミックをクリア」「標準配置」が使えます。
- 「保存」または Ctrl+S でゲームへ反映します。

保存先は `res://data/bike_course_layout.json` です。同時にローカルの
`user://bike_course_layout.json` にも保存され、次回プレイ時に自動読込されます。

コーン・段差・バリケードは転倒、水たまりはスリップを発生させます。

## 3Dエディター

`res://tools/bike_course_3d_editor.tscn` をF6で起動します。2Dエディター上部の
「3D編集」から切り替えることもできます。

- 画面内の道路・スタート／ゴール門・分岐装飾・坂・障害物は、ゲーム本番と同じ `BikeCourse` を直接プレビューしています。
- 「障害物・ギミックを配置」では、3D道路を左クリックして配置し、配置済みギミックをクリック選択できます。
- 障害物を選択すると3Dギズモが表示されます。赤X・青Zの矢印は軸移動、黄色の中央ハンドルはXZ自由移動、黄色のリングはY回転です。
- 緑Y軸は道路への自動接地を示すロック軸です。段差のX軸も道路全幅を使うためロックされます。
- 回転は5度刻みで保存され、ゲーム内の見た目と障害物の当たり判定へ反映されます。
- 「坂・地面の高さを編集」では、道路を左クリックして高さ制御点を追加します。
- 高さ制御点を選択し、Zと高さYを入力すると道路がその場で変形します。
- オレンジ色の「接地テスト」走者は、指定したZ位置の地面高と坂角度へ追従します。
- WASDで視点移動、Shiftで高速移動、Q/Eで上下移動できます。
- 右ドラッグで視点回転、マウスホイールでズーム、選択後Fキーで注視、Homeでコース全体表示ができます。
- Deleteで削除、Ctrl+Sで保存します。スタートとゴールの高さ点は削除できません。

保存した高さはゲーム内の道路、自転車、乗車中ランナー、配置ギミックへ共通反映されます。
