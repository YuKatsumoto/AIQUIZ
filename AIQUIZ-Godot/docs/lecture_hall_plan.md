# 設定ホール「地下神殿の講義室」制作計画（126 項目）

2026-10-04 作成。チェックページ（https://claude.ai/artifact/GKY7fWF7Q75rQ9n2WBBrDK）で選んだ 126 項目
（外したのは 72・74・77・78・103〜107）を、すべて★の品質で作るための段取り。番号はページの番号。
進め方: 小物と動きは Blender（ユーザーのライブ Blender、`assets/settings_hall/source/blender/`）で作り、
動きの組み合わせ・黒板の描画・授業の進行は Godot（`scripts/world/settings_hall/`）で作る。

## 品質の基準（全項目共通）

- 小物は実写の質感: 形は実物の寸法と作り（面取り・継ぎ目・ねじ・縁）を持ち、材質は Blender の手続き的な PBR
  （木目・塗装・アルミ・ホーロー・フェルト・紙・陶器・ゴム）を画像に焼いて glTF で運ぶ（色・ORM・法線）。
  ラベルや表紙の文字は Noto Sans JP で描いた画像を材質に入れて焼く。
- 大きさ: 世界はゴドーくん（身長 1.62 m、手は直径約 0.15 m のミトン）に合わせて実物の約 1.8 倍
  （`SMALL_SCALE`）。机・椅子・黒板など今の配置の寸法は変えない。
- 動きは Blender のアクション（NLA トラック）で作り、Godot が状況に応じて選んでつなぐ。
  ぬいぐるみは頭と胴が一体なので体は `Body` ごと剛体で動かし、曲げるのは腕と脚だけ（今の決まりのまま）。
- 各段階の終わりに: Blender の Cycles 確認レンダー → GLB 書き出し → Godot で実画面を撮って確認 → コミット。
