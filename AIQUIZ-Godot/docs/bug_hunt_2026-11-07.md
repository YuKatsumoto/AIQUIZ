# バグ探しの結果（2026-11-07）

提出前の総点検の記録。コードの読み直し（分野ごとに 12 本）、テストの一括実行、オンライン対戦の実機テスト（ローカルの中継サーバーで 2 つ起動）で探した。
直したものには、可能なかぎり「直す前は落ち、直したあとは通る」ことを確かめたテストを付けている。

### 小さい

- メニューを開くたびに効果音の音量が 0.1 刻みに丸められて保存される（`main_menu.gd`）
- 設定ファイルと出題履歴を直接上書きしていて、途中で終了すると壊れる → 一時ファイルに書いて置き換え（`game_manager.gd`、`buffered_provider.gd`）
- 帽子を変えてすぐ閉じると保存されない（`game_manager.gd` `_notification`）
- カスタマイズで選んだばかりの踊りが、壁速度タブで試しても踊らない／はじめて開いたとき P2 が帽子なし（`customize_settings.gd`）
- 戦績の記録を、クリア直後に「もう一度」を押すと 0 点で残す（`match_reel.gd`）
- 結果画面で、照明の高さを読むために毎フレーム重いデバッグ用の情報を作っていた（`result_ceremony_director.gd`）

## 直していないもの（判断が要る・影響が小さい）

- **ローカル 2P の P2 のジャンプは右 Ctrl だけ。** 右 Ctrl のないキーボードでは 2P 実践コースのジャンプの練習で進めない（一時停止からタイトルへは戻れる）。キー操作の仕様に関わるので変えていない。
- **60fps 上限と 144Hz などのモニター。** VSync があると 1 枚の表示時間がそろわず、わずかにカクついて見えることがある（標準を 60fps にした指示どおり）。
- オンライン：ホストが VS カットインで抜けて開始の合図が失われると、ゲストに出口がない（まれ）。名前・スキンを変えても、つなぎ直さないと相手に古い見た目が出る。結果発表の前後の細かい食い違い。
- AI まわり：ストリーミングではバッチごとの正解チェックが動かない（エンドレス）。端末の時計が大きくずれていると許可証を取り直し続ける。送信待ちの列の 1 件が拒否されると後ろが止まる。共有バンクの解説が空で上書きされる件はサーバー側（`mergeCandidate`）も直す必要がある。
- 2P で正解の金色の演出がいつも P1 の位置に出る（見た目だけ）。
- 一時停止の画面などからキーボードのフォーカスが裏のメニューへ抜ける（Tab で）。
- 結果画面のカメラの計算が毎フレーム重い、エンドレスで段数ごとのメッシュがたまる（性能）。

## テストの一括実行で落ちたもの（今日の変更が原因ではないと確かめたもの）

- `ghost_hud`（溜め撃ちのメーター）、`duo_hud`（得点の演出）：単独でも落ちる。今日の変更を戻しても同じ。ゴーストシャークまわりの未コミットの作業（ヒットストップなど）と関係ありそう。
- `emote_push`、`player_vault`、`wall_recoil`、`wall_world_border*`、のこぎり関係（`saw_*`）：今日触っていない処理。未コミットの作業中の変更と関係ありそう。
  - `saw_chase` の単体テスト（「開始の猶予中に下がると、のこぎりに捕まる」が 24〜120fps のすべてで失敗）は、`game_state.gd` に入れた今日の修正を外しても同じ結果。ローカル 2P の本編に関わるので、作業中の変更と合わせて確かめてほしい。
- 練習コースの smoke テスト：メニューに「練習」ボタンがある前提のまま（今のメニューにはない）。
- `max_fps_settings`：製品版からは開けない設定画面の高さの検査。
- `preload_progress`：テストの環境で APP_SECRET を外したため（AI が使えない扱い）。
- `menu_led` など：画面なしで動かしたため。
- サドンデス系のテストは、製品版で無効なので流していない。
