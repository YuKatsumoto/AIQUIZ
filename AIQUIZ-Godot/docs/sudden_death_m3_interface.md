# 地下神殿の本制作（マイルストーン3）：部品の取り決め

`docs/sudden_death_underground.md` 第6章を、Blenderの制作とGodotの組み立てで分担するための取り決め。両方がこの値に従う。変える場合はこのファイルを直してから、もう一方に知らせる。

## 座標

- Godotの単位（m）、Y上。部品の床面は部品内の y = 0。シーンは部品を y = `SuddenDeathLayout.FLOOR_Y`（−1.2）に置く。
- 空間の幅は x = −45〜+45。天井の下面 y = 18、天井スラブの厚さ1m（上面 y = 19）。通路（遊べる範囲）は内側の柱の内面 x = ±11.9 の間。
- 区画（bay）は長さ15m。区画 k の中心はワールド z = 15k（k = −1〜13、15区画）。部品内の z は −7.5〜+7.5。
- 各区画には柱の行がちょうど1つあり、部品内の z = 0〜7（柱は幅2m（x）×奥行7m（z）×高さ18m、中心 x = ±12.9 / ±25.8 / ±38.7）。行の明るさの番号は区画の番号と同じ（行0 = 区画 k = −1、行14 = 区画 k = 13）。
- 水門列（別に作る。部品には含めない）は、1区画おきの内側の柱の上流面（部品内 z = 0）に立つ。ワールド z = 30, 60, …, 180。（2026-10-03：本戦を早押し水没リフトに作り替え、水門列は使わなくなった。代わりに2本のリフトのタワーが z = 9、x = ±4 に立つ。`sudden_death_underground.md` 第19章）

- ノード名：メッシュは `CIS_*`。ライトの位置は空のノード `CIS_Light_<種類>_<番号>`（種類は Flood / Amber / Window）で、Godotの −Z が光の向き。色・明るさ・範囲は `cistern_layout.json` に書く。
- 材質（glTFの材質名）：`CIS_Concrete`（壁・柱・天井・梁）、`CIS_Floor`（床）、`CIS_SteelPaint`、`CIS_Galvanized`、`CIS_Grate`（透過）、`CIS_LampLens`（発光）、`CIS_Sign`。ほかに必要なら追加し、README に書く。
- UV0 は材質のテクスチャ用（繰り返し。コンクリートは1UV = 2m）。UV2 は部品ごとの重ならないライトマップ用。

## テクスチャ（`assets/environment/underground_temple/textures/`）

- 繰り返しのPBR（2K）。Blenderの手続き材質から焼く（ダウンロード・購入・生成した画像は使わない）。`concrete_{albedo,normal,orm}.png`（型枠の目地0.9×1.8m、留め具の穴、面取り、打ち継ぎ、白華と錆の垂れ）、`floor_{albedo,normal,orm,wet}.png`、`steel_*.png` など。1m周期のディテール法線。
- 部品ごとの焼いた光（UV2）：`<部品名>_light.png`。RGB＝その部品の静的な照明による照度（間接光1回を含む）を (E / light_max)^(1/2.2) で符号化（縦穴 `assets/environment/shaft_descent` と同じ）、A＝焼いたAO。`light_max` は `cistern_layout.json` に部品ごとに書く。区画は同じ区画を3つ並べて真ん中を焼き、隣の照明の光も入れる。両端は区画を1つつないで焼く。
- 床の水位の跡（床から1.5m）、黒ずみ、薄い藻は、材質のマスクか焼いた光の側に入れる。
- デカールの台紙：`cistern_decals.png`（アルベド＋アルファ：白華、錆の垂れ、水跡、配管の漏れ跡）と `cistern_decals_normal.png`。台紙の配置は `cistern_layout.json`。

## 予算

- 空間全体が画面に入っても150万三角形以内（区画1つは6万以内）。
- ライトマップは区画が2048²以内、両端が4096²以内。テクスチャ全体はVRAMで150MB以内（BC7）。

## Godotのシェーダーとの約束（Godot側が作る）

- 舞台の静的なメッシュ：アルベド(UV0) ×（焼いた光(UV2) × light_max × 区画の明るさ ＋ わずかな環境光）＋ 反射。実ライトは舞台には当てない（静的メッシュは描画レイヤー11だけに置き、実ライトの cull mask から外す）。人物・水門列・波・破片は実ライトで照らす。
- 区画の明るさ：`global uniform sampler2D cistern_row_light`（32×1、最近傍。R = 区画 k の明るさを画素 k + 1 に）と `global uniform vec4 cistern_row_grid`（x = 区画 k = −1 の中心 z（−15）、y = 15、z = 区画数、w = 未使用）。区画の番号はインスタンスのワールド z から求める。両端は端の区画の明るさを使う。
