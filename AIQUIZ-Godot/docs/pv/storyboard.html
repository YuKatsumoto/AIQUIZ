コンセプト

最初の壁で、遊び方がわかる。

このゲームは「迫ってくる壁の、正解のドアを突き破る」遊びです。PVでも同じことをします。最初の壁はAIが作った本物の問題（かけ算）で、2人が答えを選んで突っ込むところから遊び方を見せます。そのあとは実際のゲーム画面の流れで、AIが問題を作るところ・ルール・2人対戦を見せ、ゲーム本体のロゴの登場演出で締めます。

こうすると、ルールの説明カットがいりません。最初の壁（Q1）を見た時点で遊び方が分かります。Q1の看板はゲームの壁と同じ書き方にしました（頭に「Q1」を付けると、引きの画で「Q17 × 8」と読めるため）。

  • トーン：明るく、テンポは速く。失敗（ゴツン・サメ）で笑わせて、最後はスカッと終わる。
  • テロップは要所に1カット1行。絵だけでは伝わりにくいAIの仕組みとルールを、短い言葉で言い切る。問題の壁が主役のカットには乗せない。
  • ゲームの中の文字（問題の壁・ハート・PERFECT・VSカットインなど）はそのまま生かす。ナレーションは入れない。
  • 映すのは今のゲームにある機能だけ。止めている機能と、10月8日より前の映像は使わない。

S01〜S07（実際のゲームで撮影）

S01〜S07（34.67秒、18.5小節）の通しです。10/19に今のゲーム（TESTOPIA）で撮り直しました。本物のゲームを動かして撮り、ロゴはゲーム本体の登場演出をGodotで書き出したもの、テロップと閃光はAfter Effectsで重ねました。撮影中に鳴った効果音を、ゲームと同じ音量・同じ時刻に置いています（ヘリの音は編集で置いたもの）。曲は10/20にSunoで作った「TESTOPIA PV BGM - Game Show 70s」を、手を加えずにS03のタイトルから流したもの（下の「音」）。

  • 壁が空から落ちる：ゲームのプレビューの壁と同じ落ち方（2乗の加速・0.55秒）で着地し、潰れて戻る。土ぼこり・揺れ・観客のどよめき。2人はのけぞる。
  • Q1：「【かけ算】7 × 8 ＝ ？」の「56」（青・正解）と「54」（赤）。問題集の算数2年の問題で、2択の誤答は6 × 9と取り違えやすい54にした。
  • 演技：2人がドアを1拍ずつ見比べ、P2が指さして踊りながら「54」へ。ゴツンで脱落したP2をP1が指さしてダンスで煽り、2秒後にP2が爆散する。P1は「56」を踊りながら突き破る。上乗せの演技はUALのクリップ。
  • カメラ：背中越しのアップ、前から2人の顔、横から2人を一緒に、低い追従、壁の向こう側。人の位置を毎フレーム追わず、時間で決めた動きだけにして揺れをなくした。

音

BGMは選んだ曲をそのまま流し、ゲームの効果音を主役にします。曲に合わせてカットを切ったり、曲を編集したりはしません。

BGMの条件

  • 曲は「TESTOPIA PV BGM - Game Show 70s」（Suno、約133 BPM・69.2秒）をそのまま使う。最初に選んだ「Game Show」（83.6秒）と同じ楽器構成で、PVに収まる長さで作り直したもの。カット・テンポの変更など、曲には手を加えない（10/20に決定）。
  • 音ハメ（カットや効果音を曲の拍・展開に合わせること）はしない。絵コンテの小節と拍は、カットの長さの目安として残す。
  • 曲はS03でタイトル（TESTOPIAのロゴ）が出はじめるところ（PVの15.93秒、PVフレーム957）から流す。S01〜S02（Q1の壁）は効果音と観客の声だけ。
  • 曲を最後まで流し、曲の終わり（PVの85.1秒）でPVも終わる。カットの長さは曲に合わせて配り直した（v1.2：S06・S07・S09・S16・S17・S18・S20・S21を長く）。

ミックス

  • テロップは補足で、効果音が主役。BGMは一定の音量で効果音の下に敷く（曲の中の音量は変えない）。テロップの出入りに音は付けない（効果音とぶつかるため）。
  • 効果音の優先順：ドアの破壊 ＞ 激突 ＞ 噛みつき・水しぶき ＞ ドラムロール・WIN ＞ ヘリ・ジェット。
  • 仕上がりはピーク −1 dBFS 以下。全体の音量は一定の倍率だけで合わせる（自動で音量をならす処理は使わない）。

映像の見せ方

テロップは、絵だけでは伝わりにくいこと（AIの仕組みとルール）に1カット1行で使います。何が起きたかは絵の流れ・カメラ・音で伝え、テロップはそれを言葉で確かめる役です。

テロップの決まり

  • 1カット1行：本文は14字前後まで。補足を付けるときは小さい文字で1行だけ。要のことばは黄色にする。
  • 読める長さだけ出す：拍の頭で出し、カットの切り替えで消す。1小節（1.88秒）のカットは本文だけにし、補足は2小節以上のカットに付ける。命中・噛みつき・爆発の瞬間には文字を残さない。
  • 見た目をそろえる：書体はロゴに合う太いゴシック（Dela Gothic One相当）、白い文字に紺のふち。位置は左下（下から11%）が基本で、HUDや看板とぶつかるときは上の中央に移す。タイトルセーフ（外周5%）の内側に置く。
  • 出し方：0.2秒で下から押し上げて出し、0.15秒で消す。カットごとに違う動きは付けない。
  • 乗せないところ：問題の壁が主役のカット（S01・S02）、サビの頭のドアの突破（S09の中）、画面の文字で足りるカット（S05）。

映像の見せ方

  • 文字はゲームの中にも置く：問題の壁、設定画面、「問題を準備中」、ハート、PERFECT、VSカットイン、スコアタワーの式。Q1（本物の問題）は、壁の看板とドアに書く。
  • 1カットに見せ場は1つ：1秒で何が起きたか分かる構図にする。主役は画面の中央1/3に置き、テロップの場所をあけておく。
  • カメラ：ローアングル、壁の向こうからのリバースアングル、横からの追従。突破や命中の瞬間だけスピードランプ（0.5倍 → 等速）。
  • つなぎ：動きの向きをそろえてつなぐ（ドアを突き破った向きのまま次のカットへ）。場面転換にはゲームのワイプ（ドア・ハーフトーン・稲妻・S03の黄色い帯）を使う。
  • 音が説明役：「ブー」「ガシャン」「噛みつき」「歓声」で何が起きたかを伝える。効果音は曲より前に出す。笑いどころは一瞬の無音で間を作る。
  • HUD：情報になるときだけ出す。S09は2人の対戦カード・ハート・GHOST RIDERの案内をゲームのまま見せる。ほかのカットでは消す。
  • 作品説明に回すこと：AIの名前（Gemini・Claude）や、問題を作ってチェックする流れの細かいところ。

撮影

台本どおりにゲームを自動で操作して撮ります。画面録画と違ってフレームが落ちず、同じ絵を何度でも撮り直せます。S01〜S03（v3）の撮影の仕組みを土台にして、テイクごとの台本を足していきます。

撮り方

  • v3と同じく、Godotを固定のフレームレートで動かし、1フレームを8回に分けて進めて重ね、1920×1080・60fpsの連番で保存する（tests/pv_capture/pv_take_base.gd の上にテイクごとの台本、tools/pv/merge_subframes.py）。
  • 効果音は撮影中に鳴ったキュー（cues.json）から、ゲームと同じファイル・音量・時刻で置き直す（tools/pv/mix_audio.py）。
  • 2人の動きが自動操作で安定しないカットは、実際に2人で遊んで画面録画する。

PV撮影のために作るもの

  1. 撮影の土台：pv_v3_runtime.gd を、共通の部分（起動・画質・HUDを隠す・設定を汚さない・キュー・演技の上乗せ・書き出し）とテイクごとの台本に分ける。（共通の土台 pv_take_base.gd を作り、S04〜S07はその上で撮った。v3と演技の上乗せはまだ）
  2. 問題の差し込み：Q1（本物の問題・2択）。（済み）
  3. 問題の固定：実際にAIが作った問題（offline_bank.json）から選んで流し、撮り直しても同じ問題が出る。（S06・S07で済み）
  4. PVカメラ：壁の正面固定、見上げ、刃越し、サメの追従（「走って答える」の章はゲームのカメラのまま）。（背中越し・前から・横から・壁の向こう・壁の正面固定・見上げ・上空から下がるドリーは済み）
  5. 壁を空から落とす演出を10枚に広げる（S06）。（済み：今のゲームの準備中の演出がそのまま使えた）
  6. カットごとのHUDの表示切り替え（ハート・PERFECT・準備中カウンター）と、UIありで撮る経路（S04・S20）。（スロー・準備中カウンター・UIありで撮る経路（S04）は済み）
  7. 2人ぶんの自動操作：チップソーからの逃げ、ゴーストシャークの命中、スコアタワーまでの通し。

問題の差し込みはPV撮影のときだけ有効にし、ゲーム本体の遊び方は変えない。
