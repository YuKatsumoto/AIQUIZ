# PV S01–S03 プリビズ仕様（Scene Passport）

Blender 5.1.2 のライブ画面で作るプリビズ（実寸のブロックアウトとカメラワークの検証）。
ゲームの実寸は Godot の定数から取った値（調査メモは本文の末尾）。

## SCENE

- intent：PVの冒頭3カット（S01〜S03、0:00.00〜0:07.50）のカメラ・動き・タイミングを、ゲームと同じ寸法で決める
- deliverable：
  - `docs/pv/previz/AIQUIZ_PV_S01-S03.blend`
  - カットごとのプリビズ動画（S01・S02、1280×720・60fps）と確認用のコマ
  - カメラの動きをGodotの座標で書き出したJSON（PV撮影の仕組みがそのまま再生できる形）
- units：メートル。軸は右手系・Z-up
- 座標：**Blender (X, Y, Z) = Godot (x, −z, y)**。床の上面は Z = −1.2（Godotのまま）。走る向き（Godot +Z）は Blender −Y
- render：EEVEE、1280×720、60fps
- frame range：1〜450（S01 1〜225、S02 226〜337、S03 338〜450）。1拍 = 28.125フレーム、1小節 = 112.5フレーム
- dynamic：yes

## HIERARCHY

- `ENV`：コンベア、レール、海、観客席
- `WALL_Q1`：Q1の壁（梁・柱・ドア・看板・文字）。親 `RIG_wall_Q1`（壁ごと動かす空のオブジェクト）
- `HERO`：P1（ブロックマン）。親 `RIG_P1`
- `DEBRIS`：青ドアの破片20個
- `CAM`：`CAM_S01`（＋ねらい `CAM_S01_target`）、`CAM_S02`（親 `RIG_wall_Q1`）
- カメラの切り替えはタイムラインのマーカーで行う

## SHOT

### S01「Q1の壁が迫る」1〜225f（3.75秒）

- `CAM_S01`：P1の膝の高さ（Z −0.75）、背中越し。焦点距離 24mm（横の画角 約74°）
- 動き：P1の後ろ 2.6m → 1.6m へ寄りながら、P1の左右の動きを遅れて追う
- P1：最初は中央（X 0）で走る。2小節目の頭（114f）で、画面左の青いドア「AI」へ 0.46秒で横に移る（決断が見える）
- 壁：PVでの速さ 3.2m/s（ゲームの範囲 1.8〜3.9 の中）。スタート時は P1 の 12.5m 先
- 終わり：問題文が読める大きさで、P1が青いドアの正面に入った所で S02 へ切る

### S02「AIのドアを突き破る」226〜337f（1.875秒）

- `CAM_S02`：壁といっしょに動く（ベルトの座標に固定）。壁の向こう側 4.5m、高さ Z −0.4、X +3.3（青いドアのほぼ正面）、焦点距離 20mm。裏から見るので青いドアは画面の右側
- 228f（小節の頭から2フレーム後）に突破：破片20個がカメラに向かって飛ぶ
- スピードランプ：突破からゲーム時間で 0.3秒を 0.5倍、その後 0.15秒かけて等速へ戻す
- 壁はゲームどおり 0.28秒（ゲーム時間）でフェードアウト

### S03「ロゴのジングル」338〜450f（1.875秒）

- After Effects。タイトルロゴのコンポ（1240×960・60fps・6.15秒）を、0.35〜4.622秒（ベルトが出てから斜め線が付くまで）だけ 3.5倍速で使い（約1.22秒）、残り約0.65秒は完成したロゴを止めて見せる
- 背景は S02 の最後の絵をぼかして暗くしたもの

## LOOK

- 色はゲームの値：床 (0.40, 0.41, 0.42)、壁 (0.5, 0.5, 0.5)、青ドア (0.10, 0.60, 0.95)、赤ドア (0.90, 0.15, 0.10)、看板 (0.09, 0.17, 0.36)、P1 胴 (0.95, 0.55, 0.20)
- 文字は白に暗い縁取り。書体は BIZ UDゴシック Bold（ゲームの NotoSansJP の代わり）
- 背景は空色の World

## LIGHTING

- 晴れた昼。太陽光1つ（前方やや斜め上から、カメラ S01 から見て逆光気味にならない向き）と、空の環境光
- プリビズなので、ライトは形と奥行きが読めることだけを目的にする

## MOTION

- 60fps、1〜450f
- S01：壁の接近（等速）、P1 の走り（2.4歩/秒の腕と脚の振り）、114f からの横移動、カメラの寄り
- S02：突破（228f）、破片の飛び、壁のフェード、スピードランプ
- 休み：S02 の最後で破片が落ち着き、S03 へ

## ACCEPTANCE

- 構造：寸法がこの表と 1cm 単位で合う。名前の重複が無い
- 動き：S01 の最後で P1 が青いドアの正面にいる。228f で突破し、破片が画面の手前へ抜ける。カメラが P1 を見失わない
- 見た目：S01 の終わりに問題文と「AI」「せんせい」が読める。S02 で P1 と破片が主役として読める

## 調査メモ（ゲームの実寸の出どころ）

- 壁：`scripts/world/quiz_wall.gd`、`scripts/world/stage_constants.gd`、`game_tuning.gd`
- 床・海：`stage_constants.gd`、`stage_environment.gd`、`conveyor_rails.gd`
- 壁の速さ：`scripts/core/game_state.gd` の `_recalc_wall_speed`（典型 2.9m/s）
- プレイヤー：`scripts/world/player_controller.gd`、カメラ：`scripts/world/camera_controller.gd`
- 破片：`quiz_wall.gd` の `break_door`（20個、mass 0.6、重力 ×1.8、初速 vz +8.3〜25 / vy 2.5〜10.8 / vx ±8.3、1.5秒後に1秒で縮んで消える）
- 正解時：壁全体が 0.28秒でフェード、画面揺れ 0.22、緑のフラッシュ
