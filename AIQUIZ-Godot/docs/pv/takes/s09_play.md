# テイク s09_play（S09 を人が遊んだ試合で撮る）

2026-10-22 夜、ユーザーの指示で足した。台本 `s09` の自動の動きの代わりに、**2 人がキーボード 1 つで遊んだ試合**を S09 に使う。
遊んでいる間に押したキーをコマごとに記録し、同じキーを同じコマで送り直して、本番の画質で撮り直す（台本は `tests/pv_capture/pv_s09_play_runtime.gd`。
台本 `s09` の上に書いた。問題・乱数・見た目・ゲームの設定は `s09` と同じ）。

## 手順

1. **記録**（人が遊ぶ）：`tools/pv/record_s09_play.cmd` をダブルクリック（引数に記録の名前。既定 `s09_play_rec`）。中身は次と同じ。
   ```
   Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1920x1080 --fixed-fps 60 --script res://tests/pv_capture/pv_take_bootstrap.gd -- take=s09_play mode=record quality=ultra tag=s09_play_rec
   ```
   窓が実時間の 1 秒 60 コマで動く（ultra で 58 コマほど）。絵は保存しない。ボス壁を突き破った 3 秒後（2 人とも脱落したときも 3 秒後）に
   ひとりでに終わり、`artifacts/pv_capture/<名前>/inputs.json` に押したキーと毎フレームのゲームの状態の要約を書く。
2. **流し直し**（本番の画質）：
   ```
   Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1920x1080 --fixed-fps 60 --script res://tests/pv_capture/pv_take_bootstrap.gd -- take=s09_play mode=replay inputs=s09_play_rec quality=ultra tag=s09_play_frames
   ```
   `sub=1` だけ（遊んだときと同じ 1 秒 60 コマで進めないと、押し合いの決着などがずれて別の試合になる。動きのブレは付かない）。
   幽霊がサメに乗ったあとの右下の小窓は隠す（`s09` の v1.8 と同じ。`wipe_keep` で出す）。受け取ったキーと毎フレームの状態を記録と比べ、
   違えば `failures` に書く（`report.json` の `play.replay`）。
3. 通しへ：`artifacts/pv_capture/s09_play_frames/` を `pv_master.py` の S09 の部分に使う（遊んだ試合に合わせて部分の切り方とテロップを決め直す）。

## 遊ぶ人へ

- 窓の左上が「準備中…」の間はキーを押さない。「● REC」に替わったら Enter でスタート。
- P1：A・D で移動、Space でジャンプ、1・2・3 でエモート（ホースダンス・シリーダンス・YMCA）。
- P2：←・→ で移動、右 Ctrl でジャンプ、8・9・0 でエモート（ランニングマン・ウェーブヒップホップ・ヒップホップ2）。
  幽霊のサメになったら ←・→ で照準の輪を動かし、右 Ctrl を長押しして溜め、放して体当たり（輪とメーターが黄色のうちに放すと PERFECT）。
- 押し合い：横に並んで体が触れたら、相手のほうへ向かうキーを押して踏ん張り、そのキーをいったん離してすぐ押し直すと一押し。
- 遊んでいる間はほかの窓を触らない（フォーカスが外れるとキーが離された扱いになり、流し直しと合わなくなる）。Esc（一時停止）は効かない。
- PV に入れたい流れ（絵コンテ v1.9 の S09。10/22 夜、ユーザーの指示で、幽霊のサメのきっかけを海への落下からハートの脱落に替えた）：
  カウントダウンで踊る → 1 問目に並んで押し合う → 脱落する人が不正解のドアに 3 回ぶつかる（ハート 3 → 2 → 1 → 0。押し合いで不正解のドアへ
  押し込んでもよい）→ 脱落して幽霊のサメになる（ビームを出して上昇 → 照準 → 体当たり）→ 遅れた人の後ろにチップソー → 10 問目の 4 択のボス壁を突破。
- 2 人とも海に落ちない（ゲームの決まりで、海に落ちるとハートに関係なくすぐ脱落する。2 人とも脱落するとそこで終わり、幽霊のサメは出ない）。
  生き残る人は、ハートを残したまま 10 問目まで行く（間違えるたびに 1 つ減る）。

## 撮った試合（2026-10-22 夜、`s09_play_rec` → `s09_play_frames`）

- 記録：5052 フレーム（84 秒）、キー 625 回、1 秒 58.7 コマ（遅れたコマ 35）。P2 が 1 問目（1121）・3 問目（1879）・5 問目（2578）に
  不正解のドアにぶつかってハートが 0 になり脱落 → 幽霊のサメ（ビーム 2885・照準 3237・PERFECT 3424・7 問目に命中 3466、そのあと 2 回外す）。
  P1 は 4 問目・6 問目にゴツンしてハート 1 で 10 問目のボス壁を突破（4872）。
- 流し直し（ultra、224 秒）：キー 625 回がすべて同じフレームで届き、出来事・2 人の位置・最後の状態も記録と同じ。ただし毎フレームの要約は
  2578〜3602 の 1025 フレームで違った：幽霊のサメの位置だけが、遊んだときより 3 m 奥（ビームの柱の場所の計算が 1.5 m の 2 段ぶん違う）。
  遊んだときの窓が画面に収まるよう縮められて 16:9 から外れ、柱を画面に入れる計算（`ghost_shark_ride_controller.gd` の
  `_keep_beam_in_main_view`）が変わったため。流し直しは 1920x1080 で計算しているので、PV にはこちらが合っている。
  そのあと、記録のときも見える範囲を 16:9 のままにする設定（`content_scale_aspect = KEEP`）を台本に足した。
- 通し（v1.9）：22・8・26・20 拍の 4 本（`docs/pv/capture.md`「S09 の詰め方」）。
