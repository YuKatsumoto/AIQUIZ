## 撮る前（撮らない。1/60 秒刻みで約 12 秒）

1. S16 と同じ台本：2 人が走り、P2 がわざと止まってランニングマンを踊り、チップソーに巻き込まれる。
2. P1 は 0.5 秒走ってから止まり、A で左（+x、後ろから見て左）の端の近く x = 8.5 へ寄り、シリーダンス（キー 2）で煽る（踊りはジャンプするまで続く）。
3. ゲームどおり、幽霊の長い演出（魂が抜ける → 飛ぶ → サメに乗る → ビーム → 登場）。サメは P2 が脱落した側（右、−x）の海から来る。
   ゲームのカメラのまま回すので、サメの浮かぶ位置（`_keep_inside_camera` がゲームのカメラで決める）もゲームと同じ。
4. サメの登場（ENTERING、2.45 秒）の残りが 1.4 秒のところから撮る。

## カメラ（`_apply_follow_camera`）

サメの後ろから追う：サメ → P1 の向きの 6 m 後ろ・3 m 上・スタート側へ 3.5 m ずらした位置から、P1 とサメの間（P1 から 4 割）を見る。
縦の画角 44°。真後ろだとサメの体で幽霊と P1 が隠れるので斜め後ろにした。目と注視点はそれぞれ時定数 0.16・0.1 秒でなめらかに追う
（突進ではサメが先へ抜けていく）。命中したら追うのをやめ、その位置から飛ばされる P1 を見る。揺れはゲームの `camera_shake` を乱数なしの sin で。
試す引数：`follow=<後ろ>,<上>,<横>,<注視の割合>,<画角>`（3 案を撮り比べて今の値にした）。

## HUD

出すのは HUD の P2 のカード（ゴーストシャークの「GHOST RIDER」・操作・チャージのメーター）だけ。P1 のカードとコースの進み具合のバーは隠す。
**ゲームの HUD には「PERFECT」という文字は出ない**（メーターと照準の輪が PERFECT の帯で黄色になるだけ。命中のあとカードに「HAUNT x1」）。
絵コンテの「PERFECT」（画面の左上寄り）を出すなら、編集で離した瞬間（`perfect_release`）から足す必要がある。
照準の輪の脈打ちと構えの点滅はゲームが実時間（`Time.get_ticks_msec`）で動かしているので、sub=8 の重ね合わせでは輪が少しにじむ。

## 撮り方

```
Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1920x1080 --fixed-fps 60 --script res://tests/pv_capture/pv_take_bootstrap.gd -- take=s17 quality=low tag=chk_s17
Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1920x1080 --fixed-fps 480 --script res://tests/pv_capture/pv_take_bootstrap.gd -- take=s17 quality=ultra sub=8 tag=s17_sub8
python tools/pv/merge_subframes.py artifacts/pv_capture/s17_sub8 artifacts/pv_capture/s17_frames
copy artifacts/pv_capture/s17_sub8/{cues,report}.json artifacts/pv_capture/s17_frames/
python docs/pv/takes/lane3_contact.py docs/pv/previz/check/s17_contact.jpg artifacts/pv_capture/s17_frames "S17" 4 1:サメが上がる ...
```

- 引数：`measure`（スローなしの等速で撮り、出来事の時刻を書く）、`follow=`（上）、`hud_dump`（200 フレーム目に見えている HUD の部品を書き出す）。
- 撮れた絵の確認（`_check`）：照準になった・PERFECT・突進が P1 に当たった・P1 が床の外へ飛ばされた。
- 撮影の前に、照準の起点・サメの側（`hover_side` −1）などを `report.json` の `plan`・`pre_roll` に残す。
- 本番画質の撮影は `artifacts/pv_capture/GPU_LOCK` を作ってから走らせ、終わったら消した。かかった時間は 99 秒（撮る前の約 12 秒の演出を含む）。
