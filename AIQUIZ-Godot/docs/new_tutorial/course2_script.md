2026-10-25。[計画書](plan.md) の 4章 ②を細かくしたもの。旧チュートリアルは参照していない。
共通の約束（文字・吹き出し・ハテナの立ち位置・壁・見えないさく・まきもどし・音）は [コース①の台本](course1_script.md) の1章と同じ。この台本には、①と違う所と②で増えるものだけを書く。

**v0.2（2026-10-25）**：ユーザーの指示「セリフと内容が幼稚すぎるので、もっと大人向けに」で書き直した（①と同じ方針。①の台本の冒頭を参照）。ハイタッチ3回は「浮いた的に1回タッチ」に、いっしょに踊る演出は「エモートを1つ出す」にした。v0.1 との違いは 7章。

## 0. このコースの ねらい

終わったとき、プレイヤーは次のことができる。

- スペースでジャンプし、1・2・3 でエモートを出せる
- Esc でゲームを止め、音量を変えて、再開できる
- 本番と同じ始まり方（Enter → 空撮 → カウントダウン）で始めて、最後のボス壁まで突破すると CLEAR になると分かる
- リザルトのカードの見方が分かり、問題の評価・問題履歴・リトライ・メニューを使える
- メニューでモード・教科・学年・むずかしさ・人数を選び、本番を始められる

| # | レッスン | 場所 | 目安 |
|---|---|---|---|
| 2-1 | ジャンプ | ステージ | 12秒 |
| 2-2 | エモート | ステージ | 8秒 |
| 2-3 | 一時停止 | ステージとポーズ画面 | 18秒 |
| 2-4 | ミニ本番 | ステージ | 60秒 |
| 2-5 | リザルト | リザルトのカード | 35秒 |
| 2-6 | メニュー | メインメニュー | 50秒 |
| — | クリア | メインメニュー | 8秒 |

合計 約3分10秒（失敗しなかった場合）。

### 計画書から組み替えたところ

- **「ゴール」→「クリア」**：1人の10問にはゴールラインがない（最後の壁を突破するとそのまま CLEAR）
- **連続正解はミニ本番の中でハテナが数える**：1人のときは、プレイ中に連続正解の炎が出ないため
- **ポーズを先に**：ミニ本番の途中で止めたくなったときに使えるよう、ミニ本番の前に置いた

## 1. ①と違う約束

### 1.1 練習のポーズ（①も同じ）

- Esc で出すのは、**本番と同じポーズ画面**（「PAUSE」、BGM と効果音の音量のスライダー、『ゲームに戻る』『タイトルに戻る』）に、**「このレッスンをスキップ」**を1つ足したもの
- 『タイトルに戻る』を押すと、コースをやめてメニューへ戻る（スタンプは付かない）

### 1.2 画面のコーチ（2-3 のポーズ画面・2-5・2-6）

- 本物の画面の上で、いま見てほしい所を**光らせる**（まわりを少し暗くし、光る枠がゆっくり脈打つ）
- **光っている所だけ押せる**。ほかのボタンは押せない（間違えてコースを抜けないように）
- 「押してみて」の段階は、押すまで待つ。説明だけの段階は、吹き出しの時間で進み、Enter かスペースで早送りできる
- 吹き出しはハテナから出す。画面の端で止めて、光っている所と重ならない位置に出す
- **ハテナの出し方**：メインメニューでは、のこぎりの操縦席に座っているハテナが雲に乗って出てきて、画面の右側（メニューの UI にかからない所）で案内し、終わったら席へ戻る。リザルトとポーズ画面では、雲に乗ったハテナが画面の右下の小窓に出る
- Esc（ポーズ画面の上では『ゲームに戻る』）でいつでもコーチを抜けられる。抜けたら、そのレッスンをスキップしたことにする

### 1.3 練習の記録は送らない

ミニ本番は本物の仕組みで動かすが、結果はどこにも記録しない（問題の成績、AI の問題の改善、Firebase、プレイヤーの分析、戦績、ハイライト、評価の送信）。リザルトの「◯ 良い」「× 悪い」は押せるが、評価は送らない（画面の反応は本番と同じ）。

## 2. レッスンの台本

### 2-1 ジャンプ（約12秒）

**ねらい**：スペースでジャンプできる

**準備**
- 本番のステージ。コンベアは止める。見えないさく（①と同じ）
- 看板の壁（14m先）：問題パネル「スペースでジャンプ」。パネルは左が横長の「スペース」キーの絵、右が的の絵
- プレイヤーの3m前・少し右（x = −2.6。正面だと看板の文字に重なる）、床から約2.9mの高さに、光る的が浮かぶ（立ったままでは届かず、ジャンプすると届く高さ）

| きっかけ | ハテナ | 看板・画面 |
|---|---|---|
| 開始 | 「次はジャンプ」 | 看板の壁が落ちてくる。的が浮かぶ |
| 1.5秒後 | 「浮いている的にタッチしよう」 | |
| 的にタッチ | 「OK」 | 的が光ってはじける。スペースのパネルに ✓ |

**クリア条件**：的に1回タッチする。タッチは「プレイヤーが空中にいて、的の真下（横に 1.0m 以内）を通る」こと

**動かないとき**：6秒スペースが押されなければ、看板の「スペース」が点滅し、「スペースキーでジャンプ」と言う

### 2-2 エモート（約8秒）

**ねらい**：1・2・3 でエモートを出せる

**準備**
- 看板の壁はそのまま。問題パネル「1・2・3でエモート」。パネルは左が「1」「2」「3」のキーの絵、右がおどるハテナの絵

| きっかけ | ハテナ | 看板・画面 |
|---|---|---|
| 開始 | 「1・2・3キーでエモートが出る」 | |
| 1・2・3 のどれかを押す | 「いいね」→「種類はカスタマイズで変えられる」 | 押した数字に ✓ |

**クリア条件**：エモートを1回出す

**動かないとき**：6秒なにも押さなければ「数字の1・2・3キーだよ」

### 2-3 一時停止（約18秒）

**ねらい**：Esc でゲームを止められる。止めた画面で音量を変えて、再開できる

**準備**
- 看板の壁はそのまま。問題パネル「Escで一時停止」。パネルは左が「Esc」キーの絵、右が「II」（一時停止）の絵
- ハテナは看板の前で軽く体をゆらしつづける（止まったことが分かるように）

| きっかけ | ハテナ | 画面・光る所 |
|---|---|---|
| 開始 | 「Escで一時停止できる」 | |
| Esc を押す | ぴたっと止まる | 本番と同じポーズ画面が出る |
| ポーズ画面が出た | 右下の小窓から「これがポーズ画面」 | — |
| 2秒後 | 「音量はここで変えられる」 | BGM と効果音のスライダー（動かしてもよい） |
| 3秒後 | 「『タイトルに戻る』でメニューへ」 | 『タイトルに戻る』（見せるだけで、押せない） |
| 2.5秒後 | 「『ゲームに戻る』で再開」→ 押すまで待つ | 『ゲームに戻る』 |
| 『ゲームに戻る』を押す（Esc でもよい） | 「OK」 | ✓ |

**クリア条件**：ポーズ画面を開き、『ゲームに戻る』で戻る

**動かないとき**：8秒 Esc が押されなければ、看板の「Esc」が点滅し、「Escはキーボードの左上」と言う

### 2-4 ミニ本番（約60秒）

**ねらい**：本番と同じ始まり方で始め、最後のボス壁まで突破すると CLEAR になると分かる

**準備**
- ハートは3つ。ここは本番どおり（ハートが0になるとアウト、海に落ちたらアウト。見えないさくはない）
- 壁3枚を本番と同じ30m間隔で並べ、本番の自動の速さで進める。3枚目はボス壁
- 画面は本番の1人のときと同じ：左上にハート、右上に「正解: 0  問題: 1/3」
- 始まり方も本番と同じ：開始の画面「[ Enterを押してスタート ]」→ 空撮（3.8秒）→ カウントダウン（5・4・3・2・1。4.99秒。頭の上に操作キーがうっすら出る）→ スタート
- ハテナはいまの壁の前に立つ（①と同じ）。続けて正解した数をハテナが数える

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | 「最後は本番と同じ流れで3問」 | 看板の壁が空へ戻り、3枚の壁が空から落ちてくる |
| 壁がそろう | 「本番はEnterでスタート」 | 開始の画面「[ Enterを押してスタート ]」が点滅 |
| Enter を押す | — | 空撮 |
| 空撮が終わる | 「カウントダウンのあと開始」 | カウントダウン |
| スタート | — | 壁1「9 × 6 = ?」。青「56」、赤「54」（正解） |
| 壁1 を突破 | 正解なら「正解」、ミスなら「ドンマイ」 | 右上の数字が変わる |
| その1秒後 | 右上を指して「右上は正解数と何問目か」 | |
| | | 壁2「1年は何日？（うるう年以外）」。青「365日」（正解）、赤「360日」 |
| 壁2 を突破 | 続けて正解なら「2問連続」、そうでなければ正解で「いいね」、ミスで「ドンマイ」 | |
| ボス壁が、いまの壁になった | 「最後はボス壁」 | 壁3「日本一高い山は？」。画面の左から 赤「阿蘇山」・オレンジ「富士山」（正解）・緑「槍ヶ岳」・青「北岳」 |
| 壁3 を突破（ハートが残っていれば、正解でもミスでも） | 3問とも正解なら「3問連続。パーフェクト」 | 本番の CLEAR の演出（花火・紙吹雪）→ 2-5 |

| 失敗 | ハテナ | |
|---|---|---|
| ハートが0になる・海に落ちる | 本番の GAME OVER（体が崩れ、約4秒後にカード）→「残念」 | リザルトのカードで『リトライ』だけを光らせ「『リトライ』でもう一回」→ 押すと開始の画面から（ハート3つ） |
| ミニ本番で3回失敗する | | 壁の速さを少し遅くする（自動計算の「調子」を一番遅い値に） |

**クリア条件**：ハートが残ったまま、ボス壁を突破する

### 2-5 リザルト（約35秒）

**ねらい**：リザルトのカードの見方が分かり、問題の評価・問題履歴・リトライ・メニューを使える

**準備**
- 本番の CLEAR のカード（1人の形）。大きな数字の横は「正解 / 3問」
- 雲に乗ったハテナが右下の小窓に出る。コーチが順に光らせる（1.2）

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| カードが出る | 「これが結果の画面」 | — |
| 1.5秒後 | 「大きな数字が正解数」 | 大きな数字 |
| つぎ | 「正答率・最大連続・時間」 | 「正答率」「連続正解」「時間」の3つ |
| つぎ | 「最後の問題の解説」 | 解説の文 |
| つぎ | 「問題の良し悪しを評価できる」→ 押すまで待つ | 「◯ 良い」「× 悪い」 |
| どちらかを押す | 「ありがとう」→「評価はAIの問題づくりに役立つ」 | 評価の反応（練習なので送らない） |
| つぎ | 「全問の振り返りはここ」→ 押すまで待つ | 『問題履歴』 |
| 問題履歴が開く | 「解説も読める」→「見終わったら『◀ 戻る』」 | 『◀ 戻る』 |
| 戻る | 「『リトライ』でもう一度遊べる」 | 『リトライ』（見せるだけで、押せない） |
| 2.5秒後 | 「『メニュー』へ進もう」→ 押すまで待つ | 『メニュー』 |
| 『メニュー』を押す | — | メインメニューへ → 2-6 |

**クリア条件**：評価を1つ押し、問題履歴を開いて戻り、『メニュー』を押す

### 2-6 メニュー（約50秒）

**ねらい**：メニューでモード・教科・学年・むずかしさ・人数を選び、本番を始められる

**準備**
- 本物のメインメニュー（モード選択）に着く
- のこぎりの操縦席に座っているハテナが、雲に乗って画面の右側（メニューの UI にかからない所）へ飛んでくる
- 光っている所だけ押せる（1.2）

**モード選択**

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| メニューに着く | 雲で飛んできて「ここがメニュー」 | — |
| つぎ | 「10問突破でクリア」→「最後はボス壁」 | 『10問チャレンジ』 |
| つぎ | 「エンドレスは終わりなし」→「10問ごとにハートが増える」 | 『エンドレス』 |
| つぎ | 「離れた相手と対戦」 | 『オンライン対戦』 |
| つぎ | 「『10問チャレンジ』を押して」→ 押すまで待つ | 『10問チャレンジ』 |

**設定**（『10問チャレンジ』を押すと、本物の設定の画面に変わる）

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 設定の画面に変わる | 「ここで遊ぶ準備をする」 | — |
| つぎ | 「◀ ▶で教科を変えてみて」→ 変えるまで待つ | 教科の ◀ ▶ |
| 教科が変わった | 「いいね。次は学年」 | 学年の ◀ ▶（変えなくてもよい） |
| つぎ | 「『むずかしい』はドアが常に4つ」 | むずかしさの ◀ ▶ |
| つぎ | 「問題をAIが作るか選べる」 | 出題のボタン |
| つぎ | 「2人で遊ぶときはここ」 | 人数のボタン |
| つぎ | 「帽子やエモートを変えられる」 | 『カスタマイズ』 |
| つぎ | 「準備ができたらここ」 | 『ゲーム開始』 → クリアへ |

**メモ**
- 教科と学年は、選んだものがそのまま本番の設定として残る（本編のまま）
- 2人で遊ぶ・オンライン・カスタマイズは、それぞれコース③・④・⑤で教えるので、ここでは場所だけ見せる

### クリア（約8秒。メインメニューの設定の画面の上で）

| 時刻 | できごと | ハテナ | 文字 |
|---|---|---|---|
| 0.0 | ハテナが雲で画面の真ん中の手前へ来る | 「これで準備OK」 | |
| 1.5 | クリアカードが出て、スタンプが押される | | 「② 本番の流れ」「クリア」（ミニ本番をノーミスで突破していればスタンプに★） |
| 3.5 | | 「あとは本番で試してみて」 | ボタン［本番を始める］［あとで］ |

- ［本番を始める］：今の設定のまま『ゲーム開始』を押したのと同じ。本物の出発の演出から本番が始まる
- ［あとで］：設定の画面のまま残る。コーチは終わり、ハテナは操縦席へ戻る
- スタンプを保存する（`practice_stamps` に ②）
- 初回の案内から始めたときは、［本番を始める］が選ばれた状態で出す
