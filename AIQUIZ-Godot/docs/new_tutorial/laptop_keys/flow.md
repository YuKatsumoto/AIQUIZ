## 0. ねらい

- 2人で遊ぶときは **1つのキーボードを左右に分けて使う** ことを、本物のキーの並びのまま見せる
  （P1 は左側の W A S D・スペース・1 2 3、P2 は右側の 矢印・右 Ctrl・8 9 0。どれもノートPCのキーボードに実際にある）
- 押したキーがゲームの中のノートPCでも光り、画面の中のステージで自分が動くので、「指の位置」と「動き」が直接つながる
- 練習が終わったら、その画面の中へそのまま入っていく（「このノートPCで遊ぶゲームに入る」）

## 1. 部屋

- スタジアムの中の **控え室**（新しく作る）。照明を落とした暗い部屋で、明かりはノートPCの画面と机の小さなスタンドだけ。暗い木の床、オレンジと青のロッカー、ベンチ。窓はない
- 机の上にノートPC（実物の約 2 倍。2人がキーボードに手を置ける大きさ）。ハテナは机の上
- 画面の中のステージは、本物のステージをそのまま映す（SubViewport）。拡大して画面が画面いっぱいになったら、本番の画面へ 0.2 秒で重ねてつなぐ

## 2. 流れ（入り方 X：カメラが画面に入る。決定）

| コマ | 時間 | 動き | ハテナ・セリフ | カメラ |
|---|---|---|---|---|
| R1 | 0.0〜1.5 | 3-0 のカードが閉じると暗転（0.3 秒）して暗い控え室。P1（左）と P2（右）が入口に立つ。机の上に閉じたノートPC | 机に座って手をふる | 入口から 2人の背中越し |
| R2 | 1.5〜4.0 | 2人が自動で机まで歩く（入力はまだ受けない）。着く直前にふたが開き、画面がつく | 机の上に立ち、ノートPCを指す | 2人について前へ |
| R3 | 4.0〜6.4 | 2人がキーボードに手を置く（P1 は左半分、P2 は右半分）。画面にキーボードの図（左オレンジ・右青） | 「2人のときは操作が変わるよ」（c3.keys.1） | 2人の頭のあいだから肩越し |
| R4 | 6.4〜8.9 | W A S D・スペースが、画面の図と本体の両方でオレンジに光る。図に「P1　移動／ジャンプ」 | 「P1はWASDとスペースだよ」（c3.keys.2）。左を指す | R3 のまま |
| R5 | 8.9〜14.2 | 矢印・右 Ctrl が青、続いて 8 9 0 も青。P1 のキーは薄く光ったまま | 「P2は矢印キーと右Ctrlだよ」（c3.keys.3）→「P2のエモートは8・9・0だよ」（c3.keys.5） | R3 のまま |
| R6 | 14.2〜 | 画面が本物のステージに変わる。押したキーが本体で光り、画面の中の 2人が動く・跳ぶ。画面の隅に P1・P2 の ✓（左右・前後・ジャンプ） | 「2人とも動いてみて！」（c3.keys.6）→ 全員 ✓ で「NICE!」（c3.keys.ok） | 少し寄る |
| R7 | ✓ のあと 1.2 秒 | カメラが画面へまっすぐ寄る（普通の拡大だけ。ぶれ・光・粒はなし） | 机の上で見送る | まっすぐ前へ |
| R8 | 0.2〜0.4 秒 | 控え室の絵が消えて本番の画面。下のカードが出る → 3-2 の壁1 | ステージのハテナは 3-2 の始めに空から降りる | 本番の 2人のカメラ |

CPU と：R3 で「今回の相手はCPUだよ」（c3.keys.cpu1）。R5 で CPU（P2）の手がひとりでに矢印を押して見せる。R6 は P1 だけ ✓（「WASDで動いてジャンプしてみて！」c3.keys.cpu3）。
P1 が矢印を押したら、図の W A S D がオレンジで点滅し「2人のときP1はWASDで動くよ」（c3.keys.cpu2。今の 5 秒あける決まりのまま）。

クリア条件は今のまま（左右・前後に 1.5 m ずつ動いて 1 回ジャンプ。人どうしは 2人とも、CPU とでは P1 だけ）。動くのは画面の中のステージの 2人。

## 4. 気になる点

| 気になる点 | 対策 |
|---|---|
| 肩越しの画角では、2人の手が手前のキーを隠す | 読むのは画面の図。本体のキーは「押すと光る」場所の実感用 |
| 画面の中のステージの 2人は小さい | R6 は R3 より寄る。✓ は画面の隅に大きめに |
| 人どうしでは、矢印を押したのが P1 の人か P2 の人か分からない | 矢印の注意は CPU 戦だけ（今の実装と同じ） |
| ステージの画面を映しておく重さ | 部屋にいるあいだだけ映す。本番のステージは 3-1 のあいだずっと動いている |
