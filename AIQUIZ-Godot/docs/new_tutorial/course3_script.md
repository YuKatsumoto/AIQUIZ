## 0. このコースの ねらい

終わったとき、プレイヤーは次のことができる。

- 2人のときのキー（P1 は W A S D・スペース・1 2 3、P2 は 矢印・右の Ctrl・8 9 0）で遊べる
- 早い者勝ち（先に正解した人だけ得点）と、片方が間違えても問題が続くことが分かる
- 押し合いで相手を一押しできる
- 後ろから迫るのこぎりから逃げられる。触れるとハートがあってもアウトだと分かる
- アウトになったらゴーストシャークで狙い・ためて・突進でき、狙われたらよけられる
- ゴールのあとの得点の計算（正解数 ×（残りハート＋0.5）、アウトの人は正解数だけ）が分かる

## 1. ①②と違う約束（CPU の決まりは、コース④の練習試合でも使う）

### 1.1 相手（人か CPU か）

- コースの始めに「誰と練習する？」を出し、［2人で］［CPUと］から選ぶ（3-0）
- ［2人で］のときは、P2 の人が右の Ctrl を押して参加する。押されるまで始めない
- **CPU** は P2（青）として出て、頭の上に「CPU」の名札を付ける。動きはレッスンごとに台本で決めてあり、キーボードと同じ入力口から動く（`PracticeCpu`）。台本にない動き（勝手に押す・勝手にエモート）はしない
- 人どうしのときは、クリア条件の「2人とも」「どちらかが」をレッスンごとに書く

### 1.2 2人のときのキー

| | 移動 | ジャンプ | エモート |
|---|---|---|---|
| P1 | W A S D | スペース | 1 2 3 |
| P2 | ↑ ↓ ← → | 右の Ctrl | 8 9 0（テンキーの 7 8 9 でも） |

- 1人のときと違い、2人のときは **P1 は矢印キーで動けない**（矢印は P2 のもの）。3-1 ではっきり伝える

### 1.3 本番どおりに見せるもの

- 2人のときのカメラ（2人を入れる引きの画角）、画面の左下と右下のカード（得点・連続正解の炎・ハート・「OUT」）、2人のときに大きくなる壁の文字
- 開始の位置：P1 が x = +1.5（画面の左）、P2 が x = −1.5（画面の右）
- のこぎりは 3-5 で本番どおりに走る（それまでは出さない）

### 1.4 ハテナの役

- ①と同じく、いまの壁の前に立って案内する
- 3-1 では控え室の机の上で案内する（ステージのハテナは 3-1 のあいだ出さず、3-2 の始めに空から降りてくる）
- 3-5 では本編と同じく、のこぎりの操縦席に座ってのこぎりを動かす（案内役のハテナが雲で操縦席へ移る）
- 3-8 では本編と同じく、ゴールの審判をする

## 2. レッスンの台本

### 3-0 相手を選ぶ（約8秒）

| きっかけ | 画面 |
|---|---|
| コースを選んだ | カード「誰と練習する？」、ボタン［2人で］［CPUと］ |
| ［2人で］ | 「P2は右Ctrlで参加」。押されたら P2 のカードが光って「P2が参加」→ 3-1 |
| ［CPUと］ | すぐに 3-1（CPU 用の流れ） |

### 3-1 2人の操作（約25秒。控え室のノートPC）

**ねらい**：2人のときは1つのキーボードを左右に分けて使うことが分かる。P1 は W A S D、P2 は矢印で動く

**準備**
- **控え室**（新しく作る部屋）：照明を落とした暗い部屋。明かりはノートPCの画面と机の小さなスタンドだけ。左の壁にオレンジと青のロッカーとベンチ。窓はない
- 奥の壁ぎわの机に、ふたを閉じたノートPC（実物の約2倍。2人がキーボードに手を置ける大きさ）。ハテナは机の上
- 控え室の P1・P2 は、ステージの P1・P2 と同じ見た目（帽子・色。CPU なら「CPU」の名札も）
- ステージ：本番のステージ。コンベアは止める。見えないさく（①と同じ）。2人はスタートの位置。**R1〜R5 は操作を止めておく**（ステージが見えないので）。キーを押すとノートPCのキーは光る
- ノートPCのキーボードは本物の並び。P1 のキー（W A S D・スペース・1 2 3）はオレンジ、P2 のキー（矢印・右 Ctrl・8 9 0）は青で光る。テンキーの 7 8 9 を押したときは 8 9 0 が光る

**人どうし**

| コマ | きっかけ | ハテナ | 画面・ノートPC | カメラ |
|---|---|---|---|---|
| R1 | 3-0 のカードが閉じた | 机に座って手をふる | 暗転（0.3秒）して控え室。P1（左）と P2（右）が入口に立つ | 入口から2人の背中越し |
| R2 | 1.5秒後 | 机の上に立ち、ノートPCを指す | 2人が自動で机まで歩く（約2.5秒）。着く直前にふたが開き、画面がつく | 2人について前へ |
| R3 | 2人が机に着いた | 「2人のときは操作が変わるよ」（c3.keys.1）。両手を広げる | 2人がキーボードに手を置く（P1 は左半分、P2 は右半分）。画面に見出し「2人のときの操作」とキーボードの図。図の左半分はオレンジ、右半分は青 | 2人の頭のあいだから肩越し。画面が真ん中 |
| R4 | 言い終えた | 「P1はWASDとスペースだよ」（c3.keys.2）。左を指す | W A S D・スペース・1 2 3 が、画面の図と本体の両方でオレンジに光る。図に「移動」「ジャンプ」「エモート」 | R3 のまま |
| R5 | 言い終えた | 「P2は矢印キーと右Ctrlだよ」（c3.keys.3）。右を指す →「P2のエモートは8・9・0だよ」（c3.keys.5） | 矢印・右 Ctrl が青に光る。続いて 8 9 0 も青。説明の済んだキーは薄く光ったまま | R3 のまま |
| R6 | 言い終えた | 「2人とも動いてみて！」（c3.keys.6） | 画面が本物のステージに変わり、操作できるようになる。押したキーが本体で沈んで光り、画面の中の2人が動く・跳ぶ。画面の左上に P1、右上に P2 の欄（「左右」「前後」「ジャンプ」）。できたものに ✓ | R3 より少し寄る |
| R6 | 2人とも ✓ | 「NICE!」（c3.keys.ok） | | |
| R7 | 言い終えた | 机の上で見送る | | 画面へまっすぐ寄る（1.2秒。ぶれ・光・粒などの演出はなし） |
| R8 | 画面が画面いっぱいになった | — | 控え室の絵が消え（0.2秒）、本番のステージの画面になる。下のカード（得点・ハート）が出てくる（0.4秒）→ 3-2 | 本番の2人のカメラ |

**CPU と**（R1・R2・R7・R8 は人どうしと同じ）

| コマ | きっかけ | ハテナ | 画面・ノートPC |
|---|---|---|---|
| R3 | 2人が机に着いた | 「今回の相手はCPUだよ」（c3.keys.cpu1） | キーボードの図（左オレンジ・右青）。CPU（P2）の手がひとりでに矢印を押し、青いキーが光る |
| R4 | 言い終えた | 「2人のときP1はWASDで動くよ」（c3.keys.cpu2）。左を指す | W A S D・スペース・1 2 3 がオレンジに光る。図に「移動」「ジャンプ」「エモート」 |
| R6 | 言い終えた | 「WASDで動いてジャンプしてみて！」（c3.keys.cpu3） | 画面が本物のステージに変わる。P1 の欄だけ |
| R6 | ✓ | 「NICE!」（c3.keys.ok） | |

**クリア条件**：人どうしは2人とも、CPU とでは P1 が、左右・前後に合計1.5mずつ動いて1回ジャンプする（動くのは画面に映るステージの2人）

**動かないとき**：CPU とで、P1 が矢印キーを押したら、本体の W A S D がオレンジで点滅し、ハテナが「2人のときP1はWASDで動くよ」（c3.keys.cpu2）をもう一度言う（5秒は言い直さない）。押した矢印キーは沈むだけで光らない

**スキップ**：ポーズの「このレッスンをスキップ」では、控え室をすぐ閉じて本番の画面に戻し、3-2 へ

### 3-2 早い者勝ち（約35秒）

**ねらい**：先に正解のドアをくぐった人だけが得点する。前へ走ると早く着く

**準備**
- 看板の壁は空へ戻る。前のさくを外す。ハートは3つ（本番どおり。ハートの表示は下のカード）
- 壁は練習の速さ（①と同じ）
- 壁1：問題「1ダースは何個？」、ドアは青「12」（正解）・赤「10」
- 壁2（CPU とだけ）：問題「8 × 9 = ?」、ドアは青「63」・赤「72」（正解）

**人どうし**

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | ジャンプで移って「先にくぐった方だけ得点」 | 壁1が落ちてくる |
| 3秒後 | 「前に出れば早く着く」 | |
| だれかが正解する | 「P1の得点」（または「P2の得点」）→ 下のカードを指して「得点は下のカードに出る」 | 本番の正解の演出。もう1人は得点なし |

**CPU と**

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | 「先にくぐった方だけ得点」 | 壁1。CPU はゆっくり正解のドアへ向かう（プレイヤーが先に着ける速さ） |
| プレイヤーが正解する | 「先に取ったね」→「得点は下のカードに出る」 | |
| 壁2が来る | 「前に出れば早く着く」 | CPU は前へ走って先に正解のドアへ向かう |
| CPU が先に正解する | 「CPUに先を越された」→「速さも大事」 | プレイヤーは得点なし |
| プレイヤーが CPU より先に正解する | 「速い」 | |

**クリア条件**：人どうしは壁1をだれかが正解する。CPU とでは壁2が終わる（どちらが取ってもよい）

**失敗したとき**：だれも正解しないまま壁が終わったら（2人とも間違えた）、まきもどし

### 3-3 間違えても続く（約22秒）

**ねらい**：片方が間違えても、もう1人が答えるまで問題は続く

**準備**
- 壁：問題「日本一長い川は？」、ドアは青「利根川」・赤「信濃川」（正解）
- CPU とでは、CPU が先に青「利根川」へ走り込む（ハートが1つ減る。本番どおり）

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | ジャンプで移る | 壁が落ちてくる |
| CPU が間違える | 「CPUが間違えた」→「でも問題は続く」 | CPU のカードのハートが減る。壁は消えない |
| プレイヤーが正解する | 「もう1人が答えるまで続くよ」 | 正解の演出 |

**人どうし**：役は決めない。片方が先に間違えたら、上と同じ言葉で説明する。そうならなかったとき（先に正解した・2人とも正解）は、壁が終わったあとに「片方が間違えても」→「もう1人が答えるまで続くよ」と言葉で伝える

**クリア条件**：壁が終わる（正解が出る）

### 3-4 押し合い（約25秒）

**ねらい**：相手のほうへ押し続けると踏ん張る。離してもう一度押すと一押しできる

**準備**
- コンベアを止め、見えないさくを置く（①と同じ）
- 看板の壁（14m先）：問題パネル「押し続けて踏ん張る」。パネルは左が2人が押し合う絵、右が「離す → 押す」の絵
- 2人を横に並べてくっつける（P1 x = +0.6、P2 x = −0.6）
- 本編の押し合いの決まり：相手へ向かうキーを押し続けると踏ん張る。2人が0.1秒押し合ったあと、同じキーを離して押し直すと一押し（相手が0.45m下がる）。押しっぱなしや、最初にくっついたときは一押しにならない

| きっかけ | ハテナ | 看板・画面 |
|---|---|---|
| 開始 | 「相手の方へ押し続けて」 | CPU とでは、CPU がプレイヤーのほうへ押し続ける |
| 押し合いになる | 「踏ん張ってる」 | 左のパネルに ✓ |
| 1秒後 | 「一度離して押し直すと…」 | |
| 一押しが当たる | 「一押しが入った」→「端で押されると海に落ちる」 | 右のパネルに ✓ |

**クリア条件**：一押しを1回当てる（人どうしはどちらでもよい）

**動かないとき**：6秒押し合いにならなければ「相手の方向のキーを押し続けて」

### 3-5 のこぎり（約30秒）

**ねらい**：遅れると後ろからのこぎりが来る。触れたらハートがあってもアウト。前へ逃げる

**準備**
- 看板の壁は空へ戻る。さくを外す
- ハテナが雲でのこぎりの操縦席へ移る。のこぎりは本番どおり（加速して、先に進んでいる人の14m後ろまで迫る。速さは毎秒10mまで。始まってから2秒は待つ）
- 壁：問題「1時間は何分？」、ドアは青「60分」（正解）・赤「100分」。練習の速さ

| きっかけ | ハテナ | 画面 |
|---|---|---|
| 開始 | 操縦席から「次はのこぎりが追ってくる」 | のこぎりが回り出す |
| 2秒後 | 「触れたらハートがあってもアウト」 | |
| 壁が落ちてくる | 「画面の縁が赤く光ったら危険」 | のこぎりが近い人の側の画面の縁が赤く点滅する（本番どおり。2人のカードには危険の色はない） |
| だれかがのこぎりに近づく | 「前へ逃げて」→「ジャンプではよけられない」 | |
| 正解のドアをくぐる | 「逃げ切った」 | |

**失敗したとき**：だれかが捕まったら「捕まったね」→「もう一回」→ まきもどしで壁の始めへ（ゴーストにはしない）

**クリア条件**：のこぎりが走る中で壁を突破する（人どうしは2人とも、CPU とではプレイヤーが）

### 3-6 ゴーストシャークに乗る（約40秒）

**ねらい**：アウトになっても、ゴーストシャークに乗って遊び続けられる。狙う・ためる・突進ができる

**準備**
- のこぎりは止めて操縦席に戻す。ハテナは雲で壁の前へ
- P1 をアウトにした場面から始める（本番の脱落の演出 → 魂 → サメに乗る → 光の柱 → 登場。約11秒。2回目からは Enter で飛ばせる）
- 相手（CPU か P2）は床の上をゆっくり左右に動く
- 本番の操作：移動キーで照準の輪を動かす。ジャンプのキー（P1 はスペース、P2 は右の Ctrl）を長押しするとメーターがたまり、離すと突進する。メーターの光る帯（PERFECT）で離すと強い

| きっかけ | ハテナ | 画面 |
|---|---|---|
| 開始 | 「アウトになっても終わりじゃない」 | 脱落の演出 |
| サメに乗る | 「ゴーストシャークで続けられる」 | |
| 照準の輪が出る | 「移動キーで狙う」 | 照準の輪。本番の操作の案内 |
| 輪が動いた | 「スペース長押しでためる」（P2 なら「右Ctrl長押しでためる」） | メーター |
| メーターが光る帯に入る | 「光る帯で離すと強い」 | 本番の「PERFECT 帯！ 今離すと強力」 |
| 突進が相手に当たる | 「当たった」→「アウトでもまだ戦える」 | 相手が吹き飛ぶ（ここでは相手が海へ落ちないよう、床の中央で当てる） |
| 外れた | 「惜しい、もう一回」 | 本番の待ち時間のあと、もう一度狙える |

**クリア条件**：突進を1回当てる（PERFECT でなくてよい）

**人どうし**：3-6 と 3-7 を同時に行う（P1 がゴースト、P2 がよける）。終わったら役を入れかえてもう一度

### 3-7 ゴーストシャークをよける（約25秒）

**ねらい**：ゴーストに狙われたら、構えを見て横へよける

**準備**
- （CPU とだけ）CPU をアウトにした場面から始める（演出は短くしてよい）
- CPU のゴーストは、プレイヤーの位置を狙ってためてから突進する。狙いはプレイヤーの今の位置で決まる（本番どおり、構えたあとは向きが変わらない）
- 画面には本番の「あいてが ねらっているよ！ よけて！」が出る（本編の文字のまま）

| きっかけ | ハテナ | 画面 |
|---|---|---|
| 開始 | 「次は狙われる側」 | |
| CPU が構える | 「構えたら横へよけて」 | |
| よけた | 「よけたね」 | |
| 当たった | 「当たった」→（海まで飛ばされたら）「海まで飛ばされることもある」 | 床に残ったら、もう一度。海に落ちたらまきもどし |

**クリア条件**：突進を1回よける

### 3-8 ゴールと得点（約40秒）

**ねらい**：10問のあとはゴールへ走り、得点の計算で勝ち負けが決まると分かる

**準備**
- 2人とも生き返らせる。ハートは 3-5 が終わったときの数（CPU は 3-3 で1つ減っている）、正解数はここまでの壁の数をそのまま使う
- 壁1枚：問題「100 − 36 = ?」、ドアは青「64」（正解）・赤「74」。そのあとにゴールラインとゴールのスタンド（本番と同じ）
- ハテナはゴールの審判として、スタンドの前へ雲で先回りする

| きっかけ | ハテナ | 画面 |
|---|---|---|
| 開始 | 「最後はゴールまで」 | 壁が落ちてくる |
| 壁が終わる | — | 本番の「GOAL へ走れ！」 |
| ゴールする | — | 本番の「P1 ゴール！ P2を待っています…」「二人ともゴール！」 |

**クリア条件**：スコアタワーの判定まで見る

**メモ**
- CPU とでは、ハートが1つ少ない CPU に、ふつうはプレイヤーが勝つ。負けても、そのまま進む
- 両者脱落の投げ縄の演出ができていれば、ハテナが「2人ともアウトでもゴールへ運ぶ」と一言そえる

### 3-9 サドンデス（使えるときだけ。約5秒）

- 本編のサドンデスは、いまはエディターから動かしたとき（デバッグ版）だけ遊べる（`sudden_death_available`）。書き出した製品版では出ないので、このレッスンもとばす
- 使えるときは、判定のあとに「同点ならサドンデス」→「設定でオフにもできる」と言うだけにする
