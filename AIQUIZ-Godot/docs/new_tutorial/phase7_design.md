台本は [course4_script.md](course4_script.md)（v0.2）。土台は [foundation_design.md](foundation_design.md)・[phase4_design.md](phase4_design.md)・[phase5_design.md](phase5_design.md)（画面のコーチ・メニューのガイド）・[phase6_design.md](phase6_design.md)（CPU）。旧チュートリアルは参照しない（撤去済み）。

## 0. 段階7で「できた」と言える状態

1. コース選択で④が遊べる。③のクリアの［次のコースへ］で④が始まる
2. ④を選ぶと、本物のオンラインの画面（`OnlineMenu`）が「練習の形」で開く：リレーにつながない、接続の表示は `c4.status`、『コードを つくる』『コードを いれる』は押せない
3. 4-1〜4-5：オンラインの画面の上で、画面のコーチ（`PracticeCoach`）が台本どおりに案内する。ハテナはヘリの操縦席から雲で出てきて、画面の右側に浮かぶ（②の 2-6 のメニューのガイドと同じ考え方）
4. 4-2・4-5 で決めた名前（二つ名）とスキンは、本物の設定として保存される
5. 4-6：『ランダムマッチ』で本物のマッチングの演出（短い形）→ 約3秒で「相手が見つかる」→ VS カットイン（あいて：CPU）→ ゲーム画面で CPU との練習試合（壁2枚・本番の自動の速さ・2人の本番のルール）。Esc で本番の「たいせんを やめますか？」が出て、ゲームは止まらない（［やめる］は押せない）。終わると本物のオンラインの結果のカード →『オンラインメニューへ』で練習の形のオンラインの画面へ戻る
6. クリア：オンラインの画面の上でクリアカードとスタンプ。［ランダムマッチで遊ぶ］で練習を終えて本物の『ランダムマッチ』と同じ流れ（ここから通信する）、［あとで］はオンラインの画面に残る
7. 本編（オンライン対戦を含む）とコース①〜③の動きは変わらない。練習の形でないオンラインの画面は今までどおり

## 1. 作るもの

### 1.1 オンラインの画面の「練習の形」（`scripts/ui/online/` の下、`online_menu.gd` など）

- `PracticeSession` で④が始まったとき（`course_id == "c4"`）だけ練習の形にする。リレーにつながず（`NetworkManager` の接続を始めない）、接続の表示を `c4.status` にする
- コーチが光らせる部品を返す `practice_coach_target(id) -> Control`：`&"status"`（接続の表示）・`&"name_field"`・`&"name_dice"`・`&"quiz_box"`（あそぶ もんだい）・`&"grade"`・`&"random_match"`・`&"friends"`（ともだちと あそぶ）・`&"code_make"`・`&"code_enter"`・`&"code_field"`・`&"back"`（← もどる）・`&"skin_sign"`（3Dの看板。画面の位置を Control で返すか、`Rect2` を返す道具を足す）・`&"skin_hat"`（ぼうしの ◀ ▶）・`&"skin_character"`・`&"skin_done"`（✓ けってい）
- 練習の形の『ランダムマッチ』：本物のマッチングの演出（短い形）と「あいてを さがしています…」を出し、約3秒で「あいてが みつかった！」→ VS カットイン（じぶん：名前、あいて：CPU）→ ゲーム画面へ（練習の試合）
- 結果のあと『オンラインメニューへ』で戻ってきたとき、練習の形のまま開き、④の続き（クリア）を始める（`PracticeSession.resume_in_menu` と同じ考え方。`{"course": "c4", "step": "clear"}` など）

### 1.2 練習試合（ゲーム画面。`game_state.gd`・`game_world.gd`・HUD）

- 練習のモードで2人（P2 は CPU。③の `practice_p2_cpu`・`PracticeCpu`）、壁2枚、本番の自動の速さ、本番の2人のルール（のこぎり・押し合い・ゴーストは本番どおり）
- オンラインと同じ見せ方：開始の流れ（オンラインの試合の始まり方に近いもの。ヘリの到着の演出があるなら短く）、カウントダウン、2人のカード、名札（自分の名前・CPU）
- Esc：本番のオンラインの「たいせんを やめますか？（あいての かちに なります）」［つづける］［やめる］を出す。ゲームは止めない。練習では［やめる］は押せない（コーチで光らせない）
- 移動は W A S D でも矢印でもよい（オンラインと同じ。P2 は CPU）
- 2枚目の壁が終わったら、本物のオンラインの結果のカード（勝ち・負け）を出す。ゴール・スコアタワーには進まない。結果は記録しない（戦績・評価・分析に入れない）
- 失敗（ハート0・海）は本番どおり負けのカード。やり直しはしない

### 1.3 コース④の台本（`scripts/practice/courses/course_4.gd` と、メニュー側のガイド）

- 4-1〜4-5 とクリアは、オンラインの画面の上のガイド（②の `scripts/practice/menu/practice_menu_guide.gd` と同じ作りで、オンラインの画面用のもの。共通にできる所は共通にしてよい）
- ハテナ：オンラインの画面の背景のヘリの操縦席の操縦士のハテナを隠し、`HatenaGuide` を雲で出す（②の操縦席の扱いと同じ）。終わったら操縦席へ戻る
- 4-6 の試合の中（ゲーム画面）は `course_4.gd` のレッスン（監督 `PracticeDirector`）。ハテナはいまの壁の前
- 文字は全部 `PracticeTexts` の `c4.*`（監督役が台本 v0.2 のとおりに入れてある）
- `PracticeCatalog` の c4 を遊べるように。③の［次のコースへ］で④が始まるように

## 3. 作りながら決めたこと（2026-10-25）

- **始め方**：`PracticeCatalog` の c4 に `scene`（オンラインの画面）と `round_players`（ゲーム画面の回は2人）を足した。`PracticeSession.launch` は scene のあるコースを、`resume_in_menu = {"course": "c4", "step": "", …}` を入れてその画面へ移す。オンラインの画面は resume を見て練習の形で開き、案内 `PracticeOnlineGuide`（`scripts/practice/menu/practice_online_guide.gd`）を作る。練習試合から戻るときは `{"step": "clear"}`
- **練習の形**：`OnlineMenu.practice`。`NetworkManager` の `find_match`・`create_friend_room`・`join_friend_room`・`cancel_search` を呼ばない。『ランダムマッチ』は演出（いつも短い形）だけを始め、検索中に入って3秒後に案内が `practice_fake_match()` で相手（CPU）を決める。開始の合図は送らず、SWAP で `game_state.practice_online_look` を入れてゲーム画面へ
- **オンラインの見せ方**：`game_state.practice_online_look`（`is_practice_online_look()`）を、ゲーム画面を組み立てる前に入れる（2人のカードの札は作るときに決まるため）。名札（自分の名前・CPU）、2人のカード（じぶん・あいて）、呼び名（じぶん・CPU）、結果のカード（「🏆 あなたの かち！」・『オンラインメニューへ』・リトライなし）、自分だけ選んだ体の色、矢印キーでも動く・押す、開始の前の Enter と準備のパネルは出さない、カウントダウンのキーは自分のぶんだけ、Esc で本番の `NetOverlay` の「たいせんを やめますか？」（`setup_practice`：ping の札なし、［やめる］は押せない）
- **ヘリの到着**：練習は今までどおりヘリで着かず床の上から始まる（開始の前の壁 → 空撮 → カウントダウンは本番どおり）
- **4-5 の色**：「帽子と体の色を選べる」で光らせるのは台本どおり『ぼうし』の ◀ ▶ だけだが、色のカードも押せるようにした（光らせないが押せる部品。`PracticeCoach.focus` の `also_clickable`）。「キャラをクリックしてもいい」はキャラを光らせ、帽子と色もそのまま選べる
- **4-4 のコードの欄**：コードの欄は『コードを いれる』側のときだけ見えるので、案内が見せるだけ切り替える（`OnlineFriendPage.practice_show_join`）。『← もどる』の前に選ぶ側へ戻す
- **3D の看板とキャラ**：コーチが光らせるのは、3D の物の画面の範囲を写す見えない部品（`OnlineMenu.practice_coach_target(&"skin_sign" / &"skin_character")`）。練習の形では、案内が光らせている間だけ看板とキャラを押せる
- **ハテナ**：自分のヘリの操縦士のハテナを隠し、同じ所から雲で出てくる。浮かんでいる間はカメラのゆれに付いていき、スキン設定の寄りの間はうしろのヘリに隠れないよう、カメラの近くで小さく浮かぶ。『ランダムマッチ』を押したら操縦席へ戻り（マッチングの演出では操縦士として映る）、吹き出しは操縦士の頭の上、VS カットインの間は上のまん中
- **4-6 の Esc の案内**：2人の問題は先に正解した人で終わるので、CPU が先に壁2を取ると案内の途中で試合が終わってしまう。案内が済むまで CPU は壁2の正解のドアの前で P1 より前に出ない（`go_door` の急ぎ 0）。済んだらふつうの速さ（0.5）で向かう。始まる前のハテナは2人の左の少し前に立つ（壁の前だと開始の前の壁に隠れる）。スタートしたら①〜③と同じく、いまの壁の前
- **Esc**：オンラインの画面の上では、いまのレッスンをとばす（4-6 は『ランダムマッチ』を押す前まで。とばしたらクリアへ）。練習試合の中は本番どおり「やめる？」になるので、とばす・やめる道はない
- **のこぎり**：本番どおり出るので、案内のハテナ（壁の前）とのこぎりの操縦席のハテナが同時に映ることがある
