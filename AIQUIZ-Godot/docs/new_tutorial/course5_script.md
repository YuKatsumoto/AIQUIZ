## 0. このコースの ねらい

終わったとき、プレイヤーは次のことができる。

- カスタマイズの画面で、P1・P2 の帽子とエモートの枠を変えられる
- 壁の速さ（自動／手動）の変え方が分かる
- メニューの設定パネル（サウンド・画面・接続状態）の場所が分かる

### 計画書から変えたところ

- 1人用のカスタマイズで変えられるのは**帽子だけ**（全17種類）。体の色はオンラインのスキン設定にしかないので、コース④で教える
- 順番は、カスタマイズを先に、設定パネルをあとにした

## 1. ①〜④と違う約束

### 1.1 本物の設定を変える

- 帽子とエモートの枠は、プレイヤーが選んだものをそのまま本番の設定として残す（帽子は保存される。エモートの枠は本番と同じく、そのとき遊んでいる間だけ）
- **壁の速さだけは、試したあとで元の設定に戻す**（知らないうちにゲームの速さが変わらないように）
- 設定パネルの音量は動かしてもよい。動かしたら、それは残す。画面の設定（解像度・FPS上限・画質）とサドンデスは見せるだけで、練習の間は変えられない

### 1.2 ハテナ

- メインメニューでは、②と同じく、のこぎりの操縦席のハテナが雲に乗って画面の右側に出る
- カスタマイズの画面は右側に設定のパネルがあるので、ハテナは左上（3Dのプレビューの空の所）に雲で浮かぶ。カメラが動いても画面の同じ所にいる
- 設定パネルは画面全体をふさぐので、パネルが開いている間は、②のポーズ画面と同じハテナの小窓（右下）で案内する

### 1.3 とばす

- Esc で、いまのレッスンをとばす（④と同じ）。次のレッスンに要る画面（設定の画面・カスタマイズ・設定パネル）は、とばしたときも練習が開く・閉じる
- 5-2〜5-4 の始めのタブ（『スキン』『エモート』『壁速度』）がもう開いているとき（前のレッスンをとばしたときなど）は、「押してみて」の一言をとばして次へ進む

## 2. レッスンの台本

### 5-1 カスタマイズへ（約15秒）

**ねらい**：カスタマイズの画面への行き方が分かる

**準備**：コース選択で⑤を選ぶと、コース選択が閉じてメインメニュー（モード選択）のまま始まる

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 始まる | 雲で出てきて「自分らしく飾ってみよう！」 | — |
| つぎ | 「『10問チャレンジ』を押してみて！」→ 押すまで待つ | 『10問チャレンジ』 |
| 設定の画面 | 「『カスタマイズ』を押してみて！」→ 押すまで待つ | 『カスタマイズ』 |
| カスタマイズの画面が開く | 左上へ移る | — |

### 5-2 帽子（約30秒）

**ねらい**：P1・P2 の帽子を選べる。プロペラ帽はジャンプのあとゆっくり落ちる

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「『スキン』を押して帽子を選ぼう！」→ 押すまで待つ | タブ『スキン』 |
| スキンのタブ | 「◀ ▶で変えてみて！」→ 変えるまで待つ | 帽子の ◀ ▶ |
| 帽子が変わった | 「似合ってる！」（プロペラ帽にしたときは「『プロペラ帽』はゆっくり落ちるよ」） | — |
| つぎ | 「P2の帽子も選べるよ」 | 『プレイヤー１』『プレイヤー２』（押してもよい） |
| つぎ | 「右ドラッグで回せるよ」 | プレビュー（右ドラッグで回る・ホイールで大きさ。試してもよい） |

**クリア条件**：帽子を1回変える

### 5-3 エモート（約30秒）

**ねらい**：エモートの枠に踊りを入れられる。1番の踊りは2人対戦で勝ったときのダンスにもなる

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「次は『エモート』を押してみて！」→ 押すまで待つ | タブ『エモート』 |
| エモートのタブ | 「枠を選んで踊りを入れてみよう！」→ 1つ入れるまで待つ | 枠（1・2・3）と踊りの一覧 |
| 入れた | 「いい踊りだね！」 | — |
| つぎ | 「1番は勝ったときのダンスになるよ」 | 1番の枠 |
| つぎ | 「ゲーム中は1・2・3キーで出せるよ」 | 枠（1・2・3） |

**クリア条件**：踊りの一覧から1つ選ぶ（いま選んでいる枠に入る）

### 5-4 壁の速さ（約25秒）

**ねらい**：壁が速すぎるときは手動で遅くできる。ふだんは自動がおすすめ

**本編の決まり**：「自動モード」は問題を読んで答える時間から壁の速さを決める。スライダーを動かすと「手動モード」になり、その速さで壁と床が動く。『自動モードに戻す』で自動へ戻る

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「『壁速度』で速さを変えてみよう！」→ 押すまで待つ | タブ『壁速度』 |
| 壁速度のタブ | 「ふだんは自動がおすすめだよ」 | 「自動モード」の表示 |
| つぎ | 「スライダーを動かしてみて！」→ 動かすまで待つ | スライダー（プレビューの床の速さが変わる） |
| 動かした | 「速すぎたらゆっくりにしてね」 | — |
| つぎ | 「元に戻しておくね」 | 『自動モードに戻す』（見せるだけ）。5-4 を始める前の設定へ戻す（自動だったら自動へ） |

**クリア条件**：スライダーを1回動かす

### 5-5 決定（約5秒）

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「『✓ 決定して戻る』を押してね！」→ 押すまで待つ | 『✓ 決定して戻る』 |

### 5-6 設定（約30秒）

**ねらい**：音の大きさ・画面の重さ・AI の問題が使えるかを、どこで見るか分かる

**準備**：『設定 / API状態』は、設定の画面の右下にもある（モード選択へ戻らなくてよい）

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 設定の画面に戻る | 「次はメニューの設定を見よう」 | — |
| つぎ | 「『設定 / API状態』を押してね」→ 押すまで待つ | 右下の『設定 / API状態』 |
| 設定パネル（ハテナは右下の小窓） | 「音の大きさはここで変えるよ」 | 「サウンド」の『BGM音量』『効果音量』（動かしてもよい） |
| つぎ | 「画質を下げると軽くなるよ」 | 「画面」の『解像度』『FPS上限』『画質』（見せるだけ） |
| （「ゲーム」の行が出ているときだけ） | 「サドンデスのオン・オフもできるよ」 | 「ゲーム」の『サドンデス（2P 10問の引き分け）』（見せるだけ） |
| つぎ | 「AIの状態も分かるよ」 | 「接続状態」（インターネット・AIゲートウェイ・Firebase・オフライン問題数・『再チェック』。見せるだけ） |
| つぎ | 「閉じてメニューへ戻ろう！」→ 押すまで待つ | 設定パネルの『戻る』 |

**メモ**：『管理ダッシュボードを開く』は大人向けの道具なので説明せず、コーチの間は押せない

### クリア（約10秒。メインメニューの上で）

| 時刻 | ハテナ | 画面 |
|---|---|---|
| 0.0 | 雲で手前へ来て「クリア！自分だけのスタイルだね」 | |
| 1.5 | スタンプが押される | 「⑤ カスタマイズ」「クリア」 |
| 3.5 | （スタンプが5つそろったときだけ）「スタンプが全部そろったね！」 | ごほうびは未定（計画書9章） |
| 3.5 か 5.5 | 「楽しんでね！」 | ボタン［メニューに戻る］ |

- ［メニューに戻る］：カードを閉じ、ハテナは席へ戻る。メニューはモード選択に戻る
- スタンプを保存する（`practice_stamps` に ⑤）。★はない
