## 1. ハテナの新しい動き

### 1.1 いま使っている動き（2026-10-26 に grep で確かめた）

v0.2 の台本で寸劇（海に落ちる・歩いてくる など）を外したので、`HatenaGuide` の `walk_to`・`fall_into_sea`・`set_flailing`・`tremble`・`spin`・`dodge` は、どのコースからも呼ばれていない。使っているのは次のもの。

| 呼び方 | いまの中身（仮） | 段階9 |
|---|---|---|
| `play(&"wave")` | `Stand_Idle`（客席に手をふる） | そのまま |
| `play(&"cheer")`・`&"clap"`・`&"dance"`・`&"point"` | `Stand_Cheer`・`Stand_Clap`・`Stand_Dance`・`Stand_Point` | そのまま |
| `play(&"open_arms")` | `Stand_HoldCard`（札を掲げる） | **新しい** `Practice_OpenArms`（両手を広げて見せる） |
| `play(&"proud")` | `Stand_HoldCard` | **新しい** `Practice_Proud`（腰に手を当てて胸をはる） |
| `play(&"cross")` | `Stand_HoldCard` ＋ 赤い × の文字 | **新しい** `Practice_Cross`（両腕を頭の横で × の形に振り上げる）＋ 赤い × の文字は残す |
| `play(&"tilt")` | `Stand_Idle` ＋ 体を横に傾ける | **新しい** `Practice_Tilt`（片手をほおに当てて首をかしげる） |
| `hop_to` | 位置を動かすだけ（動きは前のまま） | 跳んでいる間 **新しい** `Practice_Hop`（ひざを曲げて両手を上げる）、着地で **新しい** `Practice_Land`（ひざを曲げて受け止める。1回だけ） |
| 雲の上（`ride_cloud_to`・`glide_to`・浮かんでいる間） | そのときの動き | 動きを指定していないとき（`idle`）は **新しい** `Practice_Ride`（雲の上でつり合いをとって浮かぶ） |

足す動き（台本で使う所を増やす）：

| 呼び方 | 動き | 使う所 |
|---|---|---|
| `play(&"oops")` | **新しい** `Practice_Oops`（あちゃー：片手を頭の横に当てて、うなだれる） | 失敗したとき（CPU に先を越された・ゴーストに当たった・海まで飛ばされた・④の試合に負けた）。いまの `tilt` のうち、失敗の場面だけを置き換える。ヒント（どのドアの前にもいない）と注意（やめると相手の勝ち）は `tilt` のまま |
| `play(&"nod")` | **新しい** `Practice_Nod`（2回うなずいて止まる） | 説明の続き（「得点は下のカードに出る」のような、指さない補足）に使える。最初は小窓とコーチの説明で試す |

`walk_to`・`fall_into_sea` などの使っていない動きは、作り直さない（使うときに作る）。

### 1.2 作り方（`assets/characters/aiquiz_mascot/source/build_practice_mascot.py`）

- 客席のハテナ（`build_stand_mascot.py`）と同じ作り：`aiquiz_mascot.blend` の骨格 `Rig` に、骨の向き（ハテナの空間）と体・腰の上下で姿勢を決めたアクションを作り、骨組みとアクションだけを `../mascot_practice.glb` に書き出す（メッシュなし。`mascot_model.glb` は変えない）
- 24 fps。ループする動きは最初と最後の姿勢をそろえる。`Practice_Land` は 0.4 秒の1回だけ
- 腕は短い（上腕 0.159・前腕 0.137・手 0.13 m）ので、体の前で腕を交差させたり、頭の上で手を合わせたりはできない。× は頭の横で腕を振り上げた形と赤い × の文字で見せ、ほお・頭の横に手を当てるのは体の玉の横の届く所にする
- 姿勢ごとに、ライブの Blender の確認用のカメラで正面と斜めを撮って、腕が体にめり込まないこと・形が読めることを確かめる

### 1.3 組み込み（`hatena_guide.gd`・`stand_mascot.gd`）

- `StandMascot` に、別のアニメーションライブラリを足す道具（`add_library(name, library)`）と、ライブラリの動きをそのまま鳴らす道具（`play_clip(clip, restart, loop)`）を足す。客席のハテナの動きは変えない
- `HatenaGuide` は `mascot_practice.glb` を読み込み、`ACTIONS` の行き先を新しい動きに変える。ファイルがないときは、今までの仮の動きに戻す（テストで落ちないように）
- 着地（`Practice_Land`）は1回鳴らしたら、前の動きに戻す

## 4. 作りながら決めたこと（2026-10-26）

- **ハテナの影**（ユーザーの指示「ハテナの影がないので立体的に見えません」）：客席のハテナ（`StandMascot`）は影を落とさない作りなので、案内役（`HatenaGuide.setup`）だけ体のメッシュを影ありにした。雲はもとから影を落とす
- **腕が短い**：上腕・前腕・手で 0.43 m しかなく、体の玉（幅 1.1 m）の前で腕を交差させたり、頭の上で手を合わせたりできない。× は「両手を前に出して首を2回ふる」と赤い × の文字で見せる。ほお・頭の横に手を当てる動きは、体の玉の横の届く所にした
- **体をうなずかせる・ひねるとき**は、腰（DEF-hips）と体（DEF-head）を同じだけ回す。体だけを大きく回すと、玉の腰のあたり（ウェイトの切り替わり）にしわが出た
- **失敗の場面は「あちゃー」**：CPU に先を越された・ゴーストに当たった・海まで飛ばされた（③）、試合に負けた（④）、仕上げのミス・負け・海に落ちた（①）。ヒント（どのドアの前にもいない）と注意（やめると相手の勝ち）は「首をかしげる」のまま。「うなずく」は①の補足（「色じゃなく答えで選ぼう」「練習だから戻しておくよ」）
- **①「スタート」の文字**：同じ時に最初の壁が来て、文字がドアと問題文に約1秒かぶっていた。少し小さくし、0.3 秒止まってから上へ抜けて消える（0.55 秒で消える）
- **③ スコアタワーの間**は、練習の見出し（コース名と点）を隠す（本番の得点板の上の帯に重なっていた）
- **③ 3-2 の壁2で P1 が画面の下へ外れる**のは、本番の2人用のカメラのふるまい（画面の外の「1P」の印が出る）なので直さない
- **④ 試合中にハテナが2人映る**：案内のハテナが舞台にいる間（4-6 の試合）は、のこぎりの操縦席のハテナを隠す
- **「Lambda capture at index 0 was freed」**の出どころ：`self` を使わない lambda を SceneTreeTimer につなぐと、作った物が消えても lambda は残り、消えた物を握ったまま呼ばれる。ゲームでは、本編の `particle_spawner.gd`（花火・水柱の後片付け。③の最後の花火8発ぶん）と練習の看板の後片付け。どちらも、消す物のメソッド（`queue_free`）へ直接つなぐ形にした（先に消えれば、つながりも消える）。②のテストの待ち条件にも同じ形があったので、弱い参照（`weakref`）にした
- **⑤ エモートのタブで、踊るキャラの腕がハテナのうしろに重なる**：ハテナが手前に描かれ、読みにくくはないので直さない
- **初回の案内**の「？」の丸（仮）を、ハテナの小窓と同じ 3D の絵（雲に乗って手をふる）にした（`HatenaPortrait.show_inline`）。開いている間だけ作る

## 5. 席へ戻る・席を離れる動き（2026-10-26 追加）

ユーザーの指示「操作盤に戻るときやヘリの中に戻るときのアニメーションをもっと現実的にしてください。ちゃんと雲から降りて、ヘリのハッチを開いて動作とかみたいにもっとちゃんと作り込んでください」。それまでは、雲で席の上まで飛んで消え、席のハテナが出るだけだった。

### 5.1 動きの流れ（`scripts/practice/menu/practice_seat_moves.gd`、`PracticeSeatMoves`）

| 所 | 席へ戻る | 席を離れる |
|---|---|---|
| のこぎりの操縦席（②の 2-6・⑤。メニュー） | 雲で座面の横（カメラのほう）へ飛ぶ → 雲を残して座面へ跳び降りる（雲は空へ帰る）→ 前を向いて、お尻から座る → 席のハテナと入れ替わる | 席のハテナと入れ替わる（座った姿）→ 雲を呼ぶ → 座面の上に立ち上がる → 雲へ跳び乗る → メニューの右側へ飛ぶ |
| ヘリ（④。オンラインの画面） | 雲でステップの前へ → 雲を残して跳び降りる → ヘリのほうを向いて、右手でドア（上へ開くガルウィング）を押し上げる → ステップ・敷居を上がる → かがんで機内へ → 振り返ってドアを引き下ろす → かがんで右の席の前へ → 機首を向いて座る → ベルトが出て、操縦士と入れ替わる | 操縦士と入れ替わる → 立ち上がり、かがんでドアの前へ → ドアを押し上げる → 敷居・ステップを下りる → 振り返ってドアを引き下ろす → 雲を呼んで跳び乗る → 画面の右側へ飛ぶ |

- 席の近くの動きは、ハテナを席の台（操縦席なら `SawOperatorPresentation`、ヘリなら `OnlineHeliportHelicopter`）の子にして、その空間で動かす（メニューの操縦席は動くので、付いていく）。終わったら元の親へ戻す
- 座った姿は、席のハテナの骨格にぴったり重ねる（`PracticeSeatMoves.overlay`：ハテナの `skeleton_offset()` から、ノードの位置・向き・大きさを逆算）。座った姿はヘリの操縦士と同じ「ぬいぐるみ座り」（`mascot_pilot.glb` の `Pilot_SitIdle` を案内のハテナにも足した）なので、ヘリでは入れ替わっても形が変わらない。のこぎりの操縦席の席のハテナは、手がスティック・足がペダルにあるので、入れ替わるときに手足だけ少し動く
- 操縦席の席のハテナは 0.8 倍、ヘリの操縦士は等倍。メニューの案内のハテナ（等倍）は、席へ飛ぶ間に 0.8 倍へ縮む
- ヘリの目印（`MK_BoardStand`・`MK_Step`・`MK_DoorSill`・`MK_SeatFront`）は、プレイヤーが乗りこむ道すじ（左のドア）のもの。操縦士は右の席なので、機内で右の席の前（`MK_SeatFront` の左右反転）へ移る
- オンラインの演出（`OnlineStagingDirector`）は待機中も毎フレーム左のドアを閉じるので、ヘリに `practice_doors`（練習の案内のハテナが手で動かしている間は、その開き具合を優先する）を足した
- 待っているプレイヤーは、オンラインの画面のカメラとドアの間に立つ。遠くから歩いてくるとプレイヤーの陰を通るので、雲はステップの前にじかに降ろす
- ④の 4-6 は、先にハテナがヘリへ乗りこんで座ってから、操縦席から『ランダムマッチ』を押してもらう（押したあとに乗ると、本番の演出で乗りこむプレイヤーとドアで重なる）。吹き出しは操縦士の頭の上
- かかる時間：操縦席は戻る・離れるとも約 3.5〜4 秒、ヘリは約 10 秒。Esc でとばした流れの中など、急ぐときは今までどおり雲で飛んで入れ替わる（`_return_to_seat(seconds, true)`）
- ③の 3-5（のこぎりの操縦席へ）・3-6（席から）は、操縦席がゲームのカメラに入らないので、今までどおり（雲で飛んで入れ替わる）

### 5.2 足した動き（ライブの Blender。`build_practice_mascot.py`）

`Practice_Walk`（歩く）・`Practice_DuckWalk`（かがんで歩く）・`Practice_Step`（段の上り下り）・`Practice_SitDown`（座る。終わりは `Pilot_SitIdle` と同じ）・`Practice_StandUp`（立つ）・`Practice_PushUp`（ドアを押し上げる）・`Practice_PullDown`（ドアを引き下ろす）。`HatenaGuide` には `walk_to(…, duck)`・`step_to`・`sit_to`・`sit_here`・`stand_up_to`・`turn_to`・`push_door`・`pull_door`、雲を離す `leave_cloud_here`・`send_cloud_away`・`call_cloud`・`board_cloud`、`hop_to` の弧の高さを足した。
