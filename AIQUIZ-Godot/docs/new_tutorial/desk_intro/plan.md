## 寸法とカメラ（Blender の座標）

単位はメートル、Z が上。原点は机の手前の縁の真ん中の床、+Y が机（奥の壁）の方向。Godot へは glTF の変換どおり（Godot の -Z が Blender の +Y）。

段階2で、絵コンテの見え方に合わせて決め直した値（はじめの案は括弧の中）。

- 部屋：内側の幅 4.2（3.6）、奥の壁は y = 0.80、高さ 2.5
- 机：幅 1.60・奥行き 0.75・高さ 0.72（天板の上面）
- モニター：27 型（画面 0.5977×0.3362）、画面の中心は (0, 0.40, 1.03)（(0, 0.43, 1.10)）。低めの台で手前寄りにし、D5 で画面とキーボードが近く見えるようにした
- キーボード：ゲームの配列（`TutorialKeyboard.get_key_layout()`、64 キー、キーの間隔 19.05mm）。中心は机の縁から 0.20（0.15）、奥を 3° 上げる。
  キーは1個ずつ分け、名前は英字（`KEY_Left` など）、ゲームのキーの id はカスタムプロパティ `key_id` に入れた（Godot で沈めて光らせるため）
- 椅子：ゲーミングチェア 2 脚、中心は x = ±0.34。背もたれの上端は 1.20（座った人の頭が上に出る高さ）。D1 では y = -0.70 まで引く
- カメラ（35mm 判、センサー 36mm）：
  - D1：30mm、(0, -3.1, 1.72) → (0, 0.15, 0.82)
  - D2：35mm、(0, -2.6, 1.62)
  - D3：40mm、(0, -1.65, 1.58)
  - D4〜D6：45mm、(0, -0.98, 1.74) → (0, 0.27, 0.82)、f/4 でキーボードにピント（2 人の頭のすぐ上・少し後ろ。説明画面の基準の構図。
    ブロックマンの頭を入れてから、はじめの (0, -0.80, 1.62) より引いて上げた）
  - D7〜D8：モニターの正面、画面の約 0.4 手前へ
- 光：デスクライト 約 3000K（主光、机の左端）、モニター 約 6500K（2人の輪郭）、モニターの裏の青い LED、キーごとの RGB（P1 オレンジ・P2 水色・ほかは薄い白）

## 作り方の要点

- **人物（ブロックマン）**：`build_tutorial_people.py`。MPFB2 で人の体を作って骨組み `mixamo`（指まで 52 本）だけを残し、骨ごとに角を丸めた箱
  （こし・むね・首・立方体の頭と顔・上腕・前腕・手のひら・指 3 節・親指・もも・すね・足・つま先）を 1 つの形にして、骨ごとの重み 1 で曲げる。
  材質は塗装の樹脂（色のむら・ゆず肌・うすいクリア）。色は PlayerSkin.SLOT_COLORS と同じ。
- **キーに置く手**：手のひらを下へ水平にし（人差し指〜小指の付け根を水平に、親指の側を 5mm 高く）、中指の付け根を中指のキーの 5.6cm 手前・
  4.2cm 上に置く。指ごとに、付け根の節をキーの上の点へ向け、2 つ目・3 つ目の節の曲げる量と向ける点の高さを二分法で決めて、
  指の箱のいちばん低い点がそのキーの天面の真ん中にちょうど当たるようにする（P1：人差し指 D・中指 S・薬指 A・小指 Caps・親指 Space、
  P2：人差し指 ←・中指 ↓・薬指 →、小指と親指は少し浮かせる）。もう一方の手は膝の上。
- **動き**：`build_tutorial_motion.py`。24 fps・132 コマ。カメラは D1 → D2 → D3 → D5 を 1 本でつなぐ（`CAM_Intro`。レンズ 30 → 45mm）。
  腰・背骨・足首・手首の IK の目印・指・椅子にキー。最後のコマが準備完了の姿勢。
- **書き出し**：`export_tutorial_desk.py` で glb（約 4.5MB）。キーの文字は書き出す間だけ形に置き換え、IK などの制約は動きに焼き込む。
  glb の動きは物ごとに分かれて入るので、Godot で 1 本（`desk/Intro`）にまとめる。
- **Godot**（`tutorial_keyboard_desk_3d.gd`）：
  - 光はリアルタイム（デスクライトの影あり・モニターの弱い面の光・モニターの裏の青い LED・部屋の弱い明かり）。色は AgX、ピントのぼけは CameraAttributesPractical、
    画質「高」以上で SSAO・SSIL。Blender の手続きの模様は glb に入らないので、木（机・棚・床）は木目のシェーダー（`shaders/tutorial_desk_wood.gdshader`）、
    ほかは名前ごとに色とつやを合わせ直す。
  - 押したキーへの指：押している指ごとに「手をずらしたい量」を出し、その平均だけ手首を動かして（腕の 2 本の骨の IK）、残りは指の付け根の
    2 つの節の IK で、指先の当たる所を沈んだキーの天面へ下ろす（W と D を一緒に押すと、手は半段だけ前へ出て、中指は W・人差し指は D）。
    P2 のエモートは、キーに置いた P1 の左手を手本に、膝の上の左手をキーボードへ伸ばす。指先の当たる所は、Blender と同じく指の箱の頂点で測る。
  - 準備完了の間は、背骨と頭をわずかに動かして息をさせ、手は IK でキーの上に残す。

## 段階

1. **絵コンテ**（Codex の画像生成）：8 コマ（v0.1）。ユーザーと直して決める
2. **Blender でセット**：部屋・机・モニター・キーボード・椅子・デスクライト・ハテナのフィギュアを実寸で作る。
   カメラの構図（D1・D4）を先に決めてから作り込み、Cycles で絵コンテと同じ構図を撮って見比べる
3. **Blender で人物**：作り方（A・B・C）を試して決め、2人（服・手）と骨組み（指まで）を作る
4. **Blender で動き**：カメラ、座る、椅子、手を添える。動画を書き出して確かめる
5. **Godot へ取り込み、見た目を合わせる**：光・材質・ポストエフェクト。Cycles の画と並べて比べ、実写に足りるか判断する（足りなければ座る部分だけ動画にする）
6. **流れと入力**：上の「流れ」、Space の準備完了、飛ばす、Esc、指の IK、説明カードの置き場所、頭に当たらない寄り方
7. **仕上げ**：画面比（16:9・21:9・4:3）、画質の設定（低では軽く）、重さ、テストと実際のゲーム画面での確認

## 絵コンテ v0.1 で見えたこと

- 部屋の暗さ、デスクライトとモニターの光、肩越しの手元（D4〜D6）は、ねらいどおりの見え方になった。D5 を説明画面の基準の構図にする。
- 生成した絵では、キーボードの形がコマごとに違う（テンキー付きのものもある）。作るときは、ゲームの配列（テンキーなし、矢印は右下に別）に合わせる。
- モニターの絵もコマごとに違う。実物ではメニューの背景のライブ映像を映す。
- D7 の絵は D5 より引いた構図になった。実際には D5 の位置から、2人の頭のあいだを通ってモニターへ寄る。

## 気をつけること

- 2人の頭は D5 で画面の左右を大きく占める（絵コンテどおり）。カードはその上に重なる。
- モニターの光は、近くにある頭と肩をすぐ白く飛ばす。強くするときは、`light_specular` と `light_size` も一緒に見る。
- 指先とキーの合わせは、ブロックマンの手の形（`build_tutorial_people.py` の `KNUCKLE_BACK`・`KNUCKLE_HEIGHT`・`BEND`）とキーボードの位置に依る。
  どれかを変えたら、Blender で人物と動きを作り直して glb を書き出し、`tests/tutorial_keyboard_desk_unit.gd` を流す。
