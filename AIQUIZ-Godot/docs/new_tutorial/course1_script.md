# コース① 「基本操作」 台本（v0.2）

2026-10-25。[計画書](plan.md) の 4章 ①を細かくしたもの。旧チュートリアルは参照していない。
座標・秒数は、本編のコードから取った値と、このコースのために決めた値。実装しながら調整する。

**v0.2（2026-10-25）**：ユーザーの指示「セリフと内容が幼稚すぎるので、もっと大人向けに」で書き直した。
文字は漢字かな交じりの普通の文、ハテナはくだけた口調（だ・よ）、子どもっぽい演出（ハテナが海に落ちて助けられる寸劇、わざと間違える課題）を外して短くし、練習の問題は一般常識くらいにした。v0.1 の流れは 7章に残す。

## 0. このコースの ねらい

終わったとき、プレイヤーは次のことができる。

- 左右・前後に動ける
- 壁の文字を読み、答えのドアをくぐれる（色ではなく答えで選ぶ）
- 違うドアでも、ドアの間の壁でもハートが減り、0 になるとアウトだと分かる
- 床の外は海で、落ちたらハートがあってもアウトだと分かる。端の位置が体で分かる
- 4つのドアのボス壁を知っている
- 本番の速さで3問を突破できる

| # | レッスン | 目安 |
|---|---|---|
| 1-1 | ようこそ | 6秒 |
| 1-2 | 移動 | 20秒 |
| 1-3 | ドアをくぐる | 18秒 |
| 1-4 | クイズに答える | 18秒 |
| 1-5 | ハート | 20秒 |
| 1-6 | 床の端 | 30秒 |
| 1-7 | 仕上げ | 45秒 |
| — | クリア | 10秒 |

合計 約3分（失敗しなかった場合）。

## 1. 共通の約束

### 1.1 文字

- 漢字かな交じりの普通の文。分かち書きはしない。数字は算用数字
- ハテナの話し方はくだけた口調（だ・よ）。幼い言い回し（「〜だよ！」の連発、「やったー」「すごい！」「〜してあげる」など）と、はしゃいだ感嘆符は使わない。ほめるときも短く（「いいね」「OK」）
- ハテナの吹き出し：1行・18文字まで。長くなるときは吹き出しを2つに分ける
- 壁の問題文：2行まで、1行14文字まで
- ドアの文字：5文字まで
- 本物の画面のボタンの名前は、画面の文字のまま『』で囲む

### 1.2 ハテナの吹き出し

- ハテナの頭の上に出す。画面からはみ出しそうなときは、画面の端で止める
- 出している時間は「0.8秒 ＋ 1文字あたり0.12秒」（最短1.8秒・最長4.0秒）
- 出るときに「ぽこっ」という音。ハテナの声はない（2026-10-25 決定）
- 操作をロックしている場面（1-1、1-6 の始め、クリア）だけ、Enter かスペースで次へ送れる

### 1.3 ハテナの立ち位置と動き

- **いまの壁の前**に立つ。場所は画面の左寄りで、ドアの外側（x = +9.5）。壁といっしょに近づいてくる
- 壁を突破するか壁が消えると、**次の壁へジャンプして移る**（放物線、0.8秒）
- 次の壁がないときは、プレイヤーの3m前（少し左）の床に立つ
- プレイヤーが x = +9.5 のあたりで壁に当たりそうなときは、横へよける
- 客席のハテナ（ウェーブの合図役）は、レッスン中は出さない

### 1.4 壁

- 本番と同じクイズ壁を使う。登場も本番と同じで、空から落ちてきて土ぼこりが立つ
- **練習の壁**：22m先に落ち、コンベアが毎秒1.6mで運ぶ（約14秒で届く）
- **仕上げの壁**：本番の自動の速さ
- **看板の壁**：説明のための壁。ドアの代わりに大きなパネルを2枚持ち、キーの絵・絵を出す。14m先に止まり、その間はコンベアも止める。用が済むと空へ戻る
- 2択のドア：青が x = +3.5（画面の左）、赤が x = −3.5（画面の右）
- 4択のドア：画面の左から 赤・オレンジ・緑・青

### 1.5 見えない さく

- 1-2〜1-5 は海に落ちないよう、見えないさくを置く。左右は x = ±10、前は z = +8（1-2のみ）、うしろは z = −6
- さわると押し返され、さくのある場所がうっすら光る
- 1-6 で外す。そこから先は本当に落ちる

### 1.6 まきもどし（やり直し）

- 失敗すると0.6秒の「まきもどし」が入る。プレイヤーはレッスンの始めの位置（x = 0、z = 0）へ、壁もレッスンの始めの状態へ戻る
- 戻った後の壁は12m先から近づく
- 同じレッスンで **2回** 失敗したら、床に正解のドアへの矢印を出し、ハテナが「矢印の方へ」と言う
- **3回** 失敗したら、壁の速さを半分にする

### 1.7 画面の表示

- 上の真ん中：「① 基本操作」と進み具合の点（7つ）
- ハート（左上。本編と同じ表示）：1-5 で初めて出す
- 仕上げの間は「仕上げ 1/3」を上の真ん中に出す
- 本番の「正解数・問題数」の表示は出さない

### 1.8 ポーズ

- Esc で、本番と同じポーズ画面に「このレッスンをスキップ」を足したものを出す
- 『タイトルに戻る』を押すと、コースをやめてメニューへ戻る（スタンプは付かない）
- レッスンをスキップしても、最後まで行けばスタンプは付く

### 1.9 音と観客

- できたとき：本番の正解音と、小さな「ピコン」（チェック）
- 失敗したとき：本番の音（ハートが減る・水しぶき・サメ）のあと、まきもどしの音
- 観客は本番どおりに反応する

### 1-3 ドアをくぐる（約18秒）

**準備**
- 看板の壁は空へ戻る。前のさく（z = +8）を外す
- クイズ壁（2択）が22m先に落ちてくる。問題は「青いドアをくぐろう」、ドアは青「青」と赤「赤」。正解は青
- ハートは出さない。ミスしてもハートは減らない（まきもどしだけ）
- 壁が着地したら、コンベアが練習の速さで動き出す

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | 新しい壁へジャンプ。「壁が来るよ」 | 壁が落ちてくる |
| 着地から0.5秒後 | 問題パネルを指して「書いてあるとおりにくぐろう」 | コンベアが動き出す |
| 壁まで8mになっても、青のドアの前にいない | 「青いドアの前へ」 | |
| 青のドアをくぐる | 「OK。正しいドアなら先へ進める」 | 本番の正解の演出 |

| 失敗 | ハテナ | |
|---|---|---|
| 赤のドアをくぐる | 「それは赤いドアだよ」→「もう一回」 | まきもどし |
| 壁に当たる | 「ドアの間は壁だよ」→「もう一回」 | まきもどし |

### 1-5 ハート（約20秒）

**ねらい**：違うドアでも壁でもハートが1つ減り、0 になるとアウトだと分かる

**準備**
- ハートの表示が初めて出る（左上。ポンと出て光る）。ハートは3つ
- ここからは本番どおり：違うドアや壁でハートが1つ減り、のけぞって点滅し、観客が「あーっ」となる。その壁は消えて次へ進む
- **このレッスンだけ、ハートは1より減らない**

| きっかけ | ハテナ | 壁・画面 |
|---|---|---|
| 開始 | 左上を指して「左上がハート。最初は3つ」 | ハートがポンと出て、1つずつ光る |
| 2秒後 | 「違うドアや壁で1つ減る」 | |
| 2秒後 | 「0になったらアウトだよ」 | |
| 2秒後 | 次の壁へジャンプ。「1問解いてみよう」 | 壁「7 × 8 = ?」、ドアは青「56」（正解）・赤「54」 |
| 正解のドアをくぐる | 「正解。ハートはそのまま」 | 正解の演出 → 1-6 へ |
| 違うドア・壁 | 「ハートが1つ減ったね」→「練習だから戻しておくよ」 | ハートが1つ減り、そのあと3つに戻る（増える動き）→ 1-6 へ |

**メモ**：正解でも不正解でも先へ進む。ミスしたときだけ、本番と同じ減り方と観客の反応を見せる
