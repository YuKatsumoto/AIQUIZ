# コース④ 「オンライン対戦」 台本（v0.2）

2026-10-25。[計画書](plan.md) の 4章 ④を細かくしたもの。旧チュートリアルは参照していない。
共通の約束は [コース①の台本](course1_script.md) の1章、[コース②の台本](course2_script.md) の1章（練習のポーズ・画面のコーチ・記録を送らない）、[コース③の台本](course3_script.md) の1章（CPU）と同じ。

**v0.2（2026-10-25）**：①〜③と同じ方針で書き直した（漢字かな交じりの文、ハテナはくだけた口調、子どもっぽい演出を外して短く、練習の問題は一般常識くらい）。CPU が手をふる演出は外した（③と同じ）。オンラインの画面の本物のボタンや欄の名前は、画面の文字のまま『』で囲む（オンラインの画面そのものの文字は変えない）。v0.1 との違いは 7章。

## 0. このコースの ねらい

終わったとき、プレイヤーは次のことができる。

- オンラインの画面で、名前（本名を入れない・サイコロの二つ名）、遊ぶ問題、スキンを決められる
- ランダムマッチと、友だちコード（作る・入れる）の違いが分かる
- 試合のルールは2人対戦（コース③）と同じで、オンラインでは Esc で止まらず、途中でやめると相手の勝ちになると分かる

| # | レッスン | 場所 | 目安 |
|---|---|---|---|
| 4-1 | オンラインの画面 | オンラインの画面 | 15秒 |
| 4-2 | 名前 | オンラインの画面 | 25秒 |
| 4-3 | 遊ぶ問題 | オンラインの画面 | 15秒 |
| 4-4 | 相手の探し方 | オンラインの画面 | 30秒 |
| 4-5 | スキン | スキン設定の画面 | 25秒 |
| 4-6 | 練習試合 | マッチングの演出とステージ | 70秒 |
| — | クリア | オンラインの画面 | 10秒 |

合計 約3分10秒（失敗しなかった場合）。

## 1. ①〜③と違う約束

### 1.1 練習では通信しない

- 本物のオンラインの画面（`OnlineMenu`）を使うが、リレーにはつながない。画面の上の接続の表示には「● 練習中（つないでいません）」と出す
- 4-4 の『コードを つくる』『コードを いれる』は光らせて見せるだけで、押せない
- 4-6 の『ランダムマッチ』は、本物のマッチングの演出のあとで CPU との練習試合になる

### 1.2 ハテナ

- オンラインの画面の背景には、ヘリの操縦席に操縦士のハテナが座っている。そのハテナが雲に乗って出てきて、画面の右側（UI にかからない所）で案内する（②の 1.2 と同じ考え方）。終わったら操縦席へ戻る
- 練習試合のステージでは、①〜③と同じく、いまの壁の前に立つ

### 1.3 本物の設定として残すもの

- このコースで決めた名前（二つ名）とスキンは、本番でもそのまま使う（本物の画面で決めるので、すぐ保存される）

### 1.4 練習試合の見せ方

- 相手は CPU（コース③と同じ `PracticeCpu`。名札は「CPU」）。オンラインと同じ見せ方にする：マッチングの演出（短い形）、VS カットイン、本番の Esc の「たいせんを やめますか？」、オンラインの結果のカード
- ルールは2人対戦と同じ（のこぎり・押し合い・ゴーストシャークは本番どおり動く）。オンラインなので、移動は W A S D でも矢印キーでもよい
- Esc を押してもゲームは止まらない（本番どおり）。だから、壁と壁の間の落ち着いた所で Esc を教える

## 2. レッスンの台本

### 4-1 オンラインの画面（約15秒）

**ねらい**：ここでオンライン対戦の準備をすると分かる。練習ではつながないと分かる

**準備**：コースを選ぶと、本物のオンラインの画面（トップ）が開く。接続の表示は「● 練習中（つないでいません）」

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 画面が開く | ヘリから雲に乗って出てきて「ここがオンラインの画面」 | — |
| つぎ | 「離れた相手と対戦できる」 | — |
| つぎ | 「練習ではつながないよ」 | 接続の表示 |

### 4-2 名前（約25秒）

**ねらい**：相手に見える名前を決める。本名は入れない

**本編の決まり**：12文字まで・数字は3つまで・不適切な言葉や学校が分かる言葉は使えない（はじかれた名前は、相手には決まったニックネームで見える）

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「相手に見える名前」 | 『あなたの なまえ』の欄（打ちこんでもよい） |
| つぎ | 「本名は入れないで」 | 同じ欄 |
| つぎ | 「サイコロでも決められる」→ 押すまで待つ | 『サイコロで 二つ名』 |
| 二つ名が出た | 「OK」 | — |
| つぎ | 「不適切な言葉は使えない」 | — |

**クリア条件**：サイコロを1回振る

### 4-3 遊ぶ問題（約15秒）

**ねらい**：オンラインでも、教科・学年・むずかしさを自分で選ぶ。近い学年の相手と組まれる

**本編の決まり**：相手はモード・教科・学年のまとまり（1-2年・3-4年・5-6年）で探す。20秒たつと、同じ学年のまとまりのほかの教科の人とも組む

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「ここで問題を選ぶ」 | 『あそぶ もんだい』（きょうか・がくねん・むずかしさ） |
| つぎ | 「近い学年の相手と組まれる」 | 『がくねん』 |

### 4-4 相手の探し方（約30秒）

**ねらい**：知らない相手と遊ぶならランダムマッチ、友だちと遊ぶならコード

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「知らない相手と対戦するならここ」 | 『ランダムマッチ』（見せるだけ） |
| つぎ | 「友だちと遊ぶときは」→ 押すまで待つ | 『ともだちと あそぶ』 |
| ともだちのページが開く | 「コードを作って相手に伝える」 | 『コードを つくる』（見せるだけ） |
| つぎ | 「相手のコードを入れて参加」 | 『コードを いれる』（見せるだけ） |
| つぎ | 「コードは5文字」 | コードの欄 |
| つぎ | 「『← もどる』でトップへ」→ 押すまで待つ | 『← もどる』 |

### 4-5 スキン（約25秒）

**ねらい**：オンラインで相手に見える帽子と体の色を決める

**本編の決まり**：体の色はオンライン対戦だけで使う。トップで自分のキャラの横に立つ3Dの看板『スキン設定』から入り、決めたものはすぐ保存される

| きっかけ | ハテナ | 光る所 |
|---|---|---|
| 開始 | 「看板からスキンを変えられる」→ 押すまで待つ | 3Dの看板『スキン設定』 |
| スキン設定の画面 | 「帽子と体の色を選べる」 | 『ぼうし』の ◀ ▶ |
| つぎ | 「キャラをクリックしてもいい」 | 右に立つ自分のキャラ |
| 何か1つ変えた | 「いいね」 | — |
| つぎ | 「『✓ けってい』で戻る」→ 押すまで待つ | 『✓ けってい』 |

**クリア条件**：帽子か色を1つ変えて、『✓ けってい』を押す

### 4-6 練習試合（約70秒）

**ねらい**：マッチングから試合までの流れが分かる。オンラインでは止まれず、途中でやめると相手の勝ちになる

**準備**
- 壁2枚（30m間隔、本番の自動の速さ）。ハートは3つ、本番どおり
- 壁1：「13 + 29 = ?」、ドアは青「42」（正解）・赤「32」
- 壁2：「太陽が昇る方角は？」、ドアは青「西」・赤「東」（正解）
- CPU はふつうの速さで正解へ向かう（押し合いはしない）

| きっかけ | ハテナ | 画面・光る所 |
|---|---|---|
| 開始 | 「『ランダムマッチ』を押して」→ 押すまで待つ | 『ランダムマッチ』 |
| 押した | — | 本番のマッチングの演出（短い形）。下の帯に「あいてを さがしています…」 |
| 検索中 | 「相手を探しているところ」 | 3秒後に相手が見つかる |
| 見つかる | 「今回の相手はCPU」 | VS カットイン（「じぶん：（名前）」「あいて：CPU」） |
| ステージに着く | 「試合前はエモートであいさつできる」 | |
| つぎ | 「ルールは2人対戦と同じ」 | 本番のカウントダウン → スタート |
| 壁1 が終わる | 「オンラインでは一時停止できない」→「Escを押してみて」→ 押すまで待つ | |
| Esc を押す | 「やめると相手の勝ちになる」→「『つづける』を押して」→ 押すまで待つ | 本番の「たいせんを やめますか？（あいての かちに なります）」［つづける］［やめる］（［やめる］は押せない）。ゲームは止まらない |
| ［つづける］ | 「最後まで続けよう」 | 壁2 |
| 壁2 が終わる | — | 本番のオンラインの結果のカード（「🏆 あなたの かち！」など） |
| つぎ | 「終わるとこの画面に戻る」→ 押すまで待つ | 『オンラインメニューへ』 |
| オンラインの画面に戻る | → クリアへ | |

**失敗したとき**：ハートが0になる・海に落ちたときは、本番どおり負けの結果のカードになる。ハテナは「惜しい」と言い、そのまま『オンラインメニューへ』へ進む（やり直しはしない）

**メモ**：オンラインの試合は10問・ゴール・スコアタワーまであるが、コース③で教えたので、ここでは壁2枚で終わる

### クリア（約10秒。オンラインの画面の上で）

| 時刻 | ハテナ | 画面 |
|---|---|---|
| 0.0 | 雲で手前へ来て「オンラインの準備はこれで完了」 | |
| 1.5 | スタンプが押される | 「④ オンライン対戦」「クリア」 |

## 6. 決まったこと

2026-10-25（v0.1）：6つとも提案どおり。

1. **練習では通信しない**：ランダムマッチは CPU との練習試合にし、ともだちコードのボタンは見せるだけにする
2. **練習で決めたなまえとスキンは、本番の設定としてそのまま残す**
3. **練習試合は壁2枚だけ**：ゴールとスコアタワーはコース③で教えたので見せない
4. **Esc の「やめる？」は、本番どおりゲームを止めずに出す**
5. **クリアのあとの［ランダムマッチで あそぶ］**で、そのまま本当の対戦を探せるようにする
6. **「ほんとうの なまえは いれないで」**の一言を入れる（ランダムマッチでは知らない子ども同士がつながるため）

2026-10-25（v0.2）：①〜③と同じ方針で大人向けに書き直し。コース名は「④ オンライン対戦」。CPU が手をふる演出は外した
