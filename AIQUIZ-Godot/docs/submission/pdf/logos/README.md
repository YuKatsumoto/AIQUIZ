# 02 アピール資料で使う他社のロゴ

p4「問題生成ライン」の図で、どこで動いているかを示すために使う。どちらも 2026-11-01 に公式サイトから取得し、手を加えていない。

| ファイル | 元 | 使い方の決まり |
|---|---|---|
| `cloud-run.svg` | Google Cloud の公式プロダクト アイコン（<https://cloud.google.com/icons> の「コアプロダクト アイコン」`core-products-icons.zip` の `Unique Icons/Cloud Run/SVG/CloudRun-512-color-rgb.svg`） | 図や技術資料に使うアイコンとして配られている。形と色を変えない |
| `firebase-logomark.svg` | Firebase の公式ロゴ（<https://firebase.google.com/brand-guidelines> の `logo-logomark.svg`） | 形と色を変えない。高さ 24px 以上。同じ場所に Firebase のロゴを 2 つ置かない。Firebase が作品を推薦した・一緒に作ったように見せない |

- Gemini と Claude はロゴを使わず、名前の札にしている。
  Claude のロゴは Anthropic が事前に認めたものにしか使えない（<https://www.anthropic.com/legal/trademark-guidelines>）。
  Gemini のロゴを第三者が使ってよいとする Google の決まりは見つからなかった。
- スライドの下に商標の注記を入れている。
