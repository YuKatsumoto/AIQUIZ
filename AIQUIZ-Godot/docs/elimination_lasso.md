# 両者脱落の投げ縄（ハテナが2人をゴールへ運ぶ）

> **10問だけで使う（2026-11-04）**：ユーザーの指示で、この演出は10問チャレンジ（ローカル・オンライン）に残す。
> エンドレスの2人の両者脱落は投げ縄を使わず、暗転のあと海上の結果発表アリーナで結果発表する
> （`assets/result_arena/README.md`、`ResultArena`）。分かれ目は `GameWorld._uses_elimination_lasso`（エンドレスでは false）と
> `GameWorld._uses_result_arena`（エンドレスの両者脱落の結果発表だけ true）。

2人の10問（ローカル・オンライン）で2人とも脱落したとき、暗転で結果発表へ切り替える代わりに見せる演出。
結果発表の待ち時間（`RESULT_ELIMINATION_HOLD`）は待たず、2人とも体が砕けた瞬間（死んだ所が決まった瞬間。サメに乗って待っている人は
もう決まっている）に始める（`GameWorld._elimination_lasso_can_start_now`）。
死んだ所（体が砕けた所）から魂が抜け出し、**その場で浮かんだまま動かずに待つ**。雲に乗ったハテナ（カウボーイハット）が
2人の前に飛んできて投げ縄で捕まえ、コースの上を運んで、ゴールラインの先へラグドールのまま投げつける。
2人はその場で起き上がって自分のレーンへ歩き、そのまま結果発表（スコアタワー）の行進につながる。カメラはカットを使わない。

## 捕まえ方（2人の間の距離で変わる）

| 2人の間（水平） | 捕まえ方 |
|---|---|
| `ONE_LOOP_MAX_SEP`（4.5 m）以下で、高さの差も 1 m 以下 | 縄1本。輪を2人の並ぶ向きへ広げて（楕円）2人の頭の上から落とし、締めて2人をまとめる。魂は寄せない |
| それより離れている | 両手を左右へ広げて1本ずつ縄を回し、それぞれの魂へ同時に投げて1人ずつ締める。ハテナから見て右の魂が右手、左の魂が左手（縄は交差しない）。運ぶあいだはそれぞれの手から吊って運ぶ |

両手の2本の輪は、同じ向き・同じ角度で回す（左右対称に回すと、2つの輪が真ん中でぶつかる）。結び目を手から外へずらして
約2 m 離すので、輪（半径 0.62 m）はいつも間が空いたまま重ならない（`TWIN_PIVOT`・`TWIN_KNOT_OUT`・`TWIN_RADIUS`）。

両手の縄で運ぶあいだのぶん回し（`WHIRL_STYLE`）：ふだんは `WHIRL_NONE`（ぶん回さず、ふつうに吊って運ぶ）。切り替えると次も使える。
- 縦（`WHIRL_VERTICAL`）：両腕を風車のように同じ角度で回し、2人を左右それぞれ縦の円で振り回す（真下 → うしろ →
  真上を越えて → 前へ振り下ろす）。体は縄の向きに伸び、振り下ろすたびにハテナが前へのめる。
- 横（`WHIRL_HORIZONTAL`）：雲ごと回り、2人は円すい振り子として縄の先でほぼ水平に振り出される。

どちらも、いちばん速いとき `WHIRL_REV` 回/秒。門の手前へ降りながら回すのをやめ、回し終わりでちょうど真下（横なら前向き）に
なる（`_whirl_scale` で回数を合わせる）ので、2人はそれぞれの手の下にぶら下がり、振り上げ・振り抜きにつながる。

## サメに乗った幽霊がいるとき

先に脱落した人がゴーストのサメに乗って照準を合わせているあいだ（`GhostSharkRideController` の AIMING・WINDUP）に、
もう一人も脱落したら、乗り手は片付けずに、サメに乗ったまま空中で待たせる（`hold_for_elimination_lasso`。GameWorld が
GAME_OVER になったときに呼ぶ）。投げ縄はその乗り手を、死んだ所ではなくサメの上の魂として捕まえる：

- 輪は、サメに乗ったままの乗り手の頭の上から落ちて、乗ったまま胸で締まる。
- 縄で引き上げる瞬間（縄1本で2人まとめるなら、締めて引き寄せる瞬間）に、乗り手を鞍から引きはがして受け取り
  （`take_lasso_rider`）、乗っていた小さい姿から元の大きさへ戻す。サメは海へ潜って元の泳ぎに戻る。
- 投げ縄が始まらなかったとき（素材がない）は、今まで通り結果発表が乗り手を受け取る。

魂が出てくる所は `PlayerController.get_death_origin_position`（体が砕けた瞬間の破片の真ん中）。破片はそのあと海まで
飛ぶことがあるので、今の体の位置は使わない。魂は捕まるまで真上へ浮かんで小さく上下するだけで、横へは動かない。

## 流れ（秒。`EliminationLassoDirector` の `T_*`。テンポよく、約12秒で結果発表へ）

| 時刻 | できごと |
|---|---|
| 0.0〜0.7 | 魂が死んだ所からあお向けで抜け出し、起き上がって真上へ浮かぶ（その場から動かない） |
| 0.05〜1.3 | 雲がコースの先の空から一気に降りてきて、2人の前の上に止まり、2人（うしろのカメラ）の方を向く |
| 1.2〜2.55 | ハテナが縄を頭上で回す（両手なら2本を鏡うつしに）。最後の1周で溜める |
| 2.55〜3.44 | 投げる → 輪が開いて頭を越えて落ちる → 引いて締める（広げた輪なら、締めると2人が引き寄せられてくっつく） |
| 3.56〜7.7 | 真上へ吊り上げ、壁より高く飛ぶ。吊り上げてすぐコースを流し始め（加速 → 一定 → 減速）、ゴールの門を呼び寄せる |
| 6.75〜8.1 | 門の手前へ降り、縄で2人をうしろへ振り上げて、前へ振り抜いて放す |
| 8.1〜 | 2人はラグドール（`LassoSoulRagdoll`）で回りながら飛び、ゴールラインの先に叩きつけられて転がる |
| 止まったら | その場で起き上がる（あお向け：上体→しゃがむ→立つ／うつ伏せ：腕で押し上げ→四つんばい→立つ） |
| 立ったら | 自分のレーンへ歩く。2人とも着いたら結果発表（`begin_elimination_result_ceremony`） |

このゲームは床がベルトコンベアで、ふだんは客席が止まったまま床・壁・ゴールだけが流れる。運ぶあいだはそれだと飛んで
いるように見えないので、左右の客席（柵と観客ごと）もコースと同じだけ後ろへ流す（`GameWorld` が
`StageEnvironment.set_grandstand_shift` を呼ぶ）。客席はコースの全長ぶん並んでいるので、下げても前は途切れない。
結果発表のあいだは流し終えた所のままにし、次の試合の始まり（メニュー・読み込み・開始待ち）で元へ戻す。
雲のかけらも景色と同じ速さで後ろへ流し（`LassoCloudRider.set_flow`）、雲の表面のなびきも景色の流れの速さを入れる。

2人をまとめた束は、運ぶあいだに回って P1 を +X（P1 のレーンの側）へ向ける。両手の縄で P1 が −X の側に来たときは、
P1 を高い弧・P2 を低い弧で投げて、交差してもぶつからないようにする。
ハテナは放したあと小さな輪を回しながら、下りながら前へ進んで2人の頭の上を越え、ゴール観客席の手前で横へ大きく傾いて
旋回し、横のスタンドの上を越えるように上りながら海の上へ飛び去る（`_plan_exit`）。遠くへ行ったら小さくなって消える（`T_END`）。結果発表の最初のカメラ（`CameraController.result_ceremony_camera_pose`）へ
寄せてから渡すので、引き継ぎでカメラは動かない。魂はそのまま結果発表の幽霊になる（`ResultCeremonyDirector.soul_source`）。

## カメラ

寄り（ズーム）や回り込みはしない。動くのは必要なときだけ：

1. ゲームオーバーのカメラから一度だけ、2人・止まったハテナ・広げた輪が収まる画（2人のうしろの上）へ寄せ、捕まえるまで動かさない。
   雲はその画の中へ飛んできて、ハテナはカメラの方を向いて縄を回す。
2. 吊り上げてからは、斜めうしろからハテナと吊られた2人を追う（雲の速さのぶん先回りして、画面から外さない）。
   向こう側の客席が後ろへ流れていくのが映る。流れてくる壁の近くでは、カメラは壁の上を通る。
3. 門の手前の斜めうしろの低い所から門越しに投げつけを見て、結果発表の最初のカメラへ寄せる。

## 確かめ方

```powershell
./Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1280x720 --fixed-fps 60 --script res://tests/elimination_lasso_bootstrap.gd -- fps=60 quality=high every=0.25 spread=near
```

`artifacts/elimination_lasso/runtime/` に画像と `report.json`。`spread=same|near|far`（同じ扉・隣の扉・離れた扉）で
捕まえ方が変わる。`near_swap` / `far_swap` は P1 と P2 の左右を入れかえる。`rider=1|2` は、その人が先に脱落して
ゴーストのサメに乗り、照準を合わせているところでもう一人も脱落する。脱落の瞬間から撮るなら `pre=0.25`。
区間だけ撮るなら `from=6 to=9`、ハテナの寄りは `view=hatena_right`。
確かめること：魂が死んだ所から動かない（`soul1_drift` / `soul2_drift`）、ハテナが到着から投げつけまで画面に入っている
（`hatena_onscreen`）、客席がコースと同じだけ流れる（`stand_shift` と `scrolled`）、吊られた2人が壁の上を越える
（`wall_clearance`）、カメラが飛ばない、結果発表へそのまま渡る。`every=0.0333` で撮ると、30fps の連番から動画にできる。
結果発表まで通すなら `tests/result_ceremony_bootstrap.gd -- runtime case=elimination`。
