# 8連チップソーと走行レール

Desktop側プロジェクトへの実装。ローカル2Pの「10問」「エンドレス」で、従来の前後差による脱落を8枚の刃への接触に置き換える。1P・協力・オンラインには共通レールの外観だけを適用する。

ユーザーの最終指定に従い、追加の画面下部テキスト（刃までの距離／ジャンプ回避不可）は表示しない。危険度に応じた既存HUDの色とカメラ収容は有効。

## ゲーム状態と表示

- `scripts/core/saw_chase_state.gd` がベルト基準のZ、回転時間、実移動距離を保持する。`QuizGameState` が対象者と接触・脱落を確定する。
- 初期Zは−10.85m。PLAYING開始後2秒の猶予を設け、刃の前端が先行者の14m後方へ近づく。速度上限10m/s、後退と目標の追い越しはしない。これらと警告距離6mは `GameTuning` で調整できる。
- 接触は8円盤とプレイヤー半径の平面上の相対移動区間で検査する。高さを無視し、HPに関係なく脱落。同時接触は両者のフラグを先に確定する。落下確定・サメ待機者を追跡対象から除き、生存者への追跡を継続する。
- 問題生成・開始待ち・フライオーバーでも刃を表示。ヘリからの降下中は停止し、両プレイヤーの床接触を確認したら約4秒かけて90rpmまで加速する。生成待ち・開始待ち・カウントダウンを通して回転を継続し、カウントダウンで再始動しない。着地演出を省くリトライではステージ配置後から加速する。追跡の開始条件・2秒の猶予は変更しない。ポーズ・プレイ途中の問題取得待ち・結果状態では回転角を保持する。
- メインメニューは初表示時に後端ドックから台車を搬出し、定位置Z=6.35mで約4秒かけて90rpmへ加速する。再入場では配置済みから始める。メニューのキャラクターへの死亡判定は追加しない。
- ジャンプ中のプレイヤーが刃の円盤と重なり、死亡が確定する範囲（`clearance <= 0`）に入ってから、その刃だけを伸縮支柱で持ち上げる（`SawChaseState.catch_reach`）。手前では上げない。接触判定の直後は、掃引判定で刃をわずかに通り過ぎた位置でも持ち上がるよう0.5mの余裕を持つ。接触時の高さを短く保持してから下降する。
- 刃による脱落は専用フラグと `player_caught_by_saw` 通知を使う。`SawCatchRagdoll` が脱力した身体を接触した刃へ物理的に引き込み、刃の回転方向へ巻き込む。約0.52秒から脚・腕を時間差で切り離し、1.15秒で同じ14個の物理ボディを分散部位へ引き継ぐ。死亡ワイプとゴーストシャークへ接続し、通常の壁死は従来の2秒を維持する。
- 巻き込み中は空中接触時の刃の高さを保持する。ボディと分散部位は問題壁へのCCDを維持し、ポーズで停止する。検証は `tests/saw_catch_runtime.gd`、映像・ログは `artifacts/saw_catch/`。
- 問題壁の見えている部材・閉じたドアに専用物理レイヤー16を付け、刃によって飛ばされた身体と破片が衝突する。身体の連続衝突検出を有効化し、壊れたドアと退場した壁の判定は解除する。
- 赤い警告点滅は毎フレームの時間と点滅速度を積算する。距離変化で位相が飛ぶ現象を解消する。
- `SawChaseController` は同じ状態を読み、モデル位置・刃回転・車輪回転を描画する。判定を持たない。車輪角度は実移動距離÷半径0.18m。

## 作業船による搬入（2026-09-19）

`SawDockPresentation` は表示専用の船と機構。`assets/hazards/saw_service_vessel.glb` は濃紺の鋼製船体、白い船橋、黄色の昇降機構を持つ大型作業船。船と台車の座標を独立管理する。ベルト・後端ローラー・戻りベルトには穴を開けず、当たり判定と歩ける床は拡張しない。本編の接岸時の昇降中心Z=-15.65m、搬出先Z=-10.85m。海面Y=-9.2m、甲板Y=-6.0m、コンベア床Y=-1.2m。甲板は海面上3.2m、昇降量4.8m、有効台寸法25×3.7m。メニューは向きを反転し、昇降中心Z=11.15m、定位置Z=6.35m。

0–2.25秒に10m手前から減速接近する。シャッターは廃止し、船が完全停止してから台を上げる（2.35–4.20秒）。4.20–4.42秒に接続レール・固定ピンを展開、4.42–6.20秒に台車を4.8m搬出する。後輪通過後に固定を解除し、6.30–6.50秒で接続レールを収納する。停船したまま6.55–8.40秒に台を下げる。9.00–15.00秒に42m後退する。`is_deployed()` は6.20秒の台車搬出完了、`has_departed()` は15.00秒の離岸完了を示す。

昇降中は船体の平行移動・傾斜・上下動をすべて停止する。接近時は航行速度から滑らかに減速し、各機構を短い間隔で引き継ぐ。油圧音の強さとピッチを実際の動作速度へ、エンジン音と航跡を航行速度へ合わせる。搬出後の船体移動を台車や車輪へ加算しない。

通常開始はヘリの可視到着フェーズから進行し、事前レンダリング中は時計を止める。配置完了と両プレイヤーの床接触の両方が成立してから既存の刃加速へ接続する。自然なヘリ到着完了で昇降を打ち切らない。明示的な入場省略・開始操作では配置済みに復元する。離岸を開始待ち条件に追加しない。開始後の追跡猶予・衝突・リプレイ形式を維持する。

メニュー初回はQuizManagerのセッション内メタデータで管理し、画面が見えるまで進行させない。非表示中は時計と音を止める。再入場・リトライ・ヘリ省略では船を非表示にして台車を配置済みに復元する。SFXバスに独自合成のディーゼルエンジン音と既存のモーター・固定音を使用し、刃の音源は台車を追従する。全音源をPAUSABLEに設定し、GameWorldの常時処理から独立させる。

船の入港でカメラ位置は引かない（2026-10-18に廃止。以前は12m引いた位置(-21.791,9.003,34.159)へ動かし、本編準備画面も後方1.5m・上方0.5mの補正を加えていた）。メニューは船がいる間、俯角だけ従来値へ寄せ、船が後退を始める9.00秒から離岸と同じ加減速で元の俯角へ戻す。Start後のヘリ離陸・カスタマイズのカメラ制御は維持する。

船の編集用原本：`artifacts/saw_vessel/saw_service_vessel.blend`。既存ドック原本 `artifacts/saw_dock/saw_service_dock.blend` を保持し、独立シーン `SawVessel_Workshop` に作成した。今回の改修で船体を長さ29.15m・幅26.8mへ整え、傾斜窓と窓枠、船橋通路・階段、排気設備、係船機、ホースリール、救命設備、防舷材、油圧支持・締結部を追加した。塗装・粗さ・甲板の滑り止めに実寸UVのPBRマップを使用する。可動階層と60fps・18秒の確認用アニメーションを保持する。

Higgsfield Bridgeで制作、Blender MCPで構造・寸法・動作を検証。有料生成は使用していない。GLBは参照台車と撮影セットを除き、可動部の階層を維持して材質ごとに統合した51メッシュ・190,322三角形。編集原本では955個のメッシュとモディファイアを保持する。`tools/saw_dock/build_vessel.py` が基礎構築・出力・アニメーション、`refine_vessel.py` が段階的な改修、`vessel_finishes.py` がPBR画像を担当する。

- メニューの収納（壁速度タブ）中はメニューの追走・プレビュー時計が止まるため、`SawChaseController.advance_stow` が収納時計pから操縦席を更新する。BLADEスティックで収納／展開を指令し、起き上がる門型と持ち上がる束を見上げ、束が頭上を通る間（サイドカーの `station_airspace`）は頭を押さえてかがみ、背後への吊り下ろしを振り返り、固定でうなずく。格納中は待機しぐさを収納休止時計で再生し、展開はpを逆にたどる。

検証は `tests/saw_operator_acceptance.gd`（232項目、収納・途中反転・格納休止・展開を含む）ほか既存の追走・ドック・椅子ロケット・メニュー・格納テストと実シーン撮影。結果と動画は `artifacts/saw_operator/v3/report.md`。

## 操縦盤v2とメニュー追走（2026-09-20）

左側は走行用、右側は刃昇降用。走行速度の符号で前進・中立・後退を表し、昇降レバーは高さではなく刃の変位速度で動く。保持中は中立、計器針は実際の高さを示す。最大変位の刃を選び、同量は物理的な左側を優先する。操作対象変更で反対方向へ入力が飛ぶ場合も、レバー・手・足の共通入力を連続的に移行する。リプレイは直前0.24秒と隣接記録から表示入力を復元するため、シーク順序に依存せず、34項目の記録形式を維持する。

`MenuSawChaseState` はメニュー専用の追走・巻き込み・後退復帰・復活待ち・猶予を管理する。本編の追走状態と衝突の進行処理は変更しない。搬出と4秒の回転加速後、生存者のうち最小ローカルZを先頭とし、刃前端から5mの距離を目標に最大2m/sで前進する。先頭が戻った場合は停止する。

通常の後退は身体と刃の間に1.25mを残して制限し、近づいた場合は前へ逃げる。海落下のための後退も、刃で経路が塞がれていれば中断する。台車は先頭を追うと同時に最後尾にも1.25mの安全距離を残す。距離不足時は停止し、通常時の後退は行わない。

メニュー表示後20秒は事故を選ばない。その後は1人／2人共通の10秒間隔で1回だけ抽選し、15%で刃に届く1人の後退事故を試みる。別の25%は安全距離で気づいて前へ逃げる「ヒヤリ」、残りは何もしない。接触したときだけ本編と同じ巻き込み・ラグドール・分散へ接続し、ジャンプ時の刃上昇と操縦も維持する。復帰・復活が終わった着地時点から45〜60秒間は新たな事故行動を休止する。抽選は表示中のAI時間で進み、非表示やカスタマイズの後にまとめて実行しない。事故頻度は到達可能性や他のAI行動にも依存し、固定時刻に死亡させない。

刃死亡は同フレーム分を1つの被害者マスクへまとめ、巻き込み終了後に2.5m/sで端へ後退する。復帰中は追加接触を無効化し、到着後に既存の上空からの復活を許可する。壁と刃を避けて着地してから2秒待ち、追走を再開する。壁・海での死亡は後退復帰を起こさない。非表示・カスタマイズ・退出／ヘリ搭乗中は追走と事故を止め、Start時は刃死亡と復帰待ちを解消して既存の搭乗へ引き渡す。

## 壁速度タブの収納（2026-10-28、v3：門型クレーン）

メニューのカスタマイズ（壁速度タブ）を開くと、8枚の刃を場外へ収納する。閉じると同じ経路で展開する。

v2 は四隅の昇降塔（ダビット）が刃列を吊って操縦席の上を越えていたが、作り直した。v2 の問題点：

- 所要12.42秒と長い。
- 塔の旋回・桁の折り畳み・フライ・クランプが重なり、何をしているのか分かりにくい。
- 塔が通常プレイでも立って見えていた。

ユーザーと決めた方針：

- 門型クレーンで吊って場外へ運ぶ。
- 通常時はほぼ見えない場所に格納する。
- ブロックアウトの動きを確認・承認のうえで本制作した。

### 機構

- 台車の左右端に、2本脚と y 方向の頭梁からなる門型クレーンが1基ずつある。
- 脚は伸縮2段で、ヒンジから頭梁中心まで 4.0〜6.8m。
- 頭梁には巻き上げ機・シーブ・警告灯（`MAT_BeaconLens`）が付く。
- ロープの先に、フックブロックと、旋回するスプレッダーがある。
- スプレッダーの4組の爪が、立てた刃の上縁を挟む。
- 刃側の機構（ラムで持ち上げ、トラニオンで90°起こし、モジュールごと両端へ寄せる）は v2 のものを流用した。

通常時（格納状態）：

- 門型はコンベアの外側面に吊り下げる（鉛直から外側へ3°、下端は z −3.9）。
- ベルト面より上に出るのは、ヒンジのドラムと取付板（z 0.58 まで）だけ。
- フックとスプレッダーは門型の内側にドックしている。
- この姿勢が GLB の基準姿勢で、本編・メニューとも何もしなければこの姿になる。

作業船で搬入中：

- 門型は直立して乗る（`Gantry_Upright` クリップ、内側へ2°）。
- 搬出完了（6.20秒）の0.10秒後から1.6秒かけて、外側を回って側面へ倒れる。
- 倒れる経路と収納の起き上がりは、どちらも操縦席の外側を通る。ドック中に操縦席の y 帯を横切る部品を、ヒンジから2.85m以上離したため（収縮長4.0m の理由）。

### 動き

所要6.55秒。

1. ホーンが鳴り、刃にブレーキがかかる（0.85秒）。
2. 門型が側面から外側を回って起き上がる。止まらずに内側へ乗り出す（0〜2.85秒）。
3. その途中で伸び、フックが外れて垂れ、スプレッダーが90°回る。
4. 並行して、刃が持ち上がって立ち、両端へ寄って4枚ずつの束になる。
5. 乗り出しの終わりに重ねて、スプレッダーを真下へ下ろし、爪で掴む（〜3.25秒、固定音）。
6. 束を持ち上げながら振り出す。束は斜め上へ出て弧を描き、操縦席の上を刃の下端2.5m以上で通る。
7. 振り出しの終わりに重ねて、ロープで巻き下げる。刃中心は −1.90、上端はベルト面の0.45m下。
8. 固定する（6.40秒、固定音）。警告灯が消える。
9. 空のクレビスは、束が離れた後に起こしを戻し、ラムを縮める。

各動作は、前の動作の減速中に次が始まるよう重ねてある。2026-10-28 のユーザー指摘「一連のアニメーションが分離している」への対応。速度がゼロに戻るのは、爪で掴む一瞬と最後の固定だけ。

補足：

- 展開は運動学を時間反転したもの。
- 吊り荷の揺れ（最大約3°）は、展開の時間順で計算し直している。
- 揺れは、刃を掴む・置く・ドック・固定の各瞬間で0になる。
- 最高速度：起き上がる門型の先端が 10.0m/s、刃の中心が 6.0m/s。

### Godot側（`SawChaseController`）

収納時計：

- 時計 p（0＝展開、6.55＝収納完了）を、1/240秒の固定刻みで等速（`STOW_SPEED`=1.0）に進める。
- 反転時は、機械の速度を `STOW_REVERSE_ACCEL`（8m/s²）で落としてから、反対のクリップへ0.35秒でクロスフェードする。
- 24fps のキーは、読み込み時に3次補間へ切り替える。キー間の速度の段差をなくすため。

門型の格納：

- `gantry_upright_weight()`：作業船上では1。搬出後に1.6秒で0になる。
- `_step_gantry_fold` は、本編の `update_visual` とメニューの `advance_stow` で進める。
- 適用はヒンジ根元ボーンの slerp で行い、外側を回る179°の弧をとる。
- リトライ・入場省略では、最初から格納状態になる。
- 収納は、門型が倒れ終わるまで始まらない。

サイドカーの値（`linked_saw_carriage_stow.json`）：

| 項目 | 値 |
|---|---|
| 壁の手前破砕（`wall_block`） | 0.58〜4.71秒、奥行き半分 2.0m |
| 操縦席の上（`station_airspace`） | 4.00〜5.08秒 |
| 椅子の柱（`chair_column`） | 1.42〜5.08秒 |
| 速度曲線 | 30Hz |

操縦者は `station_airspace` を受け取り、かがむ区間を決める。

v2 から変えていないもの：

- 効果音、警告灯の点滅、刃の回転の減速。
- 追走による持ち上げの戻し、台車のベルト端への後退。
- 公開API（`stow_target`、`advance_stow`、`is_stow_clear`、`is_fully_stowed`、`stow_time`、`stow_length`、`stow_brake_seconds`、`stow_blocks_walls`、`wall_reach_y`、`rack_over_station`、`chair_launch_clear`、`beacons_lit`）。追加したのは `gantry_upright_weight` だけ。
