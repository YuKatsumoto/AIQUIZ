# 8連チップソーと走行レール

Desktop側プロジェクトへの実装。ローカル2Pの「10問」「エンドレス」で、従来の前後差による脱落を8枚の刃への接触に置き換える。1P・協力・オンライン・チュートリアルには共通レールの外観だけを適用する。

ユーザーの最終指定に従い、追加の画面下部テキスト（刃までの距離／ジャンプ回避不可）は表示しない。危険度に応じた既存HUDの色とカメラ収容は有効。

## ゲーム状態と表示

- `scripts/core/saw_chase_state.gd` がベルト基準のZ、回転時間、実移動距離を保持する。`QuizGameState` が対象者と接触・脱落を確定する。
- 初期Zは−10.85m。PLAYING開始後2秒の猶予を設け、刃の前端が先行者の14m後方へ近づく。速度上限10m/s、後退と目標の追い越しはしない。これらと警告距離6mは `GameTuning` で調整できる。
- 接触は8円盤とプレイヤー半径の平面上の相対移動区間で検査する。高さを無視し、HPに関係なく脱落。同時接触は両者のフラグを先に確定する。落下確定・サメ待機者を追跡対象から除き、生存者への追跡を継続する。
- 問題生成・開始待ち・フライオーバーでも刃を表示。ヘリからの降下中は停止し、両プレイヤーの床接触を確認したら約4秒かけて90rpmまで加速する。生成待ち・開始待ち・カウントダウンを通して回転を継続し、カウントダウンで再始動しない。着地演出を省くリトライではステージ配置後から加速する。追跡の開始条件・2秒の猶予は変更しない。ポーズ・プレイ途中の問題取得待ち・結果状態では回転角を保持する。
- メインメニューは初表示時に後端ドックから台車を搬出し、定位置Z=6.35mで約4秒かけて90rpmへ加速する。再入場では配置済みから始める。メニューのキャラクターへの死亡判定は追加しない。
- ジャンプで近づいた位置の刃だけを伸縮支柱で持ち上げる。接触時の高さを短く保持してから下降する。
- 刃による脱落は専用フラグと `player_caught_by_saw` 通知を使う。`SawCatchRagdoll` が脱力した身体を接触した刃へ物理的に引き込み、刃の回転方向へ巻き込む。約0.52秒から脚・腕を時間差で切り離し、1.15秒で同じ14個の物理ボディを分散部位へ引き継ぐ。死亡ワイプとゴーストシャークへ接続し、通常の壁死は従来の2秒を維持する。
- 巻き込み中は空中接触時の刃の高さを保持する。ボディと分散部位は問題壁へのCCDを維持し、ポーズで停止する。検証は `tests/saw_catch_runtime.gd`、映像・ログは `artifacts/saw_catch/`。
- 問題壁の見えている部材・閉じたドアに専用物理レイヤー16を付け、刃によって飛ばされた身体と破片が衝突する。身体の連続衝突検出を有効化し、壊れたドアと退場した壁の判定は解除する。
- 赤い警告点滅は毎フレームの時間と点滅速度を積算する。距離変化で位相が飛ぶ現象を解消する。
- `SawChaseController` は同じ状態を読み、モデル位置・刃回転・車輪回転を描画する。判定を持たない。車輪角度は実移動距離÷半径0.18m。

## レールとモデル

`ConveyorRails` を本編・メニューのステージ・カスタマイズから共用する。レール中心X=±11.86m、走行面幅0.16m、床から上面まで0.26m。支持部と暗色台座を含むT字断面で、コリジョンは持たない。コース延長時に長さと終端キャップを更新する。夜間灯を外側ブラケットへ移設した。

ゲームアセットは `assets/hazards/linked_saw_carriage.glb`。8枚・直径2.9m・中心間隔3m・刃面高さ0.36m。車輪中心はX=±11.86m、床上0.44m、前後位置±1.45m。既存の24枚刃・銀色研磨面・赤い印字を保持する。

Blender原本は `artifacts/chip_saw/carriage/linked_saw_carriage.blend`、適合後の保存先は同ディレクトリの `linked_saw_carriage_game.blend`。`fit_game_rails.py` は原本を開いた状態で実行する再生成スクリプト。保存・選択した機構のみのGLB出力・寸法JSON・接写を生成する。撮影セットと固定レールはGLBに含めない。

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background artifacts/chip_saw/carriage/linked_saw_carriage.blend --python artifacts/chip_saw/carriage/fit_game_rails.py
```

Blenderの `Spin_Loop` はGodotの自動命名処理により `Spin` として取り込まれる場合があるため、両名を認識する。原本は約3.333秒で1回転＝18rpm。ゲーム側で5倍速の90rpmとして評価する。文字だけでなく刃メッシュも回転する。`Advance_Demo` はゲームでは再生しない。Blenderの+YをGodotの+Zに合わせる回転を表示ルートに適用する。

## 作業船による搬入（2026-09-19）

`SawDockPresentation` は表示専用の船と機構。`assets/hazards/saw_service_vessel.glb` は濃紺の鋼製船体、白い船橋、黄色の昇降機構を持つ大型作業船。船と台車の座標を独立管理する。ベルト・後端ローラー・戻りベルトには穴を開けず、当たり判定と歩ける床は拡張しない。本編の接岸時の昇降中心Z=-15.65m、搬出先Z=-10.85m。海面Y=-9.2m、甲板Y=-6.0m、コンベア床Y=-1.2m。甲板は海面上3.2m、昇降量4.8m、有効台寸法25×3.7m。メニューは向きを反転し、昇降中心Z=11.15m、定位置Z=6.35m。

0–2.25秒に10m手前から減速接近する。接岸直前からシャッターを開き（1.45–2.30秒）、船が完全停止してから台を上げる（2.35–4.20秒）。4.20–4.42秒に接続レール・固定ピンを展開、4.42–6.20秒に台車を4.8m搬出する。後輪通過後に固定を解除し、6.30–6.50秒で接続レールを収納する。停船したまま6.55–8.40秒に台を下げる。シャッターは開いたまま維持し、9.00–15.00秒に42m後退する。`is_deployed()` は6.20秒の台車搬出完了、`has_departed()` は15.00秒の離岸完了を示す。

昇降中は船体の平行移動・傾斜・上下動をすべて停止する。接近時は航行速度から滑らかに減速し、各機構を短い間隔で引き継ぐ。油圧・シャッター音の強さとピッチを実際の動作速度へ、エンジン音と航跡を航行速度へ合わせる。搬出後の船体移動を台車や車輪へ加算しない。

通常開始はヘリの可視到着フェーズから進行し、事前レンダリング中は時計を止める。配置完了と両プレイヤーの床接触の両方が成立してから既存の刃加速へ接続する。自然なヘリ到着完了で昇降を打ち切らない。明示的な入場省略・開始操作では配置済みに復元する。離岸を開始待ち条件に追加しない。開始後の追跡猶予・衝突・リプレイ形式を維持する。

メニュー初回はQuizManagerのセッション内メタデータで管理し、画面が見えるまで進行させない。非表示中は時計と音を止める。再入場・リトライ・ヘリ省略では船を非表示にして台車を配置済みに復元する。SFXバスに独自合成のディーゼルエンジン音と既存のモーター・固定音を使用し、刃の音源は台車を追従する。全音源をPAUSABLEに設定し、GameWorldの常時処理から独立させる。

メニューは船がいる間、元の視線・FOVを保って12m引いた位置(-21.791,9.003,34.159)で固定する。船が後退を始める9.00秒から、離岸と同じ加減速で元の位置(-18,6.1,23.15)へ近づき、15.00秒に復帰する。Start後のヘリ離陸・カスタマイズのカメラ制御を維持する。本編準備画面は搬入中のみ後方1.5m・上方0.5mの小さな補正を加え、6.20–9.00秒で戻す。リトライ・対象外モードは従来の画角。

船の編集用原本：`artifacts/saw_vessel/saw_service_vessel.blend`。既存ドック原本 `artifacts/saw_dock/saw_service_dock.blend` を保持し、独立シーン `SawVessel_Workshop` に作成した。今回の改修で船体を長さ29.15m・幅26.8mへ整え、傾斜窓と窓枠、船橋通路・階段、排気設備、係船機、ホースリール、救命設備、防舷材、油圧支持・締結部を追加した。塗装・粗さ・甲板の滑り止めに実寸UVのPBRマップを使用する。可動階層と60fps・18秒の確認用アニメーションを保持する。

Higgsfield Bridgeで制作、Blender MCPで構造・寸法・動作を検証。有料生成は使用していない。GLBは参照台車と撮影セットを除き、可動部の階層を維持して材質ごとに統合した51メッシュ・190,322三角形。編集原本では955個のメッシュとモディファイアを保持する。`tools/saw_dock/build_vessel.py` が基礎構築・出力・アニメーション、`refine_vessel.py` が段階的な改修、`vessel_finishes.py` がPBR画像を担当する。

最新の実ゲーム動画・主要画像・検証ログは `artifacts/saw_vessel/revision2/`。`menu_entrance.mp4` / `game_entrance.mp4` は通常画角の実ゲーム画像列から生成した無音映像。`unit.json` は24/30/60/120fpsの4,216姿勢・127,410アサーション。`mechanics.json` は実モデルの停船昇降・車輪支持・接続レール・音、`fps_suite.json` は実ランタイム各fps設定、`navigation.json` はリトライ・即Start・ポーズ・メニュー復帰、`regression.json` は既存物理・刃昇降・対象モードの検証。詳細は同フォルダーの `README.md`。
