# AIQUIZ Santorini caldera town

Original stylized Cycladic architecture, authored for the sea stage in AIQUIZ.
The geometry and all 22 authoring material colors are generated by the editable
Blender builder. No downloaded model, texture, paid asset or generative API was
used. Reference photographs informed architectural shapes and composition;
their pixels are not embedded in this asset.

## Files

- `aiquiz_santorini_town.glb`: game-ready geometry, with separate terrain,
  architecture and garden meshes for each of 13 named districts.
- `town_layout.tscn`: Godot-owned integration scene, authored/saved through the
  connected Godot editor. `Districts` has editable children for district placement.
  Its `santorini_vertex_palette.gd` tool script keeps imported vertex colors active
  in both the standalone editor scene and the game.
- `source/aiquiz_santorini_town.blend`: editable Blender scene. Export geometry
  is in `EXPORT | Town districts and cliff terrain`; the sea, lights and camera
  are in `REVIEW ONLY | Sea lights cameras` and excluded from GLB export.
- `source/build_santorini_town.py`: deterministic, editable construction source.
- `source/build_report.json`: actual counts, bounds, layout and building sites
  from the current build. Treat this generated report as authoritative for counts.
- `source/export_validation.json`: raw GLB buffer checks, palette and independent
  Blender GLB round-trip render agreement, including the exported asset SHA-256.
- `source/ASSET_SOURCES.csv`: asset provenance.
- `source/previews/`: Blender lighting/composition reviews, not Godot runtime evidence.

## Rebuild

From the Godot project root, in a separate background process:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --factory-startup --python assets/environment/santorini_town/source/build_santorini_town.py
```

The script operates on its isolated factory-startup process, creates a new scene,
and never connects to the user's running Blender instance. The seed is 9132026.
`source/.gdignore` prevents Blender sources and preview images from being imported
as runtime assets. The exporter explicitly selects only town meshes.

## Coordinates and integration

One unit is one metre. Blender is Z-up. The glTF exporter converts to Godot Y-up;
the local sea level is zero. Place the root at `Y = -9.2` to match the game's
ocean. The central course runs in Godot `+Z`. For all geometry with `Z > -150`,
the builder verifies `abs(X) >= 70`. This includes ornamental boats, piers and
outcrops, not only the building centers. The actual minimum and complete bounds
are written to the report. The asset has no collision shapes or navigation mesh.

District mesh names end in `__Terrain`, `__Architecture`, or `__Gardens`, allowing
separate culling and shadow policy. Shared opaque emission materials are named
`Santorini Window Warm Glass` and `Santorini Lantern Warm Bulb`; the runtime can
adjust their emission by the existing weather/night cycle. Other materials retain
normal lit plaster, cobalt, limestone, volcanic rock, wood and foliage shading.

For runtime export, the static colors are baked into glTF vertex colors and
consolidated into four shared lit palette materials grouped by the original
roughness. The two emission materials stay separate. This reduces the material
surface count while preserving the detailed geometry, color palette and roughness.
Static colors are stored as standard normalized RGBA8 attributes, limiting color
quantization to one step out of 255 in linear color and reducing buffer bandwidth.
The `.blend` keeps all original named authoring materials for editing.

## Architectural scope

The library has seven principal dwelling forms: flat parapet roof, rooftop room,
white barrel vault, small domestic dome, pergola roof terrace, cobalt barrel roof,
and an external roof stair. Lower attached rooms produce interlocking compounds.
Buildings have beveled plaster edges, projecting jambs/sills, recessed arched or
rectangular doors, blue shutters, window mullions, balconies and flowering pots.
Landmarks include two main domed churches and a smaller waterfront chapel with
open bell gables, a sail windmill, two
harbors with small boats, shaded café courts, olive trees and slender cypress.
Individual irregular paving stones have pale mortar gaps. Connected main flights
link the promenade and hillside lanes; underlying stepped cliff meshes continue
below the buildings and the sea datum.

The asset is an environment backdrop, without interiors, exploration controls,
resident AI or changes to gameplay. In-game readability, frame time, weather and
camera transitions require the separate runtime verification performed by the
integration task. Blender preview images alone do not prove those requirements.

Reference research: `docs/santorini_visual_references.md` in the project root.

Runtime verification and comparison: `docs/santorini_town_verification.md`.
The shared backdrop connects windows and lanterns to the existing night cycle.
Low/balanced/high settings retain their rendering controls, with directional
shadow ranges of 100/280/420 m so the nearer village can receive shadows.
