# Godot Plush

Pilot mascot for the helicopter cockpit.

Source: [godotengine/godot-plush](https://github.com/godotengine/godot-plush) (Godot Engine).
Files: `godot_plush_model.glb`, `godot_plush_albedo.png`.

Not used by the game since 2026-10-08: the pilot, saw operator and referee are now the original
mascot in `assets/characters/aiquiz_mascot/`. This folder is `.gdignore`d and kept only for the
Blender-side v2 saw operator tools (`tools/saw_operator/build_station.py`).
