# AIQUIZ STADIUM 寸法表（Blender 精密制作用）

機械が読む版は `dimensions.json`（`measure/build_dimensions.py` が作る）。この文書は人が読むための要約。
値の根拠は3種類：**定数**＝ゲームのソースから読んだ値（`game_constants.json`、git HEAD `c3f3943` と各ファイルの sha256 付き）、
**実測**＝参照画像から測った値（`measure/measure_report.json`）、**設計**＝設計判断。
丸めは構造 0.05m・大物 0.25m、杭などのピッチは 20m を割り切る値。

## 座標系

| 対象 | 座標系と原点 |
| --- | --- |
| ワールド（Godot） | +X＝P1・オレンジ・**画面左**、+Y＝上、+Z＝コース前方。走路上面 Y=-1.2、海面 -9.2（デッキは海面上 8m）、海底 -129.2 |
| 側面スタンドのブロック（Blender） | X＝コースから外向き、Y＝コース方向、Z＝上。原点＝ブロック中央・ワールド高さ 0（走路上面 +1.2m）。ワールドでは |x|=28 に置き、左スタンドは 180° 回す |

| Blender→Godot | (X, Y, Z) → (X, Z, -Y) |

## 7. 光る部位（夕暮れ・夜、V01 夕暮れ／夜から）

灯台の灯室と光の筋（加算の大きな板は使わない）、マスト頂部の灯、照らされた帆、ブースの青パネル、
スタンド前手すりの暖色の帯、走路の縁の白い足元灯、遠景ビル群の窓。

v2 の帆はスタンドを横切る面なので、コースのカメラから帆の面が正面に見える。昼はゴール側の太陽の光が透け（Godot は BACKLIGHT）、夜はブームの灯に下から照らされたように、下ほど明るく光る（`night_glow` × 0.95）。
夜の灯は `AQS_NightGlow`（頂点色の灯の色 × 夜の強さ）、街の窓は `AQS_CityFacade_*` の夜の窓のテクスチャ。どれも Godot の天気（`night_amount_changed`）で一度に切り替わる。

## Godot への組み込み（v2 で実施）

- 観客の描画範囲は座席から求める（`grandstand_crowd.gd`）。6 段・背面 10.9m でも腕の動きまで入る
- 材質は `scripts/world/aiquiz_stadium/aiquiz_stadium_materials.gd` が名前で差し替える（頂点色、夜の灯、帆のシェーダー、街の夜の窓）
- ゴール観客席の構造は `aiquiz_stadium_goal_stand.glb`（`goal_stand.gd` の `STAND_SCENE`）、GOAL ゲートは `aiquiz_stadium_goal_gate.glb`（`game_world.gd`）
- スタンド・帆・遠景は `stage_environment.gd` の `layout_stadium_style = "aiquiz"`（既定）。`"santorini"` で以前のスタンドに戻せる
