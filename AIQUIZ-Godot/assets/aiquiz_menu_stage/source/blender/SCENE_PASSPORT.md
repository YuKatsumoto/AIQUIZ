# Scene Passport — AIQUIZ HARBOR LAUNCH（メインメニュー専用ステージ、Blender 組み立て）

SCENE
- intent: メインメニューの背景を「街（ゲームプレイ画面の奥のビル群）のそばの港の発進ステージ」にする。メニューのデモ（AI の 2 人がコンベアを走り、壁・のこぎり・保守船・ヘリの回収）はそのまま動かし、そのまわりを飾る。デザインはコンセプト A「港の発進デッキ」（`../concepts/r1_A_harbor_launch_deck.png`）、配置は V1「走路の右に発進デッキ」（`../concepts/r3_v1_deck_beside_runway.png`）に V3 のガラスの手すり・琥珀の灯を足したもの
- deliverable: `aiquiz_menu_stage.blend`（部品と確認シーン）、GLB 1 本（メニューのワールド座標）、配置 JSON（街の置き方・カメラ・発進デッキ）、看板のテクスチャ、確認レンダー、build_report.json。Godot への組み込み（メニュー背景に街とステージを置く、カメラ、LED・旗・ヤシの動き）
- units: metres; axes: right-handed Z-up。Godot = (X, Z, -Y)。**座標はメニューのワールド（Godot）**：ベルトの中心線 x = 0、ベルト上面 y = -1.2、ベルトは z -136〜8、海面 y = -9.2、メニューのカメラは -Z（ベルトの奥）を向く
- render: EEVEE, 1920x1080（確認用）, 24fps, frames 1–96（確認用の回り込み）, Standard の色変換
- dynamic: yes — ゲームのシェーダーで LED の流れる帯、旗のはためき、ヤシの揺れ、琥珀の灯の明滅。Blender は確認用のカメラの寄り（メニューのカメラ → 発進デッキ）
- build: ユーザーのライブ Blender で `build_menu_stage.py` を実行（Higgsfield の Blender 連携 `bl_execute`、runpy）。ヘッドレス実行はしない。シーン `AIQUIZ_MenuStage` だけを作り直し、ユーザーの他のシーンには触れない

ADDENDUM（2026-09-29）ビル群の手前（岸辺の街）
- 依頼：「ビルの手前あたりの作りが荒いのでもっと細かく作り込んでください」。メニューの街はスタジアムの遠景の街（遠目用）で、高層ビルの手前は窓のない低い箱・平らな護岸・丸い木の列だけだった。メニューでは 750〜950m（1m ≒ 画面の 2px）と近いので粗さが目立つ
- 方針：スタジアムの資産は変えない。メニューの街を別の GLB（`aiquiz_menu_city.glb`、街のローカル座標）にし、元の街の複製から手前の帯を取り除いて（`trim_city`：面の島ごとに、地面 z 4.5 から立つ y ≥ 137 の箱 104 棟とその屋上の設備、y ≥ 231 の護岸・砂浜・並木）、岸辺の街を足す（`ams_waterfront.py`）
- 意匠：Codex の 5 回目（海の上の近景の下絵に 2 案）と 6 回目（組み立て後のゲームの実画面の望遠に仕上げの描き足し 2 枚）。`../generation_record.json`
- 見え方で決めたこと：カメラは海面から 15.3m なので屋根はほとんど見えない → 正面・輪郭・水際で読ませる（日よけ・バルコニーの帯・看板板・瓦の寄棟・屋上のパラソルと鉢植え・糸杉）。
  メニューの UI が左半分を覆うので、目玉は画面の中央（走路の壁の上、x -85〜+87）に観覧車と市場、左端に時計塔と灯台（防波堤を画面の内側へ曲げる）
- 奥行きの精度：750m 先では数 cm の重なりが揺れる。壁に貼る面は 0.2m 以上離し、舗装は土地の上面から 0.25m 上。Blender の確認カメラも手前の切り捨てを 2〜5m にする
- 結果：三角形 92,705（元の街 5,312・護岸 11,394・歩道 23,588・建物 37,213・観覧車 5,632・船 9,566）、材質 10（遠景の共有材質 7 と `AMS_Facade_*` 3）、建物 150 棟、ボート 49 隻。
