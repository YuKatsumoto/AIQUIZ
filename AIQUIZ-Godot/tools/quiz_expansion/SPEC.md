# オフライン問題 大量補充 作問仕様

`AIQUIZ-Godot/offline_bank.json` を直接編集せず、**シャードファイル**に新問題を書き、
`validate.py` で検証してから push する。本体への統合は `merge.py` で別途行う。

## 1. 出力ファイル

`AIQUIZ-Godot/tools/quiz_expansion/shards/<slug>_g<学年>_<batch>.json`

| 教科 | slug |
|---|---|
| 算数 | math |
| 理科 | science |
| 国語 | japanese |
| 社会 | social |
| 英語 | english |

```json
{
  "subject": "理科",
  "grade": 5,
  "batch": "a",
  "items": [
    {"q": "問題文", "c": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"], "a": 2,
     "exp": "解説", "t": 4.0, "g": "単元名"}
  ]
}
```

- `q` 問題文（90字以内）
- `c` 選択肢ちょうど4つ（各30字以内、重複なし）
- `a` 正解のインデックス 0〜3
- `exp` 解説 1〜2文（120字以内）。なぜそれが正解かが分かること
- `t` 想定解答秒数 1.5〜10.0（読む時間＋考える時間）
- `g` 単元名（12字以内、例「てこのはたらき」「電流と電磁石」）。ゲームは同じ単元の連続出題を抑えるため、同じ単元は同じ表記で統一する

## 2. 作問ルール

### 内容
- 文部科学省の学習指導要領に沿い、**その学年までに習う内容**だけを出す。上の学年の内容は出さない。
- その学年の主要単元を最初に**8〜15個**列挙し、各単元へほぼ均等に配分する（1単元がシャード全体の25%を超えない）。
- 難しさを散らす: 一発で分かる知識問題・少し考える問題・複数ステップの思考や応用が必要な問題を **約1/3ずつ**。ゲームは問題文の長さや思考量から「簡単/普通/難しい」に3分割するので、全部同じ難しさにしない。
- 図・写真・表を前提にした問題（「図のように」「下の表で」）は禁止。文章だけで解けること。
- 年によって変わる事実（人口順位、統計の最新値、現職の人物、最新の記録など）は出さない。普遍的な事実だけ。
- 学校や地域で答えが変わる問題（教科書会社ごとの表記ゆれ、地域の行事など）は避ける。

### 選択肢
- 正解は**1つだけ**。他の3つは「それっぽいが明確に誤り」にする。
- 「すべて正しい」「どれでもない」「上のどれか」は禁止。
- 4つの選択肢の形式・長さ・品詞・単位をそろえる（正解だけ長い／具体的、などの手がかりを作らない）。
- 正解の位置（`a`）は0〜3にほぼ均等に散らす（各位置20〜30%）。
- 問題文に正解の語句をそのまま書かない。

### 表記
- 1・2年はひらがな中心、3年以上はその学年までに習う漢字を使う（難しい漢字はひらがなにする）。
- 問題文は「〜はどれですか？」「〜は何ですか？」など、問いがはっきり分かる形にする。
- 文頭に `【単元】` を付けてもよい（既存問題と同じスタイル）。

### 教科別の注意
- **算数**: 計算問題は必ず自分で計算し直して答えを検算する。単位換算の答えも検算する。文章題を3割以上入れる。
- **理科**: 実験・観察の結果や理由を問う問題も入れる（暗記だけにしない）。
- **国語**: 漢字の読み・書き、ことわざ・慣用句、敬語、文法（主語述語・修飾語・品詞）、言葉の意味、同音異義語などから広く。読解の長文は不可（問題文90字以内）。
- **社会**: 3・4年は地域・都道府県・くらしを支える仕事、5年は国土・産業、6年は歴史・政治・国際。歴史の年号・人物は確定した事実のみ。
- **英語**: 小学校外国語の語彙・表現（単語の意味、あいさつ、曜日・月・数・色、簡単な会話表現、アルファベット）。選択肢は英語なら全部英語、日本語なら全部日本語にそろえる。

## 3. 重複禁止
- 作り始める前に `offline_bank.json` の担当教科・担当学年の既存問題を**全部読み**、どの単元がどの切り口で出ているか把握する。
- 既存問題と同じ問題・言い換えただけの問題は禁止。同じ単元でも、問う知識や切り口を変える。
- `validate.py` が完全一致はエラー、類似（類似度0.85以上）は警告で出す。警告が出たものは作り直すか、本当に別の問題であることを確認する。

## 4. 手順

1. 担当の既存問題を読む → 単元リストと単元ごとの目標数を決める。
2. 50問くらいずつシャードに書き足す。
3. **正答チェックの見直しパス**: 全問について、もう一度ゼロから解き、`a` が指す選択肢が正しいこと、他の3つが明確に誤りであることを確かめる。怪しい問題は直すか削る（数を稼ぐより正確さ優先）。
4. 検証:
   ```
   python AIQUIZ-Godot/tools/quiz_expansion/validate.py AIQUIZ-Godot/tools/quiz_expansion/shards/<file>.json
   ```
   エラー0件になるまで直す。警告も原則すべて解消する。
5. 自分のシャードファイルだけをコミットして push する（`offline_bank.json` やほかのファイルは変更しない）。
