# クラウドセッション用 作問オーケストレーション手順

このファイルは、Claude Desktop から起動したクラウドセッションが読む指示書です。
あなた（このセッションのClaude）は**オーケストレーター**として、担当セッションIDの表にある
「教科×学年」をサブエージェントに作問させ、検証・抜き取り確認・コミット・pushまで**最後まで自律的に**行います。
ユーザーへの質問で止まらないこと。判断に迷ったら SPEC.md の「正確さ優先」に従う。

## 0. 準備

```
git fetch origin quiz-expansion/base
git checkout -b quiz-expansion/<セッションID小文字> origin/quiz-expansion/base   # 例: quiz-expansion/s1
```

`AIQUIZ-Godot/tools/quiz_expansion/SPEC.md` を全部読む。サブエージェントにも必ず読ませる。

## 2. サブエージェントへの割り振り

- 1セル = 1サブエージェント（Agent/Task ツール）。**同時に最大3つ**まで並列に動かす。
  サブエージェントが使えない環境なら、セルを1つずつ自分で順に処理する。
- 1つのセルの中の batch は**順番に**作る（b を書き終えてから c。c は b と重複しないこと）。
- サブエージェントには次のプロンプトを、`{...}` を埋めて渡す:

```
小学生向けクイズゲームのオフライン問題を作る。作業ディレクトリはリポジトリのルート。
1. AIQUIZ-Godot/tools/quiz_expansion/SPEC.md を全部読み、厳密に従う。
2. 担当: 教科 {教科}、{学年}年。ファイル {シャードパス一覧（batchと問数）} を、書いた順に作る。
   各ファイルの "batch" には batch 文字を入れる。
3. 書き始める前に AIQUIZ-Godot/offline_bank.json の {教科} {学年}年の既存問題を全部、
   前後の学年はざっと読む。shards/ にある同じ教科のシャード（{slug}_g*.json）も全部読む。
   これらと同じ問題・言い換えだけの問題は作らない。
4. その学年の主要単元を8〜15個決め、均等に配分する。g には単元名を統一表記で入れる。
   難しめ（t>=6.5 の複数ステップ問題）を3割以上入れる。
5. 1ファイル書き終えるごとに、全問をゼロから解き直す正答チェックをし、怪しい問題は直すか作り直す。
   python AIQUIZ-Godot/tools/quiz_expansion/validate.py <そのファイル> を実行し、エラー0、
   警告は解消（または誤検知と確認）してから次のファイルへ進む。
6. git の commit/push はしない（オーケストレーターが行う）。shards/ の担当ファイル以外は変更しない。
{教科・学年ごとの注意（下の §4 から該当部分をそのまま貼る）}
最後に短く報告: ファイルごとの問数、単元と問数、validate の結果行、修正・削除した問題数、残った警告とその理由。
```

## 3. サブエージェント完了ごとにオーケストレーターがやること

1. `python AIQUIZ-Godot/tools/quiz_expansion/validate.py <そのセルのファイル...>` でエラー0を確認。
2. **抜き取り検査**: 各ファイルからランダムに20問を選び、自分でゼロから解いて `a` が正しいか、
   誤答が明確に誤りか、学年相応か、事実が確定したものかを確認する。誤りが見つかったら直し、
   2問以上誤りがあったファイルは全問をもう一度見直す（自分で、または同じサブエージェントに差し戻す）。
3. そのセルのシャードだけを `git add` → commit（メッセージ例 `quiz: science g1 b,c (+382)`）→
   `git push -u origin quiz-expansion/<セッションID小文字>`。push が拒否されたら
   `claude/quiz-expansion-<セッションID小文字>` に push する。
   セルが終わるたびに push して、途中でセッションが止まっても成果が残るようにする。
4. master には絶対に push しない。offline_bank.json や SPEC.md など他のファイルは変更しない。

## 4. 教科・学年ごとの注意

- **理科・社会の1・2年**: 学校では生活科にあたる。身近な自然（季節、草花・野菜の育ち方、虫・小動物、天気、
  水・風・音・光・ゴム・磁石で遊ぶ）や、身近な社会（家族と家の仕事、学校の人と施設、公共施設、町の店や
  働く人、交通安全、季節の行事、昔の遊び）から出す。ひらがな中心、1年生が読める短い文。
  「人によって答えが変わる」問題（好きなもの、家庭による習慣、マナーのうち正解が1つに決まらないもの）は禁止。
- **理科3〜6年**: 学習指導要領の単元どおり。観察・実験の結果予想や理由、条件制御の問題を入れる。
- **国語**: その学年までの配当漢字だけを使う。読み・書き・部首・ことわざ・慣用句・四字熟語（高学年）・
  敬語（高学年）・文法・言葉の意味・同音異義語など。例文の一部を答えさせる問題の
  「answer appears in the question」警告は誤検知として扱ってよい。
- **社会3〜6年**: 3年は市区町村のくらし・店・農家や工場・消防や警察、4年は都道府県・47都道府県の位置と特色・
  水やごみ・自然災害・伝統文化と先人、5年は国土・気候・農業水産業・工業・情報・環境、6年は政治・歴史・国際。
  年によって変わる統計や順位、現職の人物は出さない。
- **英語**: 小学校外国語の語彙と表現の範囲。4択は全部英語か全部日本語にそろえる。
  3・4年は外国語活動（あいさつ、数、色、形、曜日、天気、身の回りの物、好き嫌い）、
  5・6年は外国語（月・日付、時刻、教科、職業、できること、道案内、町の施設、過去の出来事、行きたい国、将来の夢）。
- **算数5・6年**: 計算は全問で検算する。文章題を3割以上。5年は小数・分数のかけ算わり算、倍数約数、
  合同、図形の角、面積、体積、単位量あたり、割合、平均、速さ。6年は分数のかけ算わり算、比、拡大縮図、
  円の面積、角柱円柱の体積、比例反比例、場合の数、資料の整理（代表値）、文字と式、対称な図形。

## 5. 最後に

全セル完了後、`python AIQUIZ-Godot/tools/quiz_expansion/validate.py` を担当ファイルすべてに対して実行し、
最終 push を確認して、次を短く報告する:
- push したブランチ名
- ファイルごとの問数と validate 結果
- 抜き取り検査で見つけて直した誤りの数と内容
- 終わらなかったセルがあればその理由
