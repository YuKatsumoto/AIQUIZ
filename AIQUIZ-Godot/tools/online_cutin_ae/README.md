# オンライン対戦「VS カットイン」 After Effects 版

マッチが決まったときに出る VS カットイン（`docs/online_match_staging/spec.md` の S8〜S10・7・16）を、After Effects で作り直したものです。
ゲームと同じ組み立て（左＝じぶん・右＝あいて、稲妻の線で左右に分ける、VS が落ちる、名前の帯、ルールの行、読み込み中のホールド、中央の線で割れて開く）と時間配分のまま、格闘ゲームの対決画面のような勢いを足しています。
割れて開くところ（REVEAL）は仕様 S10 v1.6（読み込みが終わると 2 色の稲妻が線を走り、ためてから割れて、火花を散らし震えながらゆっくり開く。下のステージは同時に寄る。3.20 秒）です。

## コンポの構成

`VS_Cutin`（1920×1080・60 fps・7.0 秒。マーカー `IN` `HOLD` `LOOP` `REVEAL` `CHARGE` `BURST` `END`）

| レイヤー | 役目 |
|---|---|
| `CTRL` | 操作用のヌル（下の「コントロール」） |
| `LEFT_NAME` `LEFT_TAG` `RIGHT_NAME` `RIGHT_TAG` `RULES` | 文字の元（ガイドレイヤー。書き出しには出ない。ここを書きかえると画面の文字が変わる） |
| `FLASH` | 白い光（45%・3 フレーム。カットインの入りの 1 回だけ） |
| `REVEAL_FX` | 割れて開くときの光（`P_Reveal_FX`）。`SPLIT_SHAKE` の子 |
| `EDGE_GLOW_L` / `EDGE_GLOW_R` | 割れた内側のふちの光（それぞれのチームの色）。半分ずつの子なので一緒に飛んでいく |
| `CUTIN_SPLIT_L` / `CUTIN_SPLIT_R` | 割れて開くときの左半分・右半分（`CUTIN_GRAPHICS` を稲妻の形のマスクで切ったもの）。`SPLIT_SHAKE` の子 |
| `CRACK_LIGHT` | ためのあいだに 4 px のすきまからもれる光（半分たちの下） |
| `SPLIT_SHAKE` | REVEAL の 2D の層をまとめて揺らすヌル（ためのふるえ・割れたときの揺れ） |
| `CUTIN` | カットイン本体（`CUTIN_GRAPHICS`。3.60 秒まで） |
| `FOCUS_LINES` | 最初の 3D の上にかかる集中線 |
| `FORMATION_PLATE` / `STAGE_PLATE` | 下の 3D の仮の絵（差しかえ用） |

`CUTIN_GRAPHICS` の中（下から）：`PANEL_L` `PANEL_R`（稲妻の形のマスク付き）→ `VIGNETTE` → `CHAR_L` `CHAR_R` → `SEAM` → `RULES_PILL` `RULES_TEXT` → `VS` → `PLATE_L` `PLATE_R` → `GAUGE_*`。揺れはすべて `SHAKE` ヌルの子にしてまとめて揺らします。

部品のプリコンポ：

| プリコンポ | 中身 |
|---|---|
| `P_Panel_L` / `P_Panel_R` | チームの色の放射グラデーション、背中の光（12 本の光の筋、ゆっくり回る）、網点（18 px 間隔、外ほど濃い）、外へ流れる集中線（36 本×2 組） |
| `P_Char_L` / `P_Char_R` | キャラの画像 8 枚（スロット 2 色 × ポーズ 4 種）。`CTRL` の値で 1 枚だけ見える |
| `P_Seam` | 稲妻：チームの色の光（左右）、白い芯 7 px、枝分かれの小さな稲妻、線を下へ流れる光の粒 |
| `P_VS` | 12 本の角の星（黄 #FFD23F・ふちオレンジ #FF8A00・紺の線）、「VS」、着地の輪と光の筋 |
| `P_Plate_L` / `P_Plate_R` | 名前の帯（560×84、白 92%、ふち 6 px のチームの色）と「じぶん」「あいて」の札 |
| `P_Reveal_FX` | REVEAL の光（下から）：光の壁 `WALL_L` `WALL_R` `WALL_CORE` → 光線 `RAYS_L` `RAYS_R` → ためた線の光 `CHARGE_GLOW_L` `CHARGE_GLOW_R` → 稲妻の影 `BOLT_SHADOW` → 2 本のより合わせた稲妻 `STRAND_L` `STRAND_R` → 白い芯 `BOLT_CORE` → 枝 `FORKS_L` `FORKS_R` → 先の光の玉 `HEAD_GLOW` `HEAD_CORE` → 火花 `SPARKS_L` `SPARKS_R`（各 34 個） |

### 割れて開く（REVEAL、S10 v1.6、3.20 秒）

v1.6（2026-10-12）で、割れたあと「火花を散らし、震えながらゆっくり開き、下のステージが寄る」ように変えた（ゲームの `SceneTransition.VERSUS_SPLIT_FX` と同じ数・同じ式。仕様書 25）。
`REVEAL` は 3.60〜6.80、`BURST` は 4.35。下の表は v1.4 のもので、0.62 秒より後の時刻は次のとおり読みかえる。

| 時刻（REVEAL から） | v1.6 |
|---|---|
| 0.40〜0.75 | ためる（v1.4 の 0.40〜0.62 と同じ動きを 0.35 秒で） |
| 0.75 | 割れる。左右の半分ががくんと 5% 開き（0.23 秒）、v1.4 の火花と揺れ（±6 px・0.18 秒） |
| 0.75〜2.58 | こすれながらゆっくり開く。`CUTIN_SPLIT_L/R` が別々に震え（最大 4 px、38 Hz。式は位置の式の中）、`P_Reveal_FX` の `GRIND_SPARKS_L/R`（各 150 本）が、そのときの半分の切り口から生まれてすき間へはじける |
| 〜3.04 | 速く外へ抜ける：`e = 0.05·(1−(1−j)²) + 0.95·smoothstep(0.05,1,k)^1.7`（k＝(t−0.75)/2.29、j＝k/0.10） |
| 0.75〜3.04 | `STAGE_PLATE` が 100 → 112% に寄る（k の smoothstep。ゲームではカメラが後ろ 9 m・上 2.5 m・画角 +8° から寄る） |
| 〜1.95 | 光の壁が消える（光線は 1.70、火花は 2.00 まで） |

v1.4 の .aep とスクリプトは `artifacts/online_cutin_ae/backup_v1_4/` に残してある。

#### v1.4 の表（参考）

時刻は `REVEAL` マーカー（3.60 秒）からの秒。かっこの中は 1.80 秒に対する割合です。

| 時刻 | 段 | 動き（AE 版） |
|---|---|---|
| 0.00〜0.50（0〜0.278） | 走る（STRIKE） | 2 色の稲妻が稲妻の線にそって上の端から下の端へ、**一定の速さ（線の長さに対して）**で走る。左の色と右の色の 2 本が線のまわりでより合わさり（振れ幅 19 px・波長 210 px、より目は毎秒 2.2 回分ずつ下へ流れる）、白い芯 4 px が重なる所を白く熱くする。先には光の玉（芯 30 px ＋ 光 170 px）。玉のすぐ後ろで短い枝が 12 本、左右交互に生まれて 0.15 秒で消える。走ったあとの線は 2 色の光（左右に 10 px ずらした光）で光り続ける。形は 1 秒に 30 回、数 px（2〜3 px）だけギザギザに描き直すが、明るさは変えない |
| 0.40〜0.62（0.222〜0.344） | ためる（CHARGE） | 線の光が太く明るくなる（26 → 72 px、不透明度 60 → 100%。白い芯 4 → 11 px）。左右の半分が 2 px ずつ外へ動き（smoothstep）、4 px のすきまから `CRACK_LIGHT` がもれる。2D の層が小さくふるえる（最大 3 px、0 から大きくなる） |
| 0.62（0.344） | 割れる（BURST） | 左右の半分が外へ飛ぶ：`open = 1 − (1 − k)^1.8`、k は 0.62 → 1.53 秒で 0 → 1。横に 0.62 画面幅（1190 px）、左は反時計回り・右は時計回りに 5°、縮尺 1.00 → 1.10。1.53 秒で画面の外。割れた内側のふちがそれぞれのチームの色で光る（`EDGE_GLOW_*`）。2D の層を ±6 px、0.18 秒で小さくなる揺れ |
| 0.62〜1.60 | 光の壁 | 線にそった 2 色の光の壁が横に広がりながら消える（左の色は左へ 380 px、右の色は右へ 380 px、太さ 40 → 760 px、ピーク 62%。白っぽい芯は 24 → 220 px、45% → 0 を 1.20 まで） |
| 0.62〜1.45 | 光線 | 線から左右に 12 本ずつ扇形の光線（長さ 520〜1050 px、0.62〜0.80 で伸びて 0.85 から消える） |
| 0.62〜1.80 | 火花 | 線にそって左右 34 個ずつ、左の色は左へ・右の色は右へ飛ぶ（速さ 450〜1900 px/秒、空気の抵抗と重力）。1.80 までにすべて消える |
| 0.62〜1.80 | ステージ | 下のステージの絵が 106% → 100% に少し引く |
| 1.35〜1.80 | 終わり | ステージがすべて見え、光が消えていく |

揺れの式（`SPLIT_SHAKE`）：ためのあいだ t＝0.40〜0.62 は `a = 3·(t−0.40)/0.22`、`(sin(173t)·a, cos(151t)·a)`。割れたあと u＝t−0.62 が 0〜0.18 は `k = 1 − u/0.18`、`(sin(97u)·6k, cos(83u)·6k)`。
半分の式：`c = smoothstep((t−0.40)/0.22)`、`e = 1 − (1 − k)^1.8`（k＝(t−0.62)/0.91、0〜1 に切る）、x＝もとの位置 ∓ (2c ＋ 1190.4e)、回転 ∓5e°、縮尺 100 ＋ 10e %（ゲームと同じ式）。

## コントロール（`VS_Cutin` > `CTRL` のエフェクト）

| 名前 | 種類 | 既定 | 内容 |
|---|---|---|---|
| Guest View | チェック | オフ | オフ＝ホスト（左オレンジ・右ブルー）、オン＝ゲスト（左ブルー・右オレンジ）。パネル・稲妻の光・帯のふち・札・キャラの画像がいっしょに入れかわる |
| Slot1 Color | カラー | (0.95, 0.55, 0.20) | スロット 1（ホスト）の色 ＝ `PlayerController.P1_BODY` |
| Slot2 Color | カラー | (0.20, 0.65, 0.90) | スロット 2（ゲスト）の色 ＝ `PlayerController.P2_BODY` |
| Left Color / Right Color | カラー | 式 | 上の 3 つから自動で決まる（さわらない） |
| Left Pose / Right Pose | スライダー | 0 / 1 | `CUTIN_POSES` の番号（0 腕組み、1 パンチ、2 こぶしを上げる、3 ダンス）。ゲームでは名前から決まる（`cutin_pose_index`：「ご機嫌な鉛筆」＝0、「テストの あいて」＝1） |
| Show Gauge | チェック | オン | ゲージと「じゅんび ちゅう」を出すか |
| Gauge Progress | スライダー | デモのキー | ゲージの進み（0〜100）。0.90〜3.45 秒で 0 → 100 のデモのキーが入っている。ループとして使うときはキーを消して一定にする |
| Breath Period | スライダー | 2.4 | キャラの息の周期（秒）。2.4 以外にするとループのつなぎ目がずれる |
| Spark Period | スライダー | 1.2 | 稲妻の光の粒の周期（秒）。2.4 を割り切れる値にするとループのまま |

文字は `LEFT_NAME`（ご機嫌な鉛筆）、`LEFT_TAG`（じぶん）、`RIGHT_NAME`（テストの あいて）、`RIGHT_TAG`（あいて）、`RULES`（さんすう ・ 3年 ・ ふつう）の「ソーステキスト」を書きかえます。
名前が帯（中の幅 510 px）に入りきらないときは自動で縮み（仕様の「9 文字をこえたら 32 px」の代わり）、札とルールの帯は文字の長さに合わせて伸びます。長い名前・別の札・別のルール・ポーズ 2 と 3 で表示がくずれないことを確かめています。

式はすべて `comp("VS_Cutin").layer("CTRL")` を読むので、メインのコンポと `CTRL` の名前は変えないでください。

## キャラの画像を撮り直す

`tests/online_cutin_ae/capture_cutin_chars.gd` は、ゲームのカットイン（`online_cutin.gd`）と同じ `CutinActors.prepare()` で箱の人形にポーズを当て、左右のカメラの SubViewport（背景透明）を PNG に保存します。

```
./Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1280x720 --script tests/net/net_match_bootstrap.gd -- runtime=res://tests/online_cutin_ae/capture_cutin_chars.gd
```

- 出力：`artifacts/online_cutin_ae/chars/slot{1|2}_pose{0..3}_{L|R}.png` と `manifest.json`（ポーズの表とサンプルの名前のポーズ番号）。
  `L`＝左のパネル用（体は右＝真ん中を向く）、`R`＝右のパネル用（左を向く）。
- 大きさ：高さはゲームの SubViewport（900×1000）の 2 倍＝2000 px。幅は 1.3 倍の 2340 px に広げている（カメラは縦の画角を保つので、体の大きさと位置はゲームと同じまま、横に伸ばした腕が切れなくなる）。`scale=` `wide=` `out=` で変えられる。
- 帽子はかぶせない（`HAT_NONE`）、肌はスロットの標準色。
- 撮り直したら、AE で .aep を開き直すか `build_vs_cutin.jsx` を流し直せば新しい画像になる（ファイル名が同じなら .aep はそのまま差しかわる）。

`plates/` の 2 枚は、`artifacts/online_staging/camera_pro/v3/s7_formation.png`（並走）と `artifacts/crowd_variety/p2_COUNTDOWN.png`（ステージ。16:9 に切り抜き）を 1920×1080 にしただけの仮の絵です。本番の 3D に合わせるときは AE の「フッテージを置き換え」で差しかえてください。

## フォント

- 名前・札・ルール・ゲージ：**NotoSansJP-Bold**（Windows に入っている Noto Sans JP の可変フォント `NotoSansJP-VF.ttf` の Bold。ゲームの `res://resources/fonts/NotoSansJP-Bold.otf` と同じ書体）
- 「VS」：**NotoSansJP-Black**（同じ書体のいちばん太いもの。仕様の Bold 170 px より太く、178 px）
- コンタクトシートのラベルだけ Yu Gothic Bold

## 作り直す・書き出す

AE（`G:\adobe\Adobe After Effects 2026\Support Files\AfterFX.exe`）を開いたまま、外からスクリプトを流します。

```
"G:\adobe\Adobe After Effects 2026\Support Files\AfterFX.exe" -r C:\AIQUIZ\AIQUIZ-Godot\tools\online_cutin_ae\build_vs_cutin.jsx
"G:\adobe\Adobe After Effects 2026\Support Files\AfterFX.exe" -r C:\AIQUIZ\AIQUIZ-Godot\tools\online_cutin_ae\render_vs_cutin.jsx
python tools/online_cutin_ae/make_contact_sheet.py
```

- `build_vs_cutin.jsx` は **今開いているプロジェクトを保存せずに閉じ**、一から組み立てて `AIQUIZ_VS_Cutin.aep` に上書き保存します。.aep を手で直したときは、流す前にその変更を build のほうへ移してください。
  失敗や式のエラーは、ダイアログではなくプロジェクトの `_build_log` フォルダの中のフォルダ名として出ます（エラーがなければ何も出ない）。
- `render_vs_cutin.jsx` は、`Guest View` をオフ → オンにして 2 本をレンダーキュー（最良設定・「H.264 - レンダリング設定を一致 - 40 Mbps」）で書き出し、オフに戻して保存します。2 本で 2 分ほど。
- AE の画面から書き出すときは、`VS_Cutin` をレンダーキューに入れ、出力モジュールを H.264 にします。ゲスト版は `CTRL` の `Guest View` をオンにしてからもう一度。

## 仕様から変えたところ（意図的）

| 項目 | 仕様・ゲーム | AE 版 | 理由 |
|---|---|---|---|
| キャラの息の周期 | 2.2 秒 | 2.4 秒（`Breath Period`） | 光の粒 1.2 秒と同じループ（2.4 秒）でつなぎ目をなくすため |
| VS の脈 | ±2%（ゲームのコードは 1.1 秒） | ±2%、1.2 秒 | 同上 |
| 星の回転 | 毎秒 10° | 毎秒 12.5° | 2.4 秒で 30°＝12 本の角 1 つ分で、ループのつなぎ目が見えない |
| VS の大きさ | 星の半径 168 px、文字 170 px | 全体を 115%（文字は Black 178 px） | 大きなキャラに負けないように。ルールの行は少し下（中心 y＝672）へ |
| 白い光の時刻 | 稲妻を描き終えた 0.32 秒から 0.06 秒 | 0.317〜0.367 秒（60 fps の 3 フレーム） | フレームにそろえ、0.06 秒以下にするため |
| ホールドの長さ | 読み込みが終わるまで（最短 1.40 秒） | 2.70 秒（なじませ 0.30 秒 ＋ ループ 2.40 秒） | プレビュー用。ループの区間は `LOOP` マーカー |
| 割れて開く中身 | SWAP で写した止まった絵 | 動いているカットインをそのまま割る | 見た目の違いはほとんどない |
| 稲妻の走り方 | 上の端から下の端へ 0.50 秒 | 線の長さに対して一定の速さ（上の端の外 y＝−22 から下の端の外 y＝1102 まで） | ゲームとまったく同じ位置にするため |
| 名前が長いとき | 9 文字をこえたら 32 px | 帯に入るまで自動で縮める | どの長さでもはみ出さない |

## 見やすさ・安全（仕様 16）

- 白い光は 1 回だけ、45%、3 フレーム（0.05 秒）。書き出した動画でも、画面全体の明るさが上がるのはフレーム 19〜21 だけであることを確かめた。
- REVEAL には画面全体の白い光はない。いちばん明るいのは稲妻の芯と線の光。書き出した動画で、REVEAL のあいだの画面の平均の明るさは 151 → 168（R＋0.73）と少し上がるだけで、1 フレームでの変わり方は最大 5（255 段階）、ほぼ白の画素はいちばん明るいフレームでも 6.5%。
- 揺れは 2D の層だけ：VS の着地（`SHAKE`、0.600〜0.767 秒、最大 5.7 px）と REVEAL（`SPLIT_SHAKE`、ためのふるえ最大 2.5 px、割れたときの揺れ最大 5.3 px）。どれも ±6 px 以内。下の 3D の絵は揺らさない。
- 点滅は 3 Hz 未満：VS の光の帯は 2.4 秒に 1 回、ゲージの点は 0.6 秒ごと。キャラの登場の淡い色や着地の輪・光の筋は画面の一部だけで、画面全体の光ではない。
- 色だけに頼らない：「じぶん」「あいて」の札と名前を必ず出す。

## わかっている制限

- キャラの画像は撮った色（スロットの標準色）のままです。`Slot1 Color` / `Slot2 Color` を変えても、パネル・稲妻・帯・札の色だけが変わります。帽子やスキンを変えた絵が要るときは、キャプチャのスクリプトで撮り直してください。
- `artifacts/` は git に入らないので、素材（キャラ・plates）は撮り直し・作り直しが必要です。
- 下の 3D（並走とステージ）は静止画の仮の絵です。
